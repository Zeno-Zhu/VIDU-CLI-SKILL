# 03｜角色与锚点

> 源：《无限轮回宇宙·短剧共创 设定》1.5–1.6、5.7
> 主角是「一个人演无数辈子」，不是「无数个人共用一个名字」。这一份讲的就是怎么拿捏这条线。

---

## 一、主角的统一人格

所有平行世界中的男主角，共享同一个核心人格。

姓名、身份、外貌、年龄、职业、身体条件、社会位置可以随世界变化。但**核心思维方式、长期性格倾向、已经确认的重要人格特征**需要保持连续。

### 默认核心人格

> 见多识广、头脑灵活、拥有很强的适应能力，经历过无数人生却仍然愿意体验新的命运。

具体展开：

- 可以幽默、自嘲、嘴贫、调侃；也可以严肃、狠辣、沉默，或非常投入当前身份。
- 有自己的判断，不容易因为普通权威、财富与地位失去主见。
- 愿意尝试新鲜事物，也可能因经验丰富而产生误判、自负或习惯性轻视。
- 面对真正重要的人和关系，可以投入感情、作出选择并承担后果。
- 面对欺骗、背叛和伤害，按自身性格与当前处境采取不同回应。

**他不是永远道德正确、永远冷静、永远成熟的完美人物。也不是每时每刻都在开玩笑的固定喜剧角色。**

### 性格稳定 ≠ 表现固定

| 这一世 | 可以表现成 |
| --- | --- |
| 帝王 | 统治者的威严 |
| 少年 | 利用少年身份完成特殊行动 |
| 反派 | 按当地身份与利益采取强硬甚至错误的选择 |
| 动物 | 知识与身体能力不匹配的荒诞反差 |
| 恋爱中的普通人 | 嫉妒、偏爱、思念、冲动 |

这些变化不等于核心人格改变。

> **核心人格是人物的长期底色，不是固定台词、表情、情绪曲线或行为清单。**

不要求每部世界篇都安排主角成长。一个故事可以主要让他体验某种身份、完成某个目标、享受某种生活或解决局部矛盾。

重大人格变化，只有在故事确实建立充分原因时才正式成为跨世界事实。

## 二、固定灵魂锚点

在无数平行世界中，存在一个与主角具有特殊跨世联系的女性灵魂锚点。她是整个系列长期共享的重要人物。

### 她的自由度

在不同世界中，可以有不同姓名、外貌、身份、能力、年龄、背景、地位与人生经历。

可以是普通人、贵族、商人、修仙者、将军、敌人、科学家，甚至可以成为反派与主角相爱相杀。

**不要求：**

- 每个世界篇都出现她
- 每个世界篇都让她与主角相遇
- 她每次都知道主角是谁
- 她每一世都保留其他人生记忆
- 她每一次出现都爱上主角

### 情感规则 ⛔

**如果某个世界篇为主角安排正式的主要爱情伴侣，该伴侣应当是灵魂锚点在当前世界中的对应身份。**

可以存在其他角色对主角产生好感、暗恋、追求、利益婚约或单方面情感。但不能在没有修改母设的情况下，长期建立一个与固定锚点相冲突的全新正式爱情伴侣。

主角与锚点女主也可以：擦肩而过、成为朋友、互相敌对、彼此错过、建立爱情，或最终分离。

**她应具有自己的性格、欲望、选择与人生，不是必须爱上主角的剧情奖励。**

### 长期秘密

她为什么会在不同平行世界中与主角形成特殊关联，属于长期世界秘密。

其起源、特殊能力、与世界意志的关系、最终命运，**不在普通独立世界篇中擅自确定**。相关真相由母宇宙正式设定或后续明确共创决定。

## 三、锚点的使用纪律

| 场景 | 怎么做 |
| --- | --- |
| 本篇卖点是爱情 | 让锚点登场，当世身份真正属于当前世界，不照搬其他世界人设 |
| 本篇卖点不是爱情 | 不为了「用上锚点」强行加感情戏。她可以缺席 |
| 需要她的当世身份 | 从当前世界的社会结构里长出来，不从系列人设里套过来 |
| 涉及她的灵魂秘密 | 遵守已确认的信息边界，不擅自揭底 |

---

## 四、主角的三条底线

写任何一集都可以拿这三条对一遍：

1. **他得是主动的。** 可以暂时失败、受辱、被限制，但不能长期只承担被动解释、求情、挨打、等别人解决问题。
2. **他的选择得有代价。** 重要节点上他做的决定，要真的改变局势或关系，而不是「表态正确但什么也没变」。
3. **他不能被写成一个道德讲台。** 他可以在某些世界做错事并承担结果。不要求每世都完成正向道德成长。

---

## 五、自检

- 把这一集的主角台词单独抽出来，去掉名字——还能认出是同一个人的说话方式吗？
- 这一世的表现，是因为「身份变了」还是因为「人格换了」？后者是错的。
- 锚点这一世的欲望，是这个世界给她的，还是从别的世界抄过来的？
- 本篇的爱情线，是不是在没有第二个「正式伴侣」的前提下成立的？

## 六、与主角相关的资产编号

写数据时角色用 `C` 编号，锚点关系用 `anchor` 字段标注：

| `anchor` 值 | 含义 | 约束 |
| --- | --- | --- |
| `base:wanji` | 万集本世身份 | 全篇恰好 1 个 |
| `base:suwei` | 苏薇（锚点）本世身份 | ≤1 个；`coreValue` 含爱情/甜时必须存在 |
| `system` | 系统精灵 | ≤1 个 |
| `local` | 本世界原创角色 | 不限 |
