# 一句话做视频

用一句话，做出一条能发的视频。

不是让你学剪辑，不是让你研究模型参数。你说清楚要什么，AI 帮你拆镜头、写提示词、提交、收片。

---

## 能做什么

**做短剧**
有剧本就能开工。都市、悬疑、玄幻、动漫，都行。
一集两分钟，一天能做几集。

**卖货**
保温杯、护肤品、小家电、衣服。
一条 30 秒，说清卖点，能直接投。

**开店 / 本地生活**
餐馆、理发店、健身房、汽修。
拍门头、拍手艺、拍人气，让三公里内的人走过来。

**企业宣传**
厂房、设备、团队、服务能力。
不用请摄制组，也不用租场地。

**做符**
把一套本事压成一张图。
太极拳怎么打、镜头怎么推、赛博朋克世界长什么样——你讲得清，它就能封成一张 16:9 的能力卡。
以后做视频带上这张图，模型照着里面的规矩来。
做过的符自动进库，攒到十几张，就是你自己的招式谱。

## 装进你的 AI（复制这段发给它）

````
帮我装一个 skill：VIDU-CLI-SKILL
仓库：https://github.com/Zeno-Zhu/VIDU-CLI-SKILL.git

1. clone 下来，直接放进这台机器的 skills 目录。
   WorkBuddy 是 ~/.workbuddy/skills/，Claude Code 是 ~/.claude/skills/，
   不确定就先查你自己的文档，别随便找个地方塞。

2. 放好之后确认它被识别（重启或者刷新一下）。

3. 跑 python scripts/init_env.py --check。
   机器上没 Python 就你自己装，winget 或者官方安装包静默装都行，
   别让我动手，也别让我去点 .cmd。

4. 引导我打开 vidu.cn，点左下角头像，找到「Vidu Token」，复制发给你。
   我要是找不到，把 assets/vidu-token.png 发给我看。
````

拉不下来的话，换成 SSH 地址或者镜像再试，别卡在这一步。

**用的是别的 AI**（ChatGPT、豆包、Kimi 这类不支持 skill 的）：把 `SKILL.md`
和你要走的那份提示词一起贴进对话框就行。但这类助手跑不了本地脚本，
提交那步得你自己来——双击 `1-初始化环境.cmd`，它会告诉你还差什么。

## 怎么用

### 1. 说你要做什么

打开对话框，说一句话就行：

- 「我要做一集都市悬疑的短剧，剧本在这……」
- 「我做保温杯，想拍条带货视频发抖音」
- 「我开了家川菜馆，想拍条视频让附近的人来吃」
- 「给太极拳做个符，掤捋挤按那四个劲儿我总是说不明白」

AI 会一个一个问你剩下的问题。**一次只问一件**，你答完再问下一件。

### 不想聊？可以让它自己干

有些人只想赶紧拿到片子，不想来回讨论。可以这么跟它说：

- 「你全做完给我看，别中间问我」→ 它一路做到底，交片时告诉你哪里可能不合意
- 「资产、脚本、提示词这三处停一下」→ 三个关键节点给你看，其余自己决定
- 「每一步都问我」→ 慢慢来
- 「第 2 步和第 4 步停，其他别问」→ 你自己点名

**没说就默认第二种。** 中间有三次点头的机会，既能纠偏，又不至于被问烦。

就算开了全自动，**资产图那一步它也会给你看一眼**——图不对，后面几十条全白做，重做比看图贵得多。

### 2. 看分镜，点头

它先给你一张分镜表：第几个镜头、多长、画面发生什么、有没有人说话。

不满意就改，改到满意为止。**这一步最省钱**——分镜错了，后面全白做。

你点头之后，它才写提示词、提交、收片。

### 3. 要做符？说个名字就行

- 「把太极拳做成符」
- 「来一张运镜的符，一镜到底那种推轨」
- 「赛博朋克的世界观，做成符」

它干两件事：先把这套本事拆成能照着做的规则，再画成一张 16:9 的图。

**它会先问你一句**：这东西解决什么问题、模型现在做不好什么。一句就够，剩下它自己办。

出来就是一张图，存在 `out/符/` 下。图上的中文字要是错了，它会自己改着重画——最多三次。三次还错，说明这张符塞的东西太多，它会砍成两张。

**做符花的是积分，不占闲时额度。** 让它先查一下余额。

### 4. 符攒起来就是库

每做一张符，它自动登记一条：叫什么、管什么、什么时候该调。以后你可以直接说：

- 「我库里有什么符？」
- 「用那张太极拳的符，做第 3 个镜头」
- 「有没有讲推镜的符？」

**符就是一张参考图**，跟你的角色图、场景图一样传进去。但记住：**它不是非得用**，没合适的就别挂——挂错比不挂更糟。

## 要花多少钱

**闲时额度：每天 200 条，0 积分。**

200 条 × 16 秒 = 53 分钟。一天白拿一部电影的长度。

一条 15 秒的镜头，闲时成本 **8 分钱**。

要是不走闲时（比如需要带人声），才花积分。一集 90 秒大概 5 毛。

---

## 三条要知道的事

**① 提交时必须写 `nopeak`**

```
--schedule-mode nopeak
```

不写，默认扣积分。这是最容易漏的一条。

**② 同时最多 100 条在跑**

40 条一次交完没问题；两百条得分批，不然后面的会失败。

**③ 闲时没有声音**

画面走闲时，声音单独做，最后在剪辑软件里合。想要一次出带声音的，得花积分。

---

## 出片要多久

40 条 15 秒的镜头，大概一个小时陆续出来。

不用坐着等。交上去就去干别的，出来一条看一条。

---

## 常见问题

**画面里人变了样？**
每组开头要写清「人在哪、朝哪边、光从哪来」。这三件不写，模型每次都重新想象。

**人物脸糊了？**
景别太远。想看清脸就用近景。

**崩了怎么办？**
重跑。8 分钱的事，别纠结。便宜的好处就是能多试几次。

**提示词不会写？**
不用你会。你把想拍的说清楚，AI 写。写出来太虚，让它改具体。

**能保证不崩吗？**
不能。便宜换来的就是偶尔崩。关键镜头想稳，用贵一点的平台，剩下九成用这个。

## 里头有什么

```
1-初始化环境.cmd              双击就能装好（平时不用管）
SKILL.md                      给你的 AI 看的说明书
README.md                     你现在看的这个
prompts/00-万能提示词.md        填几个空就能用
prompts/01-漫剧分镜提示词.md    做短剧用
prompts/02-商业视频提示词.md    卖货、开店、企业宣传用
prompts/03-符生成.md            做符用（收料 → 封装 → 生图 → 验字）
prompts/符的生成.txt            符的规则本体
references/提示词自检表.md      提示词合不合规，对着改
references/vidu-q4-参数.md      参数细节，报错时查
scripts/vidu.py               内置客户端：提交 / 查询 / 下载 / 生图 / 做符 / 符库
scripts/init_env.py           环境检查（cmd 里调的就是它）
assets/vidu-token.png         找 Token 的位置截图（找不到时 AI 会发给你）
out/符/_库.json               你的符库索引（谁管什么、什么时候调）
out/符/符-*/                  一张符一个文件夹：图 + 简介 + 提示词存档
```
