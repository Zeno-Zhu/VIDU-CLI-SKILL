# 万能提示词

填几个空，丢给你的 AI。它会先给你分镜，你点头了它才往下做。

---

## 主提示词（复制这段，改填空）

```
我要做一条视频，你帮我从想法做到能提交。

【我要做什么】
类型：@@漫剧 / 电商带货 / 门店宣传 / 企业形象@@
内容：@@一句话说清楚，比如"社区川菜馆的现炒招牌菜"@@
时长：@@30 秒@@
发在哪：@@抖音 / 视频号 / 小红书@@
我有的素材：@@角色图 / 产品图 / 门店照片 / 什么都没有@@

【你怎么做】
第一步，先盘资产：人物、场景、道具各要哪些，哪个有我现成的，哪个要你生。
第二步，缺的按设定板生图，生完先给我看，我确认长相和空间对不对。
第三步，出分镜组表：每组 12-16 秒（最多 16），组里 3-5 个分镜，单个分镜不低于 1.2 秒。
        表里要有：组号、镜号、时长、景别、角度、运镜、画面里发生什么、谁说了什么。
        运镜这一列不能空，固定机位也要写"机位固定"。
第四步，你自己审一遍这张表，改一轮，把改好的终版表给我看，顺便说动了哪几处。
第五步，我点头之后，每组写一条提示词（组里几个分镜就写几段）。
第六步，把提示词提交到 Vidu，盯着进度，好了就下载。

【几条规矩】
- 模型用 Vidu Q4，一组 12-16 秒，别超过 16；单个分镜不低于 1.2 秒
- 人物设定板以正面全身 + 背面全身为主；**含脸画面越少越稳**（一图多脸会丢身份、年龄漂移），表情示例不做
- 设定板不规定几宫格，只写清必须出现哪些角度，怎么排让模型自己定
- 有人说话就先判通道：闲时（默认）无法参考音色 ⇒ 写一份音色设定给每个角色锁声线，全片同一份；只有 normal 档才能挂样音（4-5 秒一句台词，剪映能裁）
- 台词一个字别改，只能拆句
- 提示词写能看见的东西，别写"有氛围感""高级感"这种
- 一律走闲时模式，别花积分
- 同时最多 100 条在跑，多了就排队，跑完一条补一条
- 每条提交完，把组号和 task_id 记下来

【我不要什么】
- 不要一次给我一大堆，分两步来
- 别说"让我们一起""深度赋能"这种话
```

## 三种场景怎么改

**漫剧 / 短剧**——多给一份剧本，其他不变

```
类型：漫剧
内容：都市悬疑，一集 2 分钟，剧本我发你
时长：120 秒
发在哪：抖音
我有的素材：角色图三张，场景图两张

剧本在下面（贴进来）：
```

漫剧的分镜要比电商细，所以补一句：

```
漫剧的镜头要写出景别、运镜、人物表情和动作起止，因为这决定画面里的人像不像。
```

---

**电商带货**——把产品说清楚，卖点是关键

```
类型：电商带货
内容：智能保温杯，卖点是 12 小时保温、杯盖可拆洗
时长：30 秒
发在哪：抖音
我有的素材：产品图 5 张，白底图 3 张

产品面向上班族，价格 129，想让看完的人点小黄车。
```

电商要补一句：

```
最后一个镜头要留出放价格和购买引导的位置。
```

---

**门店 / 企业宣传**——地址和到店理由是重点

```
类型：门店宣传
内容：社区川菜馆，现炒，人均 45，位置在XX路
时长：30 秒
发在哪：视频号
我有的素材：门头照、菜品照各几张

让附近三公里的人看完想来吃。
```

门店要补一句：

```
尽量别出现清晰人脸，用环境和菜品说话。
```

## 还没本子，要写剧本，这么说

```
帮我写一集短剧，按无限轮回宇宙那套。

这一世他是 @@物业经理@@，在 @@一个老小区@@。
我想要的感觉：@@先受气，再翻盘，结尾留个钩子@@
一集 @@75@@ 秒，先写 1 集看看。

写完给我 Word 和 JSON，别顺手给我排片子。
```

**世界观不用你定。** 默认就是无限轮回宇宙——主角在无数平行世界里轮回，每一世一个身份、一部独立的戏。

它只会问一两件非问不可的：这一世是什么身份、在什么地方、你想要什么感觉。

出来是 `剧本.docx`（打开就能用）+ `script.json`（下一步做片子读它）。

**看完觉得行，再说「接着做成片子」**，本子不用重新讲一遍。

## 要做符，这么说

```
把 @@太极拳的掤捋挤按@@ 做成一张符。

它解决什么：模型生成太极动作时总是软绵绵的，看不出劲儿在哪。
我有的材料：@@没有，你自己看着办@@ / @@这几张参考图你拿去@@
```

出来是一张 16:9 的图，不是视频。

**加一句更省事**：

```
图上的中文别写错，写错就改着重画。
```

---

## 要用符做片，这么说

```
做第 3 个镜头的时候，挂上我库里那张太极拳的符。

人物、场景、服装都按我给的图来，符只管动作节奏。
```

它会先查库、把命中的符念给你听，挑 0–2 张，然后把符登记成图片资产写进提示词，提交时放最后一位。

**说清用在哪一镜最管用。** 「整条都挂」等于没挂。

---

## 要立谱，这么说

```
这套片子我要统一画风，先立个谱。

故事：@@宗门里一个爱钻空子的小师妹@@
手头有：@@一张氛围图@@ / @@什么都没有@@
一共要出 8 条，一条两分钟
```

它会先出一张世界符给你看，你点头了才往下生人物规范和场景。

**单条片子别立谱**，直接做更快。

---

## 三条后悔药

**分镜不满意**
```
第 3 和第 4 个镜头太平了，换个角度。整体再快一点。
```

**提示词太泛**
```
S02 这条太虚了，写具体点：画面里到底有什么、人在做什么、镜头怎么动。
```

**崩了要重跑**
```
S07 画面崩了，用同样的提示词重跑一条，别改。
```
