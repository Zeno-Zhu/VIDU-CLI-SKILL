# 资产设定板：盘什么、做多少、怎么省

> 本文件只管**资产决策**：谁要做、做几张、哪些不做、什么时候可以省。
> 版式与校验在 `角色设定板模板.md` / `templates/`；字段在 `21-资产清单.md`。
> ⛔ 不再有 BASE、人设卡片、单图、裁图。

---

## 一、为什么是「板」而不是一张随手图

一句话生成几十组视频，最容易出的不是画得丑，是**每组换一张脸、换一个房间**。

设定板把标准钉死：

- 一张板定四件事：长相、服装、空间结构、材质。
- 后面几十组全部引用同一张图。
- 人看图能一眼判断对不对。

单张正面图不够：模型不知道侧脸、后脑、肩线、衣服背面。

---

## 二、哪些要做

| 类型 | 判据 | 数量 |
|---|---|---|
| **角色** | 有正脸、有台词、有连续出场 | 能一张不换装就一张；多状态 ≤3，优先 1–2 |
| **场景** | 同一空间 ≥2 组，或要交代空间关系 | 一个地方一张；功能区进 `subscenes` |
| **道具** | 推动剧情 / 有特写 / 被拿取 | 一个道具一张；随身常用 `bound_to` 到角色 |
| **技能（符）** | 剧情吃某一类能力 | 0–2 张，排最后 |

**哪些不做**：

- 只露一次脸、三五句台词的路人 ⇒ 并进已有角色，或用背影 / 手 / 声音。
- 只出现一次的空镜空间 ⇒ 写进提示词。
- 剧本里没用到的服装 / 状态 ⇒ ⛔ 不做。
- 衣服、发型的小变化 ⇒ 在原板上写清，不重开一张（除非全片第二套主线造型）。

判据只有一条：**后面还会不会再引用它。** 不会再引用，就别做板。

---

## 三、数量与钱

- 十个人物全做全模块，钱花完了，主角那张反而没钱重跑——这是最常见的浪费。
- **省下来的积分，加在主角和主场景上。**
- 一张板只生一次；出完自查就发用户；⛔ 不抽卡、不自己重跑第二版。
- 用户说哪里不像，只改一处再跑一次。

## 四、场景板：只交代必须出现什么

```
场景设定板，[画风]。[地点全称]，[建筑/房间类型]，[面积感与层高]，[年代与地域]。

结构写死：门在[方位]，窗在[方位]，[主家具]在[方位]，
地面[材质]，墙面[材质与颜色]，顶部[结构]。

至少三件事：进门朝[主方向]的主视角（看到主家具与门窗关系）；
对面回看的反打（交代纵深与动线）；[关键操作区]局部近景（材质与磨损）。
再给一张[光源方向]的光线状态：[白天/夜晚/灯光]。

所有画面同一空间：门窗、家具、墙色、地面一致，不得增删大件家具。

排版你自行安排，不用分隔线。

不出现：可读文字招牌（留空或纯色块）；现代穿帮物件；杂志级布景；边框装饰。
[需要比例参考时] 可有一名远景背影，不露正脸；[否则] 不出现人物。
```

- 招牌那句别省：中文招牌模型十有八九写错字——**留白，字后期加**。
- 长度 600 字内。

## 五、道具板：尺寸、材质、结构、磨损

```
道具设定板，棚拍产品感，[画风]。[道具名]，[尺寸感]，[材质]，[主色辅色，写死色相]，
[结构：几段/几部件/接口/磨损位置]，[状态：全新/有使用痕迹/破损]。

至少三件事：整体形态 45° 俯视；正俯视（轮廓与结构）；[关键结构]局部特写
（开关/接口/纹样/刻字，材质颗粒与边缘倒角）。
再给一张使用状态：[打开/合上/握持/点燃/倾倒]，交代与手或另一物件的关系。

所有画面同一件物品：比例、颜色、结构件数量、磨损位置、高光位置一致。

材质写清反光属性（哑光/釉面/金属拉丝/纸质纤维）。

排版你自行安排，不用分隔线。

不出现：可读文字、品牌 Logo、价格标签、多余配件。
```

- 产品要卖：至少三个角度；盒面瓶身不出现可读文字。
- 长度 600 字内。

## 七、出图纪律

```bash
python scripts/vidu.py image \
  --prompt "$(cat "…/_资产提示词/角色-林桂芳.txt")" \
  --name 林桂芳 --out 01_资产库 --ratio 16:9 --tail min
```

- 设定板 16:9；`--tail min`（真人）；带字也别换 `mid`。
- 生图 `normal`（6 积分/张）；⛔ 不蹭闲时。
- 多行提示词用 `--prompt "$(cat 文件)"`；⛔ 不用 `--prompt-file`。
- 出完标 `candidate`；用户点头改 `final`。

---

## 八、出完必须做

1. **一张就够，不许自己重跑。**
2. 标状态：`candidate` / `final`；换版 `name-v2.png`，旧图不删。
3. 自己先看六条：是不是一张板 / 分区在不在 / 文字错没错 / 三视图齐不齐 / 五张脸是不是一个人 / 有没有崩坏。
4. 停下来给用户看，只问一句：「这个人 / 这个空间 / 这个物件，对不对？哪里不像，我改。」
   ⛔ 不问「你觉得怎么样」。

## 九、常见崩坏

| 现象 | 多半是 | 怎么改 |
|---|---|---|
| 左栏空着 / 字段漏 | 必选字段没填全 | 七个字段一个不能空 |
| 五张脸不像一个人 | 视觉规范被改写 | 回模板照抄，一字不改 |
| 板被拆成三四张 | 版式骨架被改写 | 用 `board_build.py` 重新渲染 |
| 三视图缺侧面 / 背面 | 没点名 | 模板固定段已含；别删 |
| 板面冒中文乱字 | 少禁止项 | 加「不出现任何文字、数字、水印」 |
| 场景每张一个样 | 结构没写方位 | 门窗、主家具全部写方位 |
| 服装各图不同 | 只写颜色没写部件 | 补纽扣、口袋、领型、袖长 |
| 真人板像磨皮 | 尾缀错 | `--tail min` |
| 出片飘出设定板 | 缺 C1 禁用句 | P7.5 会注入；确认在 |
| 道具比例怪 | 尺寸感没给 | 写「约成人手掌大小」或给参照物 |

改的时候**只改那一段**，别整篇重写。
