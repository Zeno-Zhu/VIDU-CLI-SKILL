# 角色设定板 · A / B 双版

> 骨架在 `templates/character_board.A.txt` / `templates/character_board.B.txt`，数据在 `templates/character_board.schema.json`。
> 本文件只讲：两版差在哪、字段怎么填、怎么渲染、怎么校验。
> ⛔ 不再有 BASE 基准图、不再有人设卡片、不再有第三份骨架副本。

---

## 一、两版差在哪

| | **A 版** | **B 版** |
|---|---|---|
| 用于 | Vidu Q4 / H3（不上传音频） | 即梦 2.0 / 2.5 / Wan3（上传音频） |
| 声线 | **上板**：「模块2 声线特征」六项 | **不上板**：整段删除 |
| 音色资产 | `音色-<名>.txt`（九维 + 锚点串） | `01_资产库/音色/<名>.wav` |
| 提示词 | 【音色文字锁定】 | `vmN` + 【音色严格规范】 |
| 模块编号 | 1 性格 / 2 声线 / 3 服装 / 4 物品 | 1 性格 / 2 服装 / 3 物品 |

其余骨架、七个必选字段、【必留·人物视觉规范】【风格可自由调整】**完全一致**。

---

## 二、七个必选字段

| 字段 | 写什么 | 例 |
|---|---|---|
| 姓名 | 全名，与剧本一致，≤4 字 | 林桂芳 |
| 外号/小名 | 剧中真被叫过的；没有写「无」，⛔ 不自己编 | 桂芳姐 |
| 年龄 | `N岁` | 58岁 |
| 身高 | `Ncm` | 161cm |
| 体重 | `Nkg` | 56kg |
| 职业/身份 | 身份 + **必须被看见的造型** | 老城区小饭馆老板娘，常年系深色棉布围裙，袖口卷到小臂 |
| 人物定位 | 一句话说清功能 + **不可省的识别特征**（位置写死） | 男主角的母亲，全片唯一的暖色人物；左手虎口有一道浅色烫伤疤 |

**服装、发型、疤、痣塞进后两个字段**，⛔ 不另开字段。
**「人物定位」不是小传**：不写前史、不写剧情走向，只写「功能 + 一眼认出的特征」。

---

## 三、四个可选模块

| 模块 | 留 | 删 |
|---|---|---|
| 1 性格与习惯 | 有连续出场、靠小动作立人 | 路人 |
| 2 声线（仅 A） | 有台词就留 | 哑角 / 群演 |
| 3 替换服装 | 同角色要换装 | 全片一套 |
| 4 随身物品 | 有推动剧情的道具 | 物品不进特写 |

**不用就整段不填**（连标题一起不渲染），不留空栏、不写「无」。
习惯恰好 5 条；替换服装恰好 3 套；随身物品 1–2 件。

## 五、渲染

```bash
python scripts/board_build.py --data "…/角色-林桂芳.json" \
  --out "…/角色-林桂芳.txt"
```

- 只替换 `{{槽位}}`；骨架一字不改。
- 可选模块空 ⇒ 整段不渲染。
- 输出必须在 `00_剧本与提示词/_资产提示词/`，文件名 = 角色名。

---

## 六、校验（十项）

```bash
python scripts/board_check.py --file "…/角色-林桂芳.txt" --variant A \
  --voice-card "…/音色-林桂芳.txt" --style "真人写实都市短剧"
```

| # | 查 | 不过 |
|---|---|---|
| 1 | 七个必选字段齐全非空 | BLOCK |
| 2 | 姓名 ≤4 字；年龄 / 身高 / 体重格式 | BLOCK |
| 3 | A 有模块2 六项；B 整段无声线 | BLOCK |
| 4 | 习惯 5 条；服装 3 套；物品 1–2 件 | BLOCK |
| 5 | 可选模块完整或不存在 | BLOCK |
| 6 | 固定两段逐字 | BLOCK |
| 7 | 无 `<>` / `《》` / 待填 / `XX` | BLOCK |
| 8 | 500–1200 字 | 警告 |
| 9 | A 版基频 = 音色卡第 2 维 | BLOCK |
| 10 | 画风 = 项目统一画风 | BLOCK |

退出码：0 PASS / 2 BLOCK / 1 仅 --strict。

## 七、出片怎么用

**这张板整张就是参考图。**

```bash
--image 01_资产库/林桂芳.png
```

- ⛔ 不截图、不裁切、不照板重出单图。

- 板上出现两张不一样的脸 ⇒ 这张板重做；⛔ 不能裁一张用。
