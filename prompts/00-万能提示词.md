# 万能提示词

填几个空，丢给你的 AI。它会先给你分镜，你点头了它才往下做。

---

## 主提示词（复制这段，改填空）

```
我要做一条视频，你帮我从想法做到能提交。

【我要做什么】
类型：@@漫剧 / 电商带货 / 门店宣传 / 企业形象@@
内容：@@一句话说清楚，比如"社区川菜馆的现炒招牌菜"@@
时长：@@30 秒@@
发在哪：@@抖音 / 视频号 / 小红书@@
我有的素材：@@角色图 / 产品图 / 门店照片 / 什么都没有@@

【你怎么做】
第一步，先给我分镜表，我确认了再往下。
分镜表要有：镜头号、这条几秒、画面里发生什么、有没有人说话。
第二步，我点头之后，每个镜头写一条提示词。
第三步，把提示词提交到 Vidu，盯着进度，好了就下载。

【几条规矩】
- 模型用 Vidu Q4，每条镜头 4-16 秒，别超过 16
- 一条提示词一个镜头，别一条塞好几个镜头
- 提示词写能看见的东西，别写"有氛围感""高级感"这种
- 提交时带 --schedule-mode nopeak，走闲时额度，别花积分
- 同时最多 100 条在跑，多了就排队，跑完一条补一条
- 每条提交完，把镜头号和 task_id 记下来

【我不要什么】
- 不要一次给我一大堆，分两步来
- 别说"让我们一起""深度赋能"这种话
```

---

## 三种场景怎么改

**漫剧 / 短剧**——多给一份剧本，其他不变

```
类型：漫剧
内容：都市悬疑，一集 2 分钟，剧本我发你
时长：120 秒
发在哪：抖音
我有的素材：角色图三张，场景图两张

剧本在下面（贴进来）：
```

漫剧的分镜要比电商细，所以补一句：

```
漫剧的镜头要写出景别、运镜、人物表情和动作起止，因为这决定画面里的人像不像。
```

---

**电商带货**——把产品说清楚，卖点是关键

```
类型：电商带货
内容：智能保温杯，卖点是 12 小时保温、杯盖可拆洗
时长：30 秒
发在哪：抖音
我有的素材：产品图 5 张，白底图 3 张

产品面向上班族，价格 129，想让看完的人点小黄车。
```

电商要补一句：

```
最后一个镜头要留出放价格和购买引导的位置。
```

---

**门店 / 企业宣传**——地址和到店理由是重点

```
类型：门店宣传
内容：社区川菜馆，现炒，人均 45，位置在XX路
时长：30 秒
发在哪：视频号
我有的素材：门头照、菜品照各几张

让附近三公里的人看完想来吃。
```

门店要补一句：

```
尽量别出现清晰人脸，用环境和菜品说话。
```

---

## 三条后悔药

**分镜不满意**
```
第 3 和第 4 个镜头太平了，换个角度。整体再快一点。
```

**提示词太泛**
```
S02 这条太虚了，写具体点：画面里到底有什么、人在做什么、镜头怎么动。
```

**崩了要重跑**
```
S07 画面崩了，用同样的提示词重跑一条，别改。
```
