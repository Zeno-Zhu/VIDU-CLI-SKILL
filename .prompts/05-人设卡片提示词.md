# 任务 C1｜人设卡片（Cast Card · 视觉 ＋ 声音同屏）

> 派发号：`C1`｜一张 16:9 卡片 = 一个角色｜**声音特征直接排在画面上**
> 本文件即「人设卡片提示词」。它跟 `角色设定版提示词.md`（角色设定板）**不是同一件东西**，别混。

## 0. 和「设定板」的分工（必读，否则两套都做废）

| | **人设卡片**（本文件） | **角色设定板**（`角色设定版提示词.md`） |
|---|---|---|
| 给谁看 | **人**：选角、对齐、宣发、团队认人 | **模型**：出片时的参考图 |
| 画面 | 有中文信息区、9 维声音、3 表情、3 物品 | 纯净、无文字、含脸画面最少 |
| 含脸数量 | 6 张（正脸 / 75° / 全身正背 / 3 表情） | ≤2 张 |
| 能不能当出片参考 | ⚠ **不建议整张传**（多脸 + 文字会抢主体） | ✅ 就是干这个的 |
| 花不花积分 | `t2i` 可 0 积分试排；锁脸用 `r2i` 才花 | 同左 |

> ★ **2026-10-03 那条「设定板不上中文参数表、不堆多脸」依然有效 —— 它管的是出片参考板。**
> 人设卡片是另一类资产，**允许上文字、允许多脸**，代价是它不适合直接当参考图。
> 要拿卡片去出片：**先裁出「正面特写」和「全身正面」两张干净图再上传**，⛔ 别整张传。

## 0.1 三条硬约束

1. ★ **卡片上的「声音特征」九维，就是人物音色卡**（`_资产提示词/音色-<角色名>.txt`）—— 同一份，一字不改。
   卡片排版可以压短，但**数字（基频区间）与标签必须完全一致**。九维口径见 `角色设定版提示词.md` 第三十四节。
2. ⛔ **一张卡只画一个角色、一套服装、一个身份阶段**。不混前后期、不混两套衣服。
3. ⛔ **画风跟随项目统一风格**，卡片不另立画风。写实项目＝照片级写实，不上 3D 渲染感、不上插画感。

## 0.2 开工必读

- `角色设定版提示词.md` 第三十四节（九维音色卡）→ 本文件第 3 节（声音区怎么写）
- `references/音色与配音.md`（双通道：闲时锁不住音色，卡就是唯一依据）
- `references/资产设定板.md`（资产怎么盘、哪些角色该做卡）

## 1. 一张卡必须装什么（缺一件就算没做完）

| # | 模块 | 硬要求 |
|---|---|---|
| 1 | **名字** | ≤ 4 字，画面内最大字号 |
| 2 | **外号** | ≤ 4 字，没有就写「无」（⛔ 不许 AI 自己编） |
| 3 | **MBTI 性格** | 4 个字母，蓝色加粗；旁边可接一句性格概括（≤ 12 字） |
| 4 | **角色简介**（可删） | 40—60 字，4 行内；写身份 + 关系 + 行为倾向，不写剧情剧透 |
| 5 | **角色正面特写** | 半身，头顶到胸口，正对镜头，眼睛看镜头 |
| 6 | **75° 脸部特写** | 侧 3/4 脸（约 75°），**超清晰、写实、毛孔与胡渣可见**，同一个人、同光照、同妆造 |
| 7 | **全身正面** | 站直、双脚并拢与肩同宽、含鞋、双手自然垂放或插兜 |
| 8 | **全身背面** | 与正面**同一姿势同一光照**，能看清后领、背部图案、发型后侧 |
| 9 | **自动随机触发的习惯性动作** | 1 个，**必须是小动作**（推眼镜 / 转打火机 / 捋袖口 / 抠指甲 / 摸后颈…），配一张小图 + ≤20 字说明「什么时候会触发」 |
| 10 | **3 个夸张的经典表情** | 等大三张，强制三种不同强度：**惊讶 / 大笑 / 发狠**（可按角色换成 心虚 / 尬笑 / 阴笑 等，但必须一强一弱一怪），每张下方 ≤3 字标签 |
| 11 | **声音特征（声线特征）** | **九维全列，一行一维**：基准音域 / 基频区间 / 虚实占比 / 语速 / 停顿模式 / 重音习惯 / 语调曲线 / 微观质感 / 齿音强度（写法见第 3 节） |
| 12 | **三个贴身物品（含手机壳）** | 必须含**手机壳**；另外两个从随身物里选（项链 / 手串 / 打火机 / 钥匙扣 / 药瓶 / 口红…）。每个一张白底小图 + ≤4 字名称 + ≤12 字说明 |
| 13 | **质量尾缀** | 见第 5 节，**一字不改**贴在提示词最后 |

**允许裁掉**：角色简介、习惯动作、物品减到 2 个 —— 但 1—3、5—8、10、11、12（含手机壳）**不许裁**。

### 1.1 标签用固定词，不许换说法（★ 实测踩过的坑）

生图模型会把「名字」写成「主角色」、把「全身正面/背面」合成「全身形象」。所以提示词里要把标签**点名列出**：

```
名字： / 外号： / MBTI： / 角色简介： /
自动随机触发的习惯性动作： / 三个夸张的经典表情： /
声音特征： / 基准音域： 基频区间： 虚实占比： 语速： 停顿模式：
重音习惯： 语调曲线： 微观质感： 齿音强度： /
三个贴身物品（含手机壳）： / 正面特写 / 75° 脸部特写 / 全身正面 / 全身背面
```

⛔ 不许出现「主角色」「人物档案」「全身形象」「声音设定」这类近义替换 —— 词一换，下游就认不出来这是哪一栏了。

## 2. 画面结构：锁层级，不锁像素

> 排版**交给模型**，只锁「哪块在哪个方位、谁大谁小、文字不许压脸」。⛔ 不写「左上角 120px」。

```
上排
  左：身份区（名字 / 外号 / MBTI / 简介 / 习惯动作）
  中：两张脸（正面特写 ←→ 75° 特写），并排、等高、同一张脸
  右：全身正面 ←→ 全身背面，并排、等高、含鞋

下排
  左中：三个夸张表情（等大三张横排，标签在下方）
  中：声音特征（九行，标签左对齐，值右对齐）
  右下：三个贴身物品（含手机壳，横排，名称 + 一句说明）
```

- 背景：**浅色、接近纯白**（#F2F5FA 一类的冷白），人物区与信息区之间用极浅圆角面板或 1px 细线分隔。⛔ 深色底、渐变霓虹、玻璃拟态、发光边框。
- 三个人物视角（正脸 / 75° / 全身）**必须是同一个人、同一套衣服、同一光源方向**；全身图与特写图的光从同一侧来。
- 文字**只出现在留白区**；⛔ 压脸、压手、压鞋、压在衣服图案上。
- 每个模块上方一行**区块标题**（深灰近黑、小号加粗）；区块之间留白 ≥ 一行字高。

## 3. 声音特征区（这张卡的灵魂，也是唯一必须"抄"的区）

九行，**标签固定、顺序固定、一字不改**：

```
基准音域：
基频区间：
虚实占比：
语速：
停顿模式：
重音习惯：
语调曲线：
微观质感：
齿音强度：
```

**值从音色卡抄**，规则：

- **基频区间**照抄数字与单位（例 `110—220 Hz`，⛔ 不四舍五入、不改区间）
- 其余各维：取音色卡该维的**前半句**（到第一个逗号为止），压到 **≤ 10 字**；⛔ 不重新造句、不换词
- **语速 / 语调曲线**可以各配一个极简示意：语速用一条三段进度条（慢—中—快，标出落点）；语调曲线用一条细折线。⛔ 不做雷达图、饼图、仪表盘
- 九行的字号必须**不小于卡片任何其他小字**（这块要能一眼读懂，不能缩成脚注）

> 为什么这一区不许自由发挥：闲时（nopeak）**无法参考音色**，声线全靠这张卡上的九个维度锁。
> 卡上的字和 txt 里的字一旦不一致，后面每条片子的嗓子就各说各话。

## 4. 文案怎么写（字要可辨，就靠这三条）

1. **短**：名字 ≤4 字、外号 ≤4 字、每维值 ≤10 字、物品名 ≤4 字 + 说明 ≤12 字、习惯动作说明 ≤20 字。
   一行超过 12 个字，生图模型就开始糊字。
2. **层级只分四级**：名字（最大）> 区块标题 > 标签 > 值/说明。不要做五级六级，模型分不清。
3. **字体**：中文用**无衬线黑体**（思源黑体 / 苹方一类的观感），英文与数字同家族；MBTI 与关键值用**低饱和深蓝**点一下，其余黑或深灰。
   ⛔ 书法体、宋体正文、手写体、发光字、描边字、艺术字。

**字糊了怎么办**：卡片的结构只要成立，文字允许**后期重新贴一遍**（在留白区覆盖即可）。
所以提示词优先保**区块结构与留白**，不为了文字清晰牺牲人物清晰度。

## 5. 质量尾缀（一字不改，贴在提示词最后）

```
clean, smooth, ultra sharp, high resolution, 4K, no noise, no grain, no dirty texture, no speckles, no messy details, soft diffused lighting, clean background, crisp edges, color smooth transition, masterpiece, best quality
```

## 5.1 负面要求（贴在尾缀之前）

```
负面：不要拼贴感、不要九宫格等分网格线、不要英文装饰字与水印、不要 Logo、不要乱码文字与错字、
不要把文字压在人物脸部和手部、不要同一张脸画成不同的人、不要年龄漂移、不要让六张脸的五官各画一套、
不要多余路人、不要手部畸形、不要牙齿糊成一排、不要暗调背景、不要发光边框、不要霓虹渐变、
不要 3D 渲染感与塑料皮肤、不要过度磨皮
```

## 6. 两段式生成（同一张脸的唯一可靠办法）

**一次 prompt 画 6 张脸，模型大概率画成 6 个人。** 所以：

| 段 | 干什么 | 通道 | 代价 |
|---|---|---|---|
| **A 脸锚** | 先出一张 **9:16 纯净正面半身**（无文字、白底），挑一张五官最准的当锚 | `t2i` | 0 积分（闲时） |
| **B 卡片** | 以脸锚为**参考图**出 16:9 整卡，提示词开头写「严格参照已提供的角色正面参考图…」 | `r2i` | **花积分**（参考图生图不支持闲时，会 403） |

**省钱做法**：先用 `t2i` 纯文字出一版卡片**只看排版**（0 积分，脸漂不心疼）；
排版定稿后再走 A→B 锁脸。**别一上来就 r2i 烧积分试排版。**

★ **实测（2026-10-26，万集卡）**：`t2i` 纯文字**一轮就能出可用排版**，3 张内收敛，全程 0 积分。
踩过的两个坑都写进本文了：① 标签会被改写成近义词（见 1.1）；② 模块只要没写进【画面描述】，那一栏就不会出现
（`习惯动作` 漏写就整块消失）——**文案表里有的每一项，画面描述里都要再点名一次**。

```bash
# A 段（闲时 0 积分）
python scripts/vidu.py image --prompt-file face_anchor.txt --name 万集_脸锚 --ratio 9:16

# B 段（参考图生图，花积分）
python scripts/vidu.py image --prompt-file card.txt --ref 万集_脸锚.png --name 万集_人设卡 --ratio 16:9 --mode normal
```

## 8. 收尾自检（七问，全过才算做完）

1. 九个声音维度**都在**？标签一字没改？
2. **基频区间的数字**和 `音色-<角色名>.txt` 完全一致？
3. 六张脸是**同一个人**？年龄一致、痣/疤/眼镜一致？
4. 三个表情**强度拉开了**？（一强一弱一怪，不是三个微笑）
5. 手机壳**在**？三个物品都是白底小图 + 一句说明？
6. 文字**没压脸**、字号**不小于脚注**、外层留白够？
7. 质量尾缀与负面要求**原文**贴了？没被自己改写？

机检（能自动查前两项）：

```bash
python scripts/voice_lock_check.py --card "<项目>/00_剧本与提示词/_资产提示词/人设卡-<角色名>.txt" \
        --dir "<项目>/00_剧本与提示词/_资产提示词"
```

## 9. 示例：万集（★ 这条实测过：`t2i` 闲时 0 积分，一次出整卡，13 项全中）

```
&&start
【人设卡片】万集
【画面比例】16:9
【统一风格】真人写实都市短剧；真实材质与自然皮肤质感，柔和漫射光，浅冷白背景，不要 3D 渲染感、不要插画感
【人物身份】三十岁上下，本地市井里混得开的"大总管"，嘴硬心软，团队的气氛担当
【画面结构】上排：左身份区（含习惯动作）｜中两张脸｜右全身正背；下排：左三表情｜中声音特征｜右三物品

【标签词表】画面里必须原样出现下列标签，一个词都不许换，不许改写成"主角色""全身形象""声音设定"这类近义词：
名字： 外号： MBTI： 角色简介： 自动随机触发的习惯性动作： 三个夸张的经典表情：
声音特征： 基准音域： 基频区间： 虚实占比： 语速： 停顿模式： 重音习惯： 语调曲线： 微观质感： 齿音强度：
三个贴身物品（含手机壳）： 正面特写 75° 脸部特写 全身正面 全身背面

【各模块文案】
名字：万集
外号：万叔
MBTI：ESFP｜嘴硬心软的场子核心
角色简介：热情仗义、重情义，爱照顾身边人；外表不拘小节，内心细腻讲义气。
自动随机触发的习惯性动作：推眼镜 —— 思考或观察对方时，会不自觉地推一下眼镜。
三个夸张的经典表情：惊讶／大笑／发狠
声音特征：
基准音域：中低音
基频区间：110—220 Hz
虚实占比：虚 40%—实 60%
语速：稍慢
停顿模式：句中短停，句尾延长
重音习惯：句首 + 关键词重读
语调曲线：中低平稳，尾音微扬
微观质感：温暖，略带沙哑感
齿音强度：中等
三个贴身物品（含手机壳）：手机壳｜黑底金龙图案，磨砂质感；金链子｜粗款金项链，常年佩戴；木质手串｜随身把玩，缓解压力

【画面描述】
浅冷白背景，画面里排布同一个男性的六个视角，全部同一个人、同身材、同一套衣服、同一光照方向。
人物外形：三十岁上下，体格偏壮、肩背厚实，短发往上竖起、发量浓密；黑框方形眼镜；圆脸，下颌有短胡渣；表情松弛。
```
