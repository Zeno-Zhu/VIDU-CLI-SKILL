# 50 · 剪辑决策（轻量版）

> 素材拿到手，先用 5 分钟定方案，再动手。**不要打开剪映才开始想怎么剪。**
> 详细素材路径映射与字幕参数见 `51-素材映射与字幕.md`；剪映自动化 API 见 `jianying-editor/SKILL.md`。

---

## 一、5 分钟定三件事

### 1. 片型

| 片型 | 第一目标 | 默认剪法 |
|---|---|---|
| 叙事短剧 | 讲清事件、保住台词 | **顺剪** |
| 关系 / 反转 | 情绪成立、反应到位 | **情绪剪** |
| 带货 / 口播 | 信息密度、产品可见 | **信息剪** |
| 教程 / 录屏 | 步骤清楚、重点可见 | **信息剪 + 变焦** |
| 混剪 / 卡点 | 节奏与情绪 | **音乐剪** |

### 2. 素材状态

| 状态 | 判据 | 处理 |
|---|---|---|
| **齐** | 每个分镜组都有可用 take | 直接顺剪 |
| **缺** | 少某组 / 某角色 | 用反应镜、细节特写、空镜、B-roll 补；⛔ 不硬拉长 |
| **只有音频** | 有配音 / 台词，没有画面 | 先配画面（素材库 / 生成），再剪 |

### 3. 交付形态

| 要什么 | 产物 |
|---|---|
| 可编辑草稿 | 剪映草稿 + 素材台账 + 决策表 |
| 成片 | 草稿导出 mp4；字幕烧录用 ASS |
| 两者 | 先草稿，校验通过再导出 |

## 二、三种剪法

### A. 顺剪（叙事默认）

- 按分镜组顺序铺，**保台词、保因果**。
- 镜头长度 2–4s；对话镜按字数（3.6 字/秒）；反应镜 1.5–2.5s。
- 删：重复动作、无信息空镜、口头语、长停顿。
- 不删：台词、关键动作、空间关系、情绪落点。
- 每组结尾留一个稳定落点，别在甩镜/虚焦上切。

### B. 情绪剪（关系 / 反转）

- 先保**反应镜**和**停顿**，镜头可以长。
- 峰值前给 0.3–0.5s 静音或空镜，峰值后多留 0.5s 反应。
- 不追求镜头数；追求「谁在看谁、谁先动」。
- 音乐只垫底，不抢台词。

### C. 信息剪（带货 / 口播 / 教程）

- 每 3s 一个信息点；产品特写 ≥1.5s。
- 口播与画面 1:1 对齐；说到什么给什么。
- 字幕要大、要短；关键数字/卖点上屏。
- 教程：点击处加变焦/红圈（`jianying-editor` 的录屏模块）。

### D. 音乐剪（混剪 / 卡点）

- 先定音乐，再按节拍找切点。
- 切点落在鼓点/重音，**不切断台词和人声**。
- 快切段 0.5–1.5s，留 2–3 个长镜做呼吸。

## 三、素材拿到后怎么处理

### 1. 建工作目录

```
<项目>/剪辑/
  素材台账.csv
  剪辑决策表.csv
  字幕.ass
  草稿/            ← 隔离生成，校验后发布
  _废案/           ← 不删，留退路
```

### 2. 扫素材，建台账

一条素材一行：

```
ID,文件名,绝对路径,时长s,宽,高,帧率,总帧数,有音轨
```

- ID = 文件名去扩展名 + 去非法字符；全表唯一。
- **决策表只写 ID + 源内秒，不写路径**；路径只在台账。
- 用 `ffprobe` 读真实时长/分辨率/帧率/音轨；⛔ 不靠文件名猜。

### 3. 统一规格

| 项 | 规矩 |
|---|---|
| 画幅 | 与项目 profile 一致（9:16 / 16:9） |
| 帧率 | 统一；VFR 转 CFR |
| 分辨率 | 统一；不一致的转码或拒绝 |
| 音轨 | 有无音轨要记录；无音轨的不能当同期声 |
| 命名 | `EPxx_Gxx_takeN.mp4`；进台账后不再改名 |

### 4. 粗剪 → 精剪

```
粗剪：按决策表铺 ID + 入出点（不调色、不加字幕）
精剪：字幕 → 音效/BGM → 转场 → 调色 → 导出
```

**先粗剪到能看完整故事，再精剪。** 不要一边铺素材一边调字幕。

## 四、节奏怎么调

### 1. 三条硬尺

| 尺 | 值 |
|---|---|
| 开场 | 3 秒内给冲突 / 利益点 / 异常 |
| 小转折 | 每 15–20 秒一个 |
| 单镜 | 叙事 2–4s；对话 3–6s；反应 1.5–2.5s；产品 1.5–3s |

### 2. 什么时候剪短

- 同一个动作重复三遍 ⇒ 留最好的一遍。
- 人物走路 / 开门 / 坐下没有信息 ⇒ 掐头去尾，留动作落点。
- 空镜超过 3s 且不承担情绪 ⇒ 压到 1.5s 或删。
- 口头语、呼吸、长停顿 ⇒ 删；但**台词字不能删**（R1）。

### 3. 什么时候放长

- 反应镜：观众需要读表情。
- 关键道具：需要看清材质/文字/结构。
- 情绪峰值：留 0.5–1s 呼吸。
- 空间交代：多人走位/新场景第一镜。

**放长用反应镜、细节、环境声，⛔ 不用定格/空镜硬拖。**

### 4. 切点

- 切在动作中段（cut on action），不切在台词字中间。
- 每个片段留 2–4 帧 handles，方便转场/调色。
- 对话反打：先声后人 / 先人后声都可以，但**轴线不跳**。
- 转场只在时间/空间跳跃时用；同场对话不加转场。

## 五、怎么查看画面信息

### 1. 抽帧联系表（最快）

- 每 2 秒抽 1 帧，5 列拼一张；一集 90 秒 ≈ 45 帧 ≈ 9 行。
- 看四件事：构图、景别、穿帮、字幕遮挡。
- 关键段落（峰值/转场/产品）单独抽首帧、末帧、峰值帧。

```bash
# 每 2 秒一帧，缩略图拼 5 列
ffmpeg -i ep01.mp4 -vf "fps=0.5,scale=320:-1,tile=5x9" -frames:v 1 contact.jpg
```

### 2. 技术信息

```bash
ffprobe -v error -show_entries format=duration,size:stream=codec_type,width,height,r_frame_rate -of json ep01.mp4
```

看：时长、分辨率、帧率、音轨、码率。**不看文件名猜规格。**

### 3. 三查一致性

| 查 | 不合格 |
|---|---|
| 人脸 | 同一角色前后不是一张脸 |
| 服装/道具 | 同一场换了衣服、道具位置跳 |
| 空间/轴线 | 门在左变右、两人对话机位跳轴 |

### 4. 声音

- 看波形：有没有削波（顶满）、有没有长静音。
- 听：台词是否被 BGM 压住；环境声是否断。
- 字幕与语音对不齐 ⇒ 回 `51` 的时间分配规则。

## 六、交给剪映模块

### 1. 入口

| 要做什么 | 读 |
|---|---|
| 初始化 / 路径 | `jianying-editor/rules/setup.md` |
| 最小命令 | `jianying-editor/docs/minimal-command-sop.md` |
| Agent 路由 | `jianying-editor/docs/agent-playbook.md` |
| API | `jianying-editor/docs/api.md` |
| 字幕/文本 | `jianying-editor/rules/text.md` |
| 素材 | `jianying-editor/rules/media.md` |
| 导出 | `jianying-editor/rules/core.md` |

### 2. 规矩

- 业务脚本放**项目根目录**，⛔ 不写进 `jianying-editor/`。
- 用 `JY_SKILL_ROOT` 指向模块目录，按 `rules/setup.md` 的 bootstrap 初始化。
- 草稿命名 `AI_` 前缀；先生成在隔离目录，**三道校验过再发布**。
- 只写草稿，不启动剪映。
- 素材池记录 id 必须 = 媒体记录 id。

### 3. 三道校验

1. **写前对台账**：ID 能解析、文件存在、出点 ≤ 时长、规格一致。
2. **写后回读**：媒体记录数 = 引用素材数、路径逐个 exists、主轨首尾相接、总时长对、字幕/音效条数对。
3. **发布后回读**：按剪映重写后的结构查 `speeds` / `common_keyframes`。

详见 `51-素材映射与字幕.md` 第一部分。

## 七、一页检查

```
□ 片型 / 素材状态 / 交付形态 三件事定了
□ 素材台账建了，ID 唯一，路径绝对
□ 决策表只有 ID + 源内秒，没有路径
□ 规格统一（画幅/帧率/分辨率/音轨）
□ 开场 3 秒有钩子；每 15–20 秒有小转折
□ 台词没删；切点不在字中间
□ 抽帧看过：构图 / 穿帮 / 字幕遮挡 / 人脸一致
□ 字幕与语音对齐；CPS 不超
□ 草稿在隔离目录，三道校验过
□ 素材池 id = 媒体记录 id
```
