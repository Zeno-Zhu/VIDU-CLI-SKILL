# 提示词自检表（人工 · L0）

> 机器门见 `40-质检.md`；这张表只管机器判不了的「戏」。
> 改之前先说一句：「你这几条我调整一下，改完告诉你动了什么。」别闷头改。

---

## 十条

### 1. 时长 / 镜数符合 profile

- 组时长 ≤ profile 上限；优先档见 `20-渠道参数.md`。
- 30s 档：所有组 30s；内容是按 30 秒重排的，不是把 15s 组拉长。
- **镜数按节奏，不设硬上限**；单镜 ≥1.2s，≤6s（30s 档可到 8s）。
- 一组 1 镜判错；2–3 镜只告警。
- 超上限 ⇒ 拆组，别硬塞。

### 2. 一镜只讲一件事

看见「然后」「接着」「随即」「镜头一转」就警惕。
一镜两个空间 / 两次转折 ⇒ 模型必糊。拆成两镜，或删次要动作。

### 3. 三件事写清

- 人在哪（空间锚点）
- 朝哪边
- 光从哪来

缺一件，模型每次都重新想象。

### 4. 没有形容词代替画面

| 别写 | 写 |
|---|---|
| 有氛围感 | 灯泡在头顶晃，影子在墙上来回扫 |
| 高级感 | 落地窗外是城市天际线，桌上一台笔电一杯冷咖啡 |
| 很震撼 | 火球从窗口冲出，玻璃向外碎，纸箱被掀翻 |

### 5. 没有模型做不到的事

「镜头穿过玻璃继续推进」「转头同时背景变白天」「手写字幕浮现」「精确口型」⇒ 换硬切。

### 6. 台词没被改

逐字；不润色、不加语气词、不换归属。只能拆句 / 换行。

### 7. 提示词没超 profile 上限

- Vidu / H3 / 即梦 2.0：8000 字。
- 即梦 2.5 / Wan3 30s：不设上限。
- 超了先删：重复句、情绪解释、风格反复强调、模型赞美。
- **别删**：空间关系、动作过程、光线、台词、衔接。

### 8. pn / vm 不是手写的

- 提示词里的【资产盘点】由 `prompt_assemble.py` 注入。
- pn 顺序 = `EPxx_资产绑定.json`；⛔ 不对就重跑绑定，别手改。
- 正文里只写资产名，不写 pn 编号。

### 9. 衔接写清

每镜结束：人在哪、朝哪、手里有什么、下一镜怎么接。
跨组：上一组末镜 = 下一组首镜（同空间、同侧、同光位）。

### 10. 没有不该出现的

真实品牌 / 人名 / 地名（除非用户明确要求）、政治宗教、医疗功效承诺、具体价格。

---

## 怎么说

**别这样**：

> 你的提示词存在表达不够具体的问题，建议优化以提升生成质量。

**这样**：

> 你这条里「画面很有氛围感」模型看不懂，我换成了「灯泡在头顶晃，影子在墙上来回扫」。
> 另外时长写了 22 秒，超过这个渠道的上限，我拆成两组了。

改了哪几处，一条一条说清。用户不同意，改回去。
