# 02｜固定资产

> 源：《无限轮回宇宙·短剧共创 设定》「固定角色与资产继承规则」＋「固定男女主角色与 Base 资产继承规则」（两节合并去重）
> 这是全系列唯一的「不许改」清单。写什么题材都不能动。

---

## 一、五项核心资产

| # | 资产 | 管什么 |
| --- | --- | --- |
| 1 | **万集 BASE** | 男主基础形象 |
| 2 | **苏薇 BASE** | 女主基础形象 |
| 3 | **苏薇音色** | 女主固定声音参考 |
| 4 | **系统形象** | 系统精灵固定视觉 |
| 5 | **系统音色** | 系统精灵固定声音参考 |

万集当前未指定固定音色资产，按具体剧本需求处理。

---

## 二、固定姓名

- **男主：万集**。常用称呼：集哥、万爷。按人物关系、时代背景、剧情场景与对话习惯自然选择，**不强制使用昵称**。
- **女主：苏薇**。姓名固定，其他称呼按剧本中的身份与人物关系自然设定。

**男女主正式姓名不得随题材、世界观、时代背景改变。**

---

## 三、人物设定自由（姓名与 BASE 之外，全部放开）

除固定姓名与视觉 BASE 外，其他人物设定均由当前剧本决定：

- 身份、职业、社会地位、家庭背景
- 性格、行为习惯、能力、目标、人物成长
- 男女主之间的关系、情感发展与冲突
- 不同题材、时代、世界观下的角色定位

**不预设固定人设、固定职业或固定恋爱关系。** 每部剧独立塑造，确保角色符合当前故事需要。

---

## 四、形象继承

万集与苏薇的 BASE 是跨世界、跨剧本的统一人物本体基准。

### 必须保持一致

面部五官、骨相、核心发型标识、基础身材、体型比例、人物辨识度。

### 允许自由调整

服装、发型整理方式、妆容、配饰，以及符合当前剧本时代、职业、身份的造型。

### 生成方式

必须以对应 BASE 为参考进行图生图，在保留人物本体的前提下生成当前剧本所需的正式角色形象。

### ⛔ 禁止重新选角

不得因题材、时代或身份变化而重新设计男女主五官、脸型及基础身材。

男女主在不同世界中的身份、职业、性格、能力与人物关系，由当前剧本独立设定，不受 BASE 造型限制。

### 写剧本时的描述纪律

**不需要重复描述 BASE 已确定的外貌特征。** 只按需补充当前剧情所需的服装、配饰等变化信息；没有特殊需求时可以省略。

> 这条在剧本层的落地：`characters[]` 里 `anchor` 为 `base:*` 的角色，正文与动作描述中不得出现对其五官、脸型、身高体型的重新描写。改写服装、状态、表情、动作都不受限。

---

## 五、系统精灵

系统精灵是全系列统一角色，**形象与音色永久固定**。

- 必须继承既定系统形象，不重新设计、不更换外观。
- 允许根据剧情变化表情、动作、情绪及发光状态（包括已经设定的炸毛等状态）。
- 任何世界篇均使用同一系统精灵形象与系统音色。

---

## 六、音色

| 角色 | 规则 |
| --- | --- |
| **苏薇** | 统一使用「苏薇音色」作为声音参考。允许按剧情调整情绪与表达方式，**不随世界篇更换基础声线** |
| **系统精灵** | 统一使用「系统音色」。允许按剧情调整情绪，**不改变基础声音身份** |
| **万集** | 暂无固定音色资产，按具体剧本处理 |

---

## 七、执行优先级

四层，从高到低：

```
1. 固定姓名（万集 / 苏薇）
2. Hero BASE 视觉基准 ＋ 固定音色资产
3. 当前剧本人物设定（性格、身份、关系、服装设计）
4. 场景临时变化（表情、动作、情绪、状态）
```

**下一层不得覆盖上一层。** 所有剧本创作、角色设定、分镜规划、AI 视频提示词生成与配音环节，统一遵守。

---

## 八、一句话记住

**男女主换身份、换服装、不换人；系统精灵不换形象、不换声音。**

最终目标：让万集和苏薇成为可跨题材、跨时代、跨故事复用的固定主角资产，同时不限制每部剧的创作自由。
