# 分镜组规划

> 本包走这一级：一张表搞定时间结构。镜头要逐镜写死时，在九列表里补齐景别 / 角度 / 运镜即可。

---

## 一、先记死这几个数

| 项 | 值 |
|---|---|
| 单组时长 | **1—16 秒（整数）**，硬上限 **16**；目标 **12—16** |
| 单镜时长 | **≥ 1.2 秒，无例外** |
| 单组镜数 | 2—6，推荐 **3—5** |
| 单组人物 | 核心 ≤4；**有独立音色的发言者 ≤3** |
| 单组素材 | 图 ≤9、音色 ≤3、提示词 ≤2000 字 |
| 台词语速 | 中文含停顿 **3.2—4 字/秒**（按 3.6 估） |

**组是提交单位，分镜是画面单位。** 一条任务 = 一个组 = 组里几个分镜。
超 16 秒提交不了；4 秒一组则组数翻四倍，人物更容易漂。

---

## 二、两种表，按写词方式选

### A. 结构三列（镜头全交给模型时）

```
分镜组ID	时长	原剧本锚点
1_1	14	start:雨夜巷口，他撑伞停在店门前
1_2	12	start:两人对坐，桌上只有一盏灯
```

锚点**逐字摘原文**，10—25 字；首镜 `start:`、末镜 `end:`；单镜组写 `start:… | end:…`。

### B. 基础九列（要写标准提示词时）

```
组号	分镜	时长	景别	角度	运镜	功能	内容	台词
1_1	A1	5	全景	门外平视	机位固定	叙事	雨夜巷口，他撑伞停在店门前	
1_1	A2	4	中景	过肩，店内向外	推	叙事	他推门进来，收伞，水珠甩在地砖上	
1_1	A3	5	近景	柜台侧平视	微推	对白	老板抬头打量他	老板：吃点什么？
```

- **运镜这一列要填满**，固定机位写「机位固定」——不写不等于固定，等于让模型自由发挥
- 功能填：叙事 / 对白 / 反应 / 空镜 / 氛围 / 转场
- 台词逐字不动，只能拆句换行
- **资产不进表**，写词时按 `pn` 编号挂

---

## 三、怎么拆组

**一个组只发生一件事。**

**必须拆的五种：** 场景切换 · 时间跳跃 · 超过 16 秒 · 两条线各说各的 · 有音色的发言人超过 3 个。

**能合就合的两种：** 同场景同批人连续动作 · 一问一答中间没动作插入。

**别按台词句数拆** ——「一句一组」会切出大量 3 秒碎片。

**按容量定档，再在容量内找断点**：不是先按剧情分组再算时长。

---

## 四、组里怎么分时长

```
G01（14 秒）＝ A1 全景交代空间（5s）＋ A2 中景人物进门（4s）＋ A3 近景表情落点（5s）
```

1. **不要平均切**（4.7/4.7/4.7 最难看）
2. **动作多的给长**（推门、拿东西、转身至少 3 秒），纯反应给短
3. **最后一镜留落点**，话没说完别切走

**加起来必须等于组时长。**

---

## 五、台词先算再写

| 组时长 | 大概能装 |
|---|---|
| 12 秒 | 38—48 字 |
| 14 秒 | 45—56 字 |
| 16 秒 | 51—64 字 |

超了：**拆组**（首选）/ 跨镜连说（次选）。
**别靠「语速飞快」硬塞**，模型不会真快，只会把话吞掉。

**这是上限，不是配额。** 靠表演撑的戏，密度 1.5 字/秒也正常。

## 七、表冻结

用户点头后：提示词按组写、镜号与表一一对应；提交时 `--duration` 用表里的组时长；
某组崩了只改这组；**冻结后再改必须告诉用户改了哪几处**。
