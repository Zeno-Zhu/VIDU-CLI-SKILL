# 排错表

> SKILL.md 第十一节的下沉版。**遇到报错先查这张表**，不要凭印象改参数。
> 判断成功与否只看 `state`：`success` / `failed` / `canceled` 才是终态。`ok: true` 也可能是失败。

---

## 一、提交视频时的报错

| 报错 | 改法 |
|---|---|
| `Q4 should not include transition` | 去掉 `--transition`（这个模型不支持转场参数） |
| `Q4 does not support claw_pass` | 改 `--mode nopeak` 或 `--mode normal` |
| `duration ... out of range` | 参考生视频 1–16 秒，图生视频 3–16 秒 |
| `Q4 character2video requires an image...` | 至少给一张图，参考生视频必须有主体 |
| `withaudio & lipsync nopeak mode is not allowed` | 闲时带了参考音频 / 开了 lip_sync。★ **闲时无法参考音色**：删 `--audio`，改用【音色文字锁定】；真要参考音走 `--mode normal`。⚠ **台词照念，别删台词** |
| `Invalid resolution` | 用 1080p |

## 二、生图和做符时的报错

| 报错 / 现象 | 改法 |
|---|---|
| `INVALID_PROMPT_LENGTH` | 提示词超 8000 字（或该账号/模型的实际上限更低）。先砍到 4000 以内；还报就继续压 |
| `Invalid resolution` | 去掉 `--resolution`，用默认 |
| 符上文字糊、错字、繁简混 | 别重画整段。把错的词单独拎出来写「必须逐字准确」，重跑 |
| 符上冒出写实人脸 | `prompt.txt` 补一句「人物仅黑白线稿或剪影，无五官细节、无服装造型」 |
| 面板塞满、字小到看不清 | 不是调字号，是砍内容；还不行就拆两张 |

## 三、看着像报错、其实正常的现象

| 现象 | 说明 |
|---|---|
| 装完 Python 当前窗口找不到 `python` | PATH 没刷新，正常。用绝对路径或重开窗口，见 `references/环境自检.md` |
| 提交流程没报错但一直没结果 | 闲时排队慢，几分钟 `status` 看一次；`ok: true` 不代表成功，看 `state` |
| 符上的中文个别字错 | 生图模型写中文一定会出错字，改 `prompt.txt` 重跑，三次不行就砍内容 |
| 脚本 `[OK]` 说打开了浏览器但没窗口 | 沙箱/远程桌面里子进程被回收，正常。把链接用代码块发给用户，见 SKILL.md 零节第 3 步 |

---

## 四、改完还不过怎么办

1. **先看是不是顺序问题**：资产没定就排镜头、表没审就写词，报错只是表症。
2. **再跑一遍机检**：`storyboard_check.py`（表）、`vidu_check_prompts.py`（词）、`voice_lock_check.py`（音色卡），三道的错都必须改到 0。
3. **还不通就把报错原文贴给用户**，别自己编解释；同时说清你已经试过哪几种改法。
