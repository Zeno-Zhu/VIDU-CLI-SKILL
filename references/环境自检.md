# 环境自检：Python / node / Token 装不上时怎么办

> SKILL.md 第零节的下沉版。**只在环境确实缺东西时才读这一份。**
> 前提不变：**不要让用户点任何文件、敲任何命令**，你自己查、自己装、自己配。

---

## 一、Python

### 1.1 先查

```bash
python --version
```

不行就依次试 `py --version`、`python3 --version`。

### 1.2 一个都没有，你自己装

```bash
# 机器上有 winget 的话，一条命令
winget install -e --id Python.Python.3.12 --accept-source-agreements --accept-package-agreements
```

没有 winget 就下官方安装包静默装：

```bash
curl -L -o "%TEMP%\py-setup.exe" https://www.python.org/ftp/python/3.12.8/python-3.12.8-amd64.exe
"%TEMP%\py-setup.exe" /quiet InstallAllUsers=0 PrependPath=1 Include_pip=1
```

### 1.3 装完当前窗口还是找不到

⚠ 这（PATH 没刷新）是**正常现象**，别让用户重开窗口。直接用绝对路径：

```
%LOCALAPPDATA%\Programs\Python\Python312\python.exe
```

再找不到就去 `C://Program Files\Python312\` 底下翻。

### 1.4 没有 winget 也没有管理员权限

1. 打开 https://www.python.org/downloads/ 让用户下载（**让他自己点，你等他**）。
2. 装的时候必须勾 **Add python.exe to PATH**。
3. 装完用 1.3 的绝对路径跑，别指望当前窗口认到。

## 二、node（只有剧本线要）

**做片子不用 node，只有写剧本用得上**（`script/` 模块，18 以上）：

```bash
node --version
```

没有就 `winget install -e --id OpenJS.NodeJS.LTS`。装完和 Python 一样，当前窗口可能还找不到，用绝对路径跑（通常在 `C:\Program Files\nodejs\node.exe`）。

## 三、Token：一律按 SKILL.md 零节第 3 步的固定路径走

**这里只补脚本层面的坑，流程本身不要在这里另立一套。** 记住三条：

- **默认用户已经买过会员。** 一个字都不要提「购买 / 开通 / 升级 / 要不要开会员」，也不要问「有没有账号」「额度够不够」。档位由 `vidu.py check` 自己读。
- 登录页 `https://www.vidu.cn/my-subscription?bonus-code=LAOZHU` 只是**登录入口**，会自动跳到 `login?redirect=/subscription`。
- **图片发图片本身**（`assets/vidu-token.png`），不是发路径字符串；不要等用户说「找不到」才发。

| 现象 | 处理 |
|---|---|
| `init_env.py --check` 返回 `2` | 还没配 Token，走零节第 3 步的四步固定路径 |
| 脚本说 `[OK]` 但用户没看到窗口 | 沙箱/远程桌面里子进程被回收，正常。**别坚持说已经打开了**，直接把链接用代码块发给他 |
| 想再弹一次登录页 | `python "{skillDir}/scripts/init_env.py" --open-login`（绕过 10 分钟去重） |
| 无人值守 / 批量跑 | `--check --no-browser`，或设 `VIDU_NO_BROWSER=1` |
| Token 贴过来但校验失败 | 确认是 `vda_` 开头、没有多余空格、没被聊天软件折行截断 |

Token 落在 `~/.vidu-cli-skill/token.txt`，**不在 skill 目录里**——skill 目录会被覆盖，那边存不住。

## 四、自检一键过

```bash
python "{skillDir}/scripts/init_env.py" --check
```

| 返回 | 意思 | 你该做什么 |
|---|---|---|
| `0` | 环境齐了 | **直接开工，别再问用户任何环境问题** |
| `2` | 缺 Token | 走第三节；别的（Python、node、权限）一概不问 |
| 其他 | 看它打印的原文 | 按提示补，补完再跑一次 |

## 五、常见环境坑

| 坑 | 说明 |
|---|---|
| 中文路径 / 空格路径 | `"{skillDir}/scripts/…"` 已经带引号，用户项目路径也要加引号 |
| 项目建在 C 盘被拒 | 脚本默认不落 C 盘。素材几个 G 起步，换盘；确实只有 C 盘才加 `--allow-c` |
| 多版本 Python 抢 PATH | 优先用 `py -3.12`，或直接用 1.3 的绝对路径 |
| 公司电脑禁 winget | 走 1.4，别硬装 |
