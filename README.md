# vidu-skill · 一句话做视频

用一句话，做出一条能发的视频。

不是让你学剪辑，不是让你研究模型参数。你说清楚要什么，AI 帮你拆镜头、写提示词、提交、收片。

---

## 能做什么

**写剧本**
手上连本子都没有，也能开工。默认按「无限轮回宇宙」写——主角在无数平行世界里轮回，每一世换一个身份、拍成一部独立的戏。
从世界篇、全剧大纲到逐集台词，出来是一份打开就能用的 Word。17 道大纲门 + 12 道剧本门，脚本硬校验，不靠模型自觉。
写完直接往下做片子，本子不用再转一道格式。

**做短剧**
有剧本就能开工。都市、悬疑、玄幻、动漫，都行。
一集两分钟，一天能做几集。

**资产不会挂错**：分镜组表只写「这一组用谁」（出场资产列），pn 编号由脚本按「角色→场景→道具→符」算好并冻结；
提示词里的【资产盘点】、作业单里的图片顺序，全部从绑定表派生。人和图错位 → 成片换脸，这条链上不允许手写 pn。

**卖货**
保温杯、护肤品、小家电、衣服。
一条 30 秒，说清卖点，能直接投。

**开店 / 本地生活**
餐馆、理发店、健身房、汽修。
拍门头、拍手艺、拍人气，让三公里内的人走过来。

**企业宣传**
厂房、设备、团队、服务能力。
不用请摄制组，也不用租场地。

**音色怎么定**

两条通道，别搞混（★ 2026-10-26 实测）：

- **默认闲时（0 积分）**：平台**照样用原生配音逐句念台词**，声线靠一份「人物音色卡」钉死——音域、基频、虚实比、语速、停顿、重音、语调、质感、齿音，九个维度＋一行锚点串，随提示词一起交，全片一个声。⛔ 这条通道**参考不了你的样音**。
- **要真用你的样音**：走 `--mode normal`（花积分）。丢一段 4–5 秒样音进去，片子里的台词就是这个声线；一组最多三个有独立音色的角色。

**⚠ 别读反**：「不能参考音色」不等于「没有声音」。台词一直都由平台念，删的只是"这是谁的声音"。

## 它是怎么做的

不是上来就写提示词。五步，一步都不省。

**零、先有本子**

手上没有，它先写。一集 60–90 秒，标准 △ 格式——场次、动作、台词分得清清楚楚，分镜能直接照着排。

已经有本子，跳过这步，把本子贴给它就行。

**一、先盘资产**

人物、场景、道具，就三类。缺的按**设定板**生——一张板定下长相、服装、空间结构、材质，后面几十组都引用它，才不换脸、不换屋。

**角色板是固定版式**：左边档案栏（姓名、外号、年龄、身高、体重、职业身份、人物定位），右上人物展示区（正面/侧面/背面三视图＋正脸、75° 侧脸、3–4 张表情特写），右下细节特写区（皮肤、面料、服饰）。骨架不许改，四个可选模块（性格习惯 / 声线 / 替换服装 / 随身物品）不用就整段删掉。

**这张板就是出片参考图**，整张上传：不截图、不裁切、也不再照板另出一张单图。板上有多视角和文字，用提示词里一句禁用句压住就行。

**一张图出完就发你审，不合意再改一处。** 不抽卡、不偷偷重跑。

场景和道具的板**不规定排版**，只写清必须出现哪些角度和细节，怎么排让模型自己看着办。

**二、再排分镜组**

平台一次最多 16 秒，所以**一条任务 = 一个组**，组里装好几个分镜。

**优先落到 12–16 秒**（一次提交不管几秒都只扣一次额度，装满是省钱），**单个分镜不低于 1.2 秒**。低于 12 秒也行，但一集最多一两组。

一组**优先装 4–8 个分镜，不设死线**——依据内容定，别为凑数硬拆，也别为省事合并。

每个分镜要写齐四样：**景别、角度、运镜、站位**。固定机位也得写「机位固定」——不写，模型就自己发挥。站位写谁在画左/画右、朝哪、机位在轴线哪侧；写完先做**站位预演**（不挡不叠、不跳轴、上下组接得上），再往下写词。

**三、审一轮，改一轮**

表出来先过一遍机器体检：有没有超时、有没有碎镜、空镜和纯情绪是不是太多、景别和机位是不是一路平到底。

再自己看六件事——上下组搭不搭、为剪辑留没留余地、景别衔接顺不顺、运镜合不合理、角度合不合理、该不该加反应镜。改一轮，改完的才是终版表。

**四、最后才写提示词**

照表写，一镜一段。表里几镜就几镜，不许偷偷加镜、改时长。

**为什么绕这一圈？** 因为返工最贵的不是写词，是几十组出完才发现人物换了脸、节奏全拖。

## 片子存在哪

一条 30 秒的片子，图加视频也有几个 G。**别放 C 盘。**

开工第一句：

```bash
python "{skillDir}/scripts/asset_init.py" 我的项目
```

它会挑一个非系统盘（E 盘、D 盘，哪个有就用哪个），把整棵树建好：

```
我的项目/
├─ 00_剧本与提示词/   剧本、每个资产的提示词、分镜组表、你自己的模板
├─ 01_资产库/         人物、场景、道具、音色，平铺，文件名就是资产名
├─ 02_分集工程/       EP01…EP16/视频
├─ 03_背景音乐/
└─ 04_最终交付/       成片、创作截图
```

想放别处：加 `--root "D:/AI视频项目"`。

**真要放 C 盘，脚本会先拦你一次**，告诉你还能放哪；确认要建再加 `--allow-c`。

资产库平铺、不分子目录，是故意的：写提示词时路径短，错一次就换脸，路径越短越不容易错。

## 符和谱：想用再用，不用也照样出片

**先说符是什么。** 一张符 = 一类 AI 视频能力的知识浓缩，载体是图。
本来要几千字讲清的经验、要点、禁忌，压成一张 16:9 的图。模型读图比读长文本准——不会被截断，不会抓错重点。
所以符就是「AI 视频的 skill」，只不过 skill 装在文字里，符装在图里。

**符不是另一条路，是做片子时的一个选项。**

- 不挂符 → 正常写提示词，该写多少字写多少字
- 挂符 → 把其中「讲道理」的那部分，换成一张图 + 一句调用指令

开关在**写提示词那一步**拨，前面读剧本、盘资产不变，后面提交、下载也不变。

**做符**
把一套本事压成一张图。太极拳怎么打、镜头怎么推、赛博朋克世界长什么样——你讲得清，它就能封成一张 16:9 的能力卡。做过的符自动进库，攒到十几张就是你自己的招式谱。

**立谱**
一整套片子要一个调，先出一张世界符定下画风，后面所有人物和场景都从它长出来。单条片子不用立，浪费时间。

**这三件不做，也照样能出片。** 你不提，它不会推销。

## 怎么用：做片子

### 1. 说你要做什么

打开对话框，说一句话就行：

- 「我还没本子，帮我写一集，主角这世是个物业经理」→ 走剧本线
- 「我要做一集都市悬疑的短剧，剧本在这……」→ 走漫剧线
- 「我做保温杯，想拍条带货视频发抖音」→ 走商业线
- 「我开了家川菜馆，想拍条视频让附近的人来吃」→ 走商业线
- 「给太极拳做个符，掤捋挤按那四个劲儿我总是说不明白」→ 走符创作

AI 会一个一个问你剩下的问题。**一次只问一件**，你答完再问下一件。

### 不想聊？可以让它自己干

有些人只想赶紧拿到片子，不想来回讨论。可以这么跟它说：

- 「你全做完给我看，别中间问我」→ 它一路做到底，交片时告诉你哪里可能不合意
- 「资产、脚本、提示词这三处停一下」→ 三个关键节点给你看，其余自己决定
- 「每一步都问我」→ 慢慢来
- 「第 2 步和第 4 步停，其他别问」→ 你自己点名

**没说就默认第二种。** 中间有三次点头的机会，既能纠偏，又不至于被问烦。

就算开了全自动，**资产图那一步它也会给你看一眼**——图不对，后面几十条全白做，重做比看图贵得多。

### 2. 看分镜，点头

它先给你一张分镜表：第几个镜头、多长、画面发生什么、有没有人说话。

不满意就改，改到满意为止。**这一步最省钱**——分镜错了，后面全白做。

你点头之后，它才写提示词、提交、收片。

## 想用符、想立谱，怎么开口

**做符和立谱是另外造东西，用符是做片子时拨的一个开关。** 三件都不做也能正常出片，你不提，它不会主动问。

### 做符：说个名字就行

- 「把太极拳做成符」
- 「来一张运镜的符，一镜到底那种推轨」
- 「赛博朋克的世界观，做成符」

它干两件事：先把这套本事拆成能照着做的规则，再画成一张 16:9 的图。

**它会先问你一句**：这东西解决什么问题、模型现在做不好什么。一句就够，剩下它自己办。

出来就是一张图，存在 `out/符/` 下。图上的中文字要是错了，它会自己改着重画——最多三次。三次还错，说明这张符塞的东西太多，它会砍成两张。

**做符花的是积分，不占闲时额度。** 让它先查一下余额。

### 用符：让它挂进提示词

每做一张符，它自动登记一条：叫什么、管什么、什么时候该调。以后你可以直接说：

- 「我库里有什么符？」
- 「用那张太极拳的符，做第 3 个镜头」
- 「有没有讲推镜的符？」

它会做四件事：查库 → 挑 0–2 张 → 把符写进提示词 → 提交时当最后一张参考图。

**写进提示词是关键那步。** 符会变成提示词里的一段：

```
【技能调用】
pn4,符-太极拳=@
调用指令：写打斗、教学、慢动作镜头时调用，结合当前人物与场景执行，不复制面板示意。
```

正文里再点名用在哪：「运镜按 [@符-太极拳] 的重心转移节奏」。这样模型既拿到图，也知道什么时候该照着做。

**没有合适的符就别挂。** 挂错比不挂更糟，会污染构图。

### 立谱：一整套片子一个调

一个项目要出好几条片子、或者分好几集，就跟它说「统一画风」或「立个谱」。

它先出一张**世界符**——16:9，左边视觉规范（画风、色彩比例、材质），右边世界规则（规矩、冲突、口号）。这张定了，后面的人物规范、空间规范、场景主视全都挂它往下生。

大约 8–15 张图。**花的是积分，不占闲时额度**，开工前让它先查余额。

单条片子别立谱，直接做更快。

## 要花多少钱

**闲时不花积分，能跑多少看你账号是哪一档：**

| 档位 | 每天闲时额度 | 一集 6 组，一天能跑 |
|---|---|---|
| **专业版** | **20 条** | 3 集 |
| **旗舰版** | **200 条** | 30 集左右 |

开工第一件事，它会先查你是哪一档，然后按额度排片。

**默认只走闲时，不扣积分。** 要走积分（比如想一次出带声音的），得你自己开口，它不会替你做主。

生图（资产板、符、世界符）不走闲时，扣积分。开工前它会先查余额，告诉你大概花多少。

---

## 三条要知道的事

**① 提交时必须写 `nopeak`**

```
--mode nopeak
```

本包 CLI 默认就是闲时（0 积分），显式写是为了不漏；要花积分必须自己写 `--mode normal`。

**② 额度按档位算，别看别人跑多少**

专业版一天 20 条，一集 6 组，三集封顶；旗舰版一天 200 条，能跑三十集。
**超额交会直接失败**，不是排队，是白等。它开工前会告诉你能跑几集。

**③ 闲时没有声音**

画面走闲时，声音单独做，最后在剪辑软件里合。想要一次出带声音的，得花积分。

## 出片要多久

40 条 15 秒的镜头，大概一个小时陆续出来。

不用坐着等。交上去就去干别的，出来一条看一条。

## 常见问题

**画面里人变了样？**
每组开头要写清「人在哪、朝哪边、光从哪来」。这三件不写，模型每次都重新想象。

**人物脸糊了？**
景别太远。想看清脸就用近景。

**崩了怎么办？**
重跑。8 分钱的事，别纠结。便宜的好处就是能多试几次。

**提示词不会写？**
不用你会。你把想拍的说清楚，AI 写。写出来太虚，让它改具体。

**能保证不崩吗？**
不能。便宜换来的就是偶尔崩。关键镜头想稳，用贵一点的平台，剩下九成用这个。
