# 分镜组审核

> 本包的审核 = 机器体检 + 人工四看 + 只改一轮。
> 镜头语言与跨组连续性，用 `references/分镜组规划.md` 的九列表逐项人工核。

---

## 一、跑机器体检

```bash
python scripts/storyboard_check.py "…/EP01_分镜组.tsv" --json "…/EP01/_体检.json"
```

**错误必须改到 0，才允许往下写提示词。**

| 错误 | 判据 |
|---|---|
| 组超长 | 组时长 > **16s** |
| 组太短 | < **6s**（6—12s 只警告） |
| 分镜太碎 | 单镜 < **1.2s** |
| 镜数不够 | 一组 < 2 镜 |

**警告值得看一眼：** 镜数 >6 · 空镜+氛围单组 >40% / 全片 >25% · 单个无水词氛围镜 >4.5s ·
连续 3 镜同景别 / 同机位 / 同运镜 · 全片单一景别 >55% · 台词字数 > 组时长 ×4 · 运镜空着。

**同一类警告每组都出现** ⇒ 不是单组问题，是拆组问题，回上游改。

## 二、自己再看四件事

### ① 空镜是不是太多

连着三个雨滴、灯笼、水面，就是 MV 不是剧。每隔一两个对白镜就插空镜 ⇒ 砍掉一半。

### ② 表演是不是空白

**站在那里、没动作、没台词、镜头看着他** = 表演空白。
典型：`功能=氛围`、`台词=空`、4 秒以上、内容写「他沉默着，眼神复杂」。
模型演不出「眼神复杂」，只会给一张呆脸。**必须给落点**：手指缩了一下、喉结动了、把杯子推开。

### ③ 纯情绪是不是拖太长

一个情绪镜超过 4 秒，观众开始走神。压到 3 秒内，或拆成「动作 + 反应」两镜。

### ④ 角度合不合理

- **跳轴**：两人对话都在同一侧，观众以为他们没面对面
- **一个机位拍到底**：三四个镜都是平视正面同高度，像监控录像
- **角度和情绪不配**：吵架用俯拍显得可怜，告别用平视显得平淡
- **越轴运动**：从左往右走，下一镜变成从右往左

**判据**：一组至少两种景别、两种机位；对话戏两人各占一侧。

## 三、只改一轮

| 能改 | 不能改 |
|---|---|
| 时长、镜数、景别、机位、运镜 | 台词的字（只能拆句） |
| 空镜换成反应镜/动作镜 | 剧情事实、人物关系 |
| 补动作落点、删多余镜 | 用户确认过的资产 |
| 组边界（拆组/并组） | 组号 |

**改完再跑一遍体检**，错误回到 0。

## 四、交表时说什么

只说两样：**终版表** + **动了哪几处**（3—5 条，一句话一条）。

> 表改好了，动了四处：
> - G03 原来 18 秒，拆成 G03 / G04
> - G07 三个空镜砍成两个，第二个换成老板抬眼的反应
> - G11 结尾 5 秒沉默压到 3 秒，加了把茶杯推开的动作
> - G12 两个对话镜原来都在左侧，右边那个改成过肩反打

**不要说**「我按六个维度评分」「综合得分 82」。用户只关心表能不能用。
