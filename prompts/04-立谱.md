# 立谱：先定这套片子长什么样

一句话：**先出一张世界符，后面所有图都从它长出来。**

不立谱的后果是画风一层层漂——第一集的小饭馆是冷蓝写实，第三集变成暖黄糖水，观众认不出是一部片子。

---

## 什么时候立谱

| 情况 | 立不立 |
|---|---|
| 用户说「统一画风」「做个设定集」「立个谱」「这套片子要一个调」 | **立** |
| 一个项目要出 5 条以上片子，或者分好几集 | **立** |
| 单条卖货片、单条宣传片 | **不立**，直接走主线更快 |
| 用户已经有一批定稿的设定图 | **不立**，直接拿他那批当参考 |

**立谱是前置，不是第三条线。** 谱立完就回漫剧线或商业线，盘资产时直接挂这些图，不用重画。

---

## 四层，不是十二层

```
1. 收种     → 一张图 + 一段文字
2. 世界符   → 16:9，左边 VIS 视觉规范，右边 CIS 世界规则     ［停点·谱］
3. 人物规范 → 一张造型总纲
4. 空间规范 → 一张：体量、材质、光线
5. 场景主视 → 每个主要场景一张主视角
6. 回主线   → 盘资产时直接挂
```

**为什么砍到四层。** 同类方法在长剧集和游戏项目里要跑到十二层（群像、关卡总览、3D 简模拍六机位、六宫格细化、场景扩展……）。那些服务的是一季几十集、需要精确机位复用的生产。短剧和卖货片跑一套几十张图，钱和时间都白花，还用不上。

**什么时候该加层。** 用户明确要做长剧集、或者同一场景要反复从不同角度拍，再往上加。加之前先算一下：加一层就是十几张图。

---

## 第一步：收种

要两样，**各一样就够开工**：

| 他给的 | 你做什么 |
|---|---|
| 一张图 + 一段文字 | 直接开始，这是最好的开局 |
| 只有一段文字 | 先帮他画一张开局图，让他确认调子 |
| 只有一张图 | 问一句：这张图里，你最想保住的是哪一件事？ |
| 什么都没有 | 问：这故事大概讲什么？发生在什么地方？ |

**图不是必须多好看，但必须有"生命力"。** 一张氛围图、一张随手涂鸦都行——它是这个世界的第一份参考，后面所有东西都从它长。

**只问一句，别问设定。** 世界观、派系、历史这些，他不说你就先不定。定了反而要改。

---

## 第二步：世界符（唯一停点）

一张 16:9 的图，一图平铺两栏：

```
┌─────────────────────┬─────────────────────┐
│  VIS 视觉规范        │  CIS 世界规则        │
│                     │                     │
│  统一风格前缀        │  世界规则            │
│  色彩比例（带百分比） │  能力来源            │
│  字体与材质          │  核心冲突            │
│  构图规范            │  SLOGAN             │
└─────────────────────┴─────────────────────┘
```

**VIS 写什么**（决定"看着像什么"）：

- 统一风格前缀：一句话，比如「真人古偶质感，木石真实，冷调」
- 色彩比例：写百分比，别只写颜色名。`烟霞蓝 30 · 黛青灰 22 · 贝母白 20 · 柔金 8`
- 字体与材质：招牌、织物、石木各自什么质感
- 构图：主体放哪、留白多少、机位高低

**CIS 写什么**（决定"是什么世界"）：

- 世界规则：一句话讲清这地方的规矩
- 能力来源：力量 / 产品 / 服务从哪来
- 核心冲突：故事靠什么撑
- SLOGAN：一句能反复用的口号

### 命令

**世界符不用 `card`，用 `image`。** `card` 是给符用的——它会强制加「符-」前缀、默认写进符库。世界符是项目资产，不是可复用的技能卡，两回事。

**先把提示词写成文件**（`image` 不会自动帮你存 prompt.txt，得你自己写）：

```bash
mkdir -p out/谱/世界符
# 把世界符的提示词写进 out/谱/世界符/prompt.txt，再跑下面这条

# 16:9，风格化，用默认 full 尾缀
python scripts/vidu.py image \
  --prompt-file out/谱/世界符/prompt.txt \
  --name 世界符-符宗 \
  --out out/谱/世界符 \
  --ratio 16:9
```

出图存 `out/谱/世界符/世界符-符宗.png`。

### 验收

| 看什么 | 不行就 |
|---|---|
| 色彩比例写的是百分比，不是形容词 | 补上数字 |
| SLOGAN 一句话能记住 | 砍到 12 字内 |
| 字都能看清 | 砍内容，别调字号；还不行用 `--resolution 2k` |
| 没有具体人物正脸 | 世界符是规范图，不是海报 |

**这一步必须停下来给用户看。** 世界符定错，后面每一张都跟着错。改一次比改二十张便宜。

## 第三步：人物规范

一张造型总纲，管"这群人怎么穿、什么骨架、什么材质"。

写什么：

- **骨相基准**：脸型、体型的共性范围
- **服装体系**：按身份分层，一两句一层
- **材质基准**：布料、皮革、金属各自的质感
- **派系对比**：两个阵营看着哪里不一样
- **不能做的**：明确写死几条禁区（比如"不出现现代拉链"）

```bash
python scripts/vidu.py image \
  --prompt-file out/谱/人物规范/prompt.txt \
  --name 人物规范 \
  --out out/谱/人物规范 \
  --ref out/谱/世界符/世界符-符宗.png \
  --ratio 16:9
```

**必须挂世界符当参考图**（`--ref`）。不挂，人物规范和世界符就是两张互不相干的图。

---

## 第四步：空间规范

一张，管"这地方有多高多大、用什么材料、光从哪来"。

写什么：

- **体量基准**：层高、开间、进深，用参照物说（"门高是人的一倍半"）
- **材质基准**：墙、地、梁、窗各是什么
- **光线基准**：主光方向、色温、明暗比
- **色调**：跟 VIS 的色彩比例对齐

```bash
python scripts/vidu.py image \
  --prompt-file out/谱/空间规范/prompt.txt \
  --name 空间规范 \
  --out out/谱/空间规范 \
  --ref out/谱/世界符/世界符-符宗.png \
  --ratio 16:9
```

同样挂世界符。

---

## 第五步：场景主视

每个主要场景一张主视角，**一张就够，不要六宫格**。

```bash
python scripts/vidu.py image \
  --prompt-file out/谱/场景/prompt-饭馆.txt \
  --name 场景-饭馆 \
  --out out/谱/场景 \
  --ref out/谱/空间规范/空间规范.png \
  --ref out/谱/世界符/世界符-符宗.png \
  --ratio 16:9
```

**两张参考一起挂**：空间规范管结构，世界符管调子。

主视角要写清空间结构——门在哪、窗在哪、主要家具位置。因为这些图后面要当参考图用，写站位全靠它。

**后期要加角度再加。** 用户说"这个院子我要从西边再看一眼"，再单出一张，挂主视角当参考。别一上来就拍六个机位。

```
out/谱/

    世界符-符宗.png
    prompt.txt
  人物规范/
    人物规范.png
    prompt.txt
  空间规范/
    空间规范.png
    prompt.txt
  场景/
    场景-饭馆.png
    prompt.txt
```

**每张图旁边留一份 prompt.txt。** 改图就改它，别凭记忆重写——重写的和原来那张必然不一样。

---

## 三条规矩

1. **一层只挂它上游那一层。** 场景主视挂空间规范，不直接挂世界符（除非结构简单）。跳层挂，画风会打架。
2. **换版不删旧图。** 用户要改，新图叫 `xxx-v2.png`，旧的留着。哪天他说"还是上一版好"，你还有得退。
3. **立完谱就回主线。** 别在立谱里顺手把片子也做了。谱是资产，片是片，两件事分开交付。

---

## 成本

一次完整立谱大约 8–15 张图（世界符 1、人物规范 1、空间规范 1、场景主视 5–10）。

**生图走积分，不走闲时额度。** 开工前 `check` 看一眼。积分不够就先只出世界符，让用户确认方向，别一口气跑完。

---

## 跟「符」的区别（别混）

|  | 世界符 | 符 |
|---|---|---|
| 管什么 | 这套片子**长什么样** | 这类动作**怎么做** |
| 数量 | 一个项目一张 | 可以攒很多张 |
| 归谁 | 项目资产，存 `out/谱/` | 可复用技能，存 `out/符/` + 符库 |
| 用命令 | `image --ratio 16:9` | `card` |
| 什么时候用 | 开工前 | 写提示词时挂参考图 |

用户说「做个世界符」和说「做个符」，是两件事，别听混。
