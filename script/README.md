# 无限轮回宇宙 · 短剧剧本

一套给「无限轮回宇宙」写短剧剧本的流程：**从一句脑洞到一份可以直接开拍的 Word 剧本。**

不管你要写都市喜剧、玄幻、动物世界还是反派视角，这一套流程都能用——变的只是皮，
不变的是母宇宙的三层结构、万集和苏薇这两张脸，以及短剧那 75 秒的硬容量。

> 这个模块已经内置在「一句话做视频」里，**不用单独安装**。跟 AI 说一句「写个剧本」就会走到这里。

---

## 它解决什么

| 常见问题 | 这个 skill 怎么处理 |
| --- | --- |
| 写着写着超出时长，到生成环节才发现 | 台词按 4.5 字/秒、动作按 2.5 秒/拍**确定性折算**，超出当场拦下 |
| 大纲说这一集有大爆点，剧本里改着改着就没了 | 爽点认领，机器逐集核对 |
| 每个世界篇的男主都长得不一样 | 锚点唯一性门：万集恰好 1 个、苏薇最多 1 个 |
| 上一集还活着的人，下一集突然开口 | 角色/场景/道具三道对账门 |
| 台词像散文，喂不进 TTS | 台词是结构化数据（说话人 + 内容 + 表演提示），动作单独成拍 |
| 写完了还要手工排版 | 直接生成 `.docx`，1.5 倍行距、首行缩进、A4，打开就能用 |

## 怎么开始

在对话里说一句：

> 这次万集变成一头猪，我想做个荒诞喜剧，6 集

然后按 A → B → C → D 走：

```
A 世界篇初始化   产出 world.json + 初始化设定（十项）
B 全剧大纲       产出 outline.json（17 道质量门）
C 逐集剧本       产出 script.json（12 道质量门）
D 交付           产出 剧名-剧本.docx  ← 你拿到的东西
```

**每个阶段之间都停一次**，等你确认。不会一口气写完全剧。

## 核心概念：母宇宙固定，世界篇开放

- **固定的**：世界意志的动机（想离开，又怕母宇宙崩掉，所以要培养继承者）、六条轮回规则、万集和苏薇这两张脸、系统精灵的形象与音色、灵魂锚点。
- **自由的**：题材、时代、主角这一世是什么、反派是谁、局部世界规则、故事结构、结局形式。

一句话：**固定母宇宙，开放平行世界；固定核心灵魂，开放万千人生。**

所以你可以写万集当皇帝、当猪、当物业经理、当反派的爹——都是同一个人。

## 单集为什么是 75 秒

默认口径（可按项目覆盖）：

| 项 | 默认值 |
| --- | --- |
| 单集时长 | 75 秒（±15%，即 63.75–86.25 秒） |
| 台词折算 | 4.5 字/秒（标点算时间） |
| 动作折算 | 2.5 秒/拍 |
| 单句台词 | ≤ 35 字 |
| 钩子位置 | 全集前 4 拍内 |

75 秒的容量是 **22 拍左右**（13 句台词 + 9 拍动作）。别拿三分钟的写法来套——那是 50 拍。

> 这个 4.5 字/秒是**剧本侧**的折算口径，用来卡剧本容量。真正配音的语速是 3.2–4 字/秒，
> 两边换算见 `../references/剧本到分镜的交接.md`。

## 质量门是真的会拦

不是清单，是代码。每道门都有一个「故意写违规 → 确认被拦」的自测用例：

```bash
# 在包的根目录下跑
node script/scripts/selftest.mjs
# ✓ 全部 80 项断言通过（不调模型、不花额度）
```

**大纲 17 门**，含三道母设门：锚点唯一性、核心商品认领、主线边界。
**剧本 12 门**，含时长、字数、说话人、钩子位置、动作体、三道对账。
