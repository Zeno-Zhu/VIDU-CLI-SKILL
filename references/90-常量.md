# 90 · 逐字常量

> 这些句子**一字不许改**。写提示词、写设定板、写作业单时从这里复制；
> 脚本里的同名常量也必须与本文件逐字一致。
> ⛔ 不许在别处另抄一份再改字。

---

## C1 参考图禁用句（每条分镜提示词必带）

```
参考图仅用于人物长相、发型与服装 / 空间结构与材质，画面中不得出现多视角拼贴、画中画、分格线、文字标注与色卡。
```

用于：角色板 / 场景板 / 道具板整张当参考图时。
⛔ 缺这句，画面里会飘出一张定妆档案。

---

## C2 强制声明（每个分镜组必带）

```
【强制声明】无背景音乐；画面无字幕/台词文字/水印/Logo/角标/UI；声音：不要配乐，仅保留同期声；全程无背景音乐，仅保留真实环境音效与动作同期声。
```

---

## C3 音色文字锁定（A 版渠道：无音频参考）

```
【音色文字锁定】
本组无参考音频，音色以下列设定为准，同一角色全片同一份，禁止改写或另立声线。
<角色名>：<音色卡锚点串，逐字照抄，≤40 字>
```

一个发言角色一行；不入镜、不说话的不列。

---

## C4 音色严格规范（B 版渠道：上传音频参考）

```
【音色严格规范】
严格匹配各角色专属参考音色，一角色对应一份参考音；全程锁定原始音色基底，禁止修改音色参数、拼接融合或生成陌生新音色。
```

同时在【资产盘点】写 `人物音色资产：vm1,<名>音色=@`。

---

## C5 台词绑定头（每句台词必带）

```
<保持<角色名>的音色不变，……>
```

括号内只写声音表现 + 必须与发声同步的少量画面表现。
⛔ 不写外貌、服装、景别、运镜。

---

## C6 命名

| 对象 | 规则 | 例 |
|---|---|---|
| 资产名 | 剧内语义名，全表唯一；= 文件名去后缀 | `林桂芳` |
| 图片 | `01_资产库/<资产名>.png`（扁平） | `01_资产库/林桂芳.png` |
| 音色 | `01_资产库/音色/<资产名>.wav` | `01_资产库/音色/林桂芳.wav` |
| 音色卡 | `00_剧本与提示词/_资产提示词/音色-<资产名>.txt` | `音色-林桂芳.txt` |
| 角色板数据 | `.../角色-<资产名>.json` | `角色-林桂芳.json` |
| 角色板提示词 | `.../角色-<资产名>.txt` | `角色-林桂芳.txt` |
| 分镜组 | `EP%02d_分镜组.tsv` | `EP01_分镜组.tsv` |
| 绑定表 | `EP%02d_资产绑定.json` | `EP01_资产绑定.json` |
| 作业单 | `EP%02d_jobs.json` | `EP01_jobs.json` |
| 提示词 | `EP%02d_提示词_<模板>.txt` | `EP01_提示词_自己人.txt` |

组号 / 分镜 ID：`集_组_镜`（`1_2_4`），组内从 1 连续；组号必须是纯数字。

---

## C7 资产类型与 pn 顺序

顺序固定：**角色 → 场景 → 道具 → 技能参考（符）**。
角色按组内首次出场排序；符永远排最后。

---

## C8 禁止出现的内部痕迹

提示词正文里不许出现：

```
《》  变量占位
pn1 / vm1 之外的编号解释
主镜头为 / 沿用上一组站位 / 承接上一轮
内部判断 / 自检 / 参数层级 / 必填选填
```
