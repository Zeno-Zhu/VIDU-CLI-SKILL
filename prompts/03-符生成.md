# 做一张符

符 = 把一类 AI 视频能力压成一张 16:9 的图。

说白一点：**符就是 AI 视频的 skill，只不过 skill 的载体是文字，符的载体是图。** 本来要几千字讲清的经验、要点、禁忌、错法，压成一张图，让模型直接看。模型读图比读长文本准——不会被截断，不会抓错重点，不会把第三条要点当成装饰。

太极拳怎么打、镜头怎么推、赛博朋克的世界长什么样——凡是「模型现在做不好、但你讲得清」的东西，都能封成符。

**图是能力卡，不是海报。** 它要能让下游模型照着做，不是让人点赞。

---

## 什么时候用这个文件

这个文件管两件事：**做符**（前五步）和**用符**（最后两节）。两件事都**用户主动提才做**。

| 用户说 | 你做什么 |
|---|---|
| 「做个符」「把太极拳做成符」「封装一下这个技巧」 | 做符，走第一步往下 |
| 「来一张运镜的符」「世界观风格做成符」 | 做符 |
| 「用我的符做」「带张运镜的符」「用我库里的符」 | 跳到「用符」那节，先回主线 |
| 用户只丢来一堆零散经验、参考图、失败案例 | 先问清要封装哪个能力 |

**别主动推销符。** 用户没提，你就当这个文件不存在。新手第一次做片，全程不该听见「符」这个字。

**符不是视频。** 做符做完就交图，不提交视频任务，也不进分镜。

> 唯一例外：用户自己抱怨「这类动作每次都崩」，而库里恰好有对症的符——这时候可以提一句。没有就闭嘴。

## 第一步：收料（只问一句）

| 他给的 | 你要什么 |
|---|---|
| 通用主题（太极拳、推镜、赛博朋克） | 够了，直接做 |
| 他自己的方法 / 新梗 / 某个片的某个镜头 | 要材料：参考图、案例、他自己的一句话经验 |
| 只丢来一张参考图 | 问：这张图里，你想让我保住的是哪一件事？ |
| 什么都说不清 | 问：这东西是治什么毛病的？一句就行 |

问法就一句：

> 这个能力是解决什么问题的？一句话——模型现在做不好的是什么。

**别问**：分几栏、什么配色、字多大、要不要参数表。规则里已经定死了，问了也白问。

---

## 第二步：封装（照规则做，别自创格式）

`prompts/符的生成.txt` 是这套东西的系统规则，**整份读，按它的工作流走**。

它已经定死了几件事，你照着就行：

- 先定「有效标准」——这个能力解决什么问题、什么结果算成功
- 从案例里抽机制，不是抄案例的样子
- 分清「必要变量」（改了能力就废）和「开放变量」（改了只是换个样子）
- 一张 16:9 只装一个能力，装不下就砍范围，不许缩字号硬塞
- 示意人物只能黑白线稿 / 剪影，不许出现写实脸

它给的输出是两个代码块：

1. **JSON**：`name` / `type` / `intro`（≤60 字）/ `prompt`（≤100 字，下游调用指令）
2. **视觉 Brief**：必须以「技能/知识面板设计需求」开头

这两个不是给用户看的成品，是生图的原料。

**他要是只要提示词、不要图，到这里就停**，把两个代码块给他。

---

## 第三步：落盘 + 转成生图提示词

存到 `out/符/<能力名>/`：

```
meta.json     第一个代码块，原样存（入库就用它）
brief.md      第二个代码块，原样存（以后改符、拆符都靠它）
prompt.txt    真正丢给生图模型的（见下）
panel.png     出图后自动落这里
```

**为什么中间要过一道 prompt.txt**：brief 是给人看的结构化文档，动辄两三千字，直接喂生图模型会被截断，或者抓住「人物示意」这种次要要求、把核心要点丢了。

prompt.txt 只留五段，1500 字以内。**开场语和尾缀不用你写**——第一次跑 `card` 时脚本会自动补上，并把补好的版本写回 prompt.txt。

```
16:9 的 AI 视频技能知识面板，简体中文，字迹清晰。

标题：太极拳·掤捋挤按

必须出现的文字（逐字照抄，不要改字、不要漏字）：
1. 掤：前臂撑圆，力道向外，肘不过肩
2. 捋：顺对方来力侧引，重心后坐
3. 挤：两臂相合向前挤，劲从脚起
4. 按：双手下按，沉肩坠肘，意到脚底
5. 错法：只用手臂发力，胯不动

必须画对的关系（用黑白线稿小人）：
- 掤：前臂弧线与身体的夹角
- 捋：重心从前往后移动的方向箭头
- 挤：双脚蹬地 → 腰 → 前臂的力线
- 按：肩、肘、手依次下沉的竖向顺序

人物一律黑白线稿 / 剪影，不要五官、不要具体服装、不要写实脸。

版式、配色、图标、信息层级你自由设计，要求一眼能看到标题和四条要点的先后关系。
```

三条经验：

1. **文字是要点，不是段落。** 一条超过 20 个字就砍。
2. **「逐字照抄」这四个字必须写。** 不写，模型自己改写你的术语。
3. **人物约束要写两遍**（规则里一次、视觉说明里一次）。只写一遍，它照样给你画一张写实脸。

**改字重跑时，只动中间那段。** prompt.txt 现在是三块：开场语 → 你的正文 → 尾缀。开场语和尾缀别删也别改，动了就不可复现了。

## 第四步：生图（生完自动进库）

```bash
python scripts/vidu.py card --name 太极拳 \
    --prompt-file out/符/符-太极拳/prompt.txt \
    --meta out/符/符-太极拳/meta.json \
    --tag 动作 --tag 教学
```

- 固定 16:9，出图存 `out/符/符-太极拳/panel.png`
- **`--meta` 一定要给**：库里靠它知道这张符「管什么、什么时候调」。不给也能进库，但只有个名字，等于没写
- `--tag` 是给以后搜用的，一个符两三个就够（动作 / 运镜 / 风格 / 情绪 / 世界观）
- 有参考图（画风、版式想照着来）：加 `--ref 参考图.png`，可重复
- 文字糊：加 `--resolution 2k`；报 `Invalid resolution` 就退回默认
- 不想进库：加 `--no-lib`

**生图不走闲时额度，走积分。** 开工前 `check` 看一眼余额。

出图成功后脚本会自己写一条进 `out/符/_库.json`，不用你手动登记。

---

## 第五步：看三件事（最容易漏）

| 看什么 | 不对怎么改 |
|---|---|
| 中文错字、漏字、繁简混 | 打开 prompt.txt，把错的那几个词单独拎出来，写「必须是『掤捋挤按』这四个字，逐字准确」，重跑 |
| 冒出写实人脸 / 具体角色 | prompt.txt 补一句「人物仅黑白线稿或剪影，无五官细节、无服装造型」，重跑 |
| 塞太满、字小到看不清 | 别调字号，砍内容：留 3 条要点；还不行就拆两张（一张讲机制，一张讲错法） |

**最多重跑 3 次。** 三次还错字，不是模型的问题，是这张符想讲的东西太多，砍一半再来。

重跑就是同一条命令再来一遍，只改 prompt.txt，别重写整段。

---

## 交付：图 + 三行字

```
符名：太极拳·掤捋挤按
管什么：让模型生成太极动作时不乱、不软、不抢拍
什么时候调：写打斗 / 教学 / 慢动作镜头时，把这张图当参考图带上
```

完整 brief 不用贴给用户，太长，他看不完。存着，下次改符直接改它。

## 符库：攒下来的符存在哪

一张符 = 一个文件夹 + 一条索引。

```
out/符/
  _库.json              总索引，先读它，人可以手改（改完别动 id）
  符-太极拳/
    panel.png           成品，唯一会被当参考图传出去的那张
    meta.json           名字 / 类型 / 简介 / 调用指令（第一个代码块）
    brief.md            完整视觉 Brief（第二个代码块）
    prompt.txt          生图实际用的提示词
```

索引一条长这样：

```json
{
 "id": "符-太极拳",
 "name": "太极拳·掤捋挤按",
 "type": "教学型技能面板",
 "intro": "让模型生成太极动作时不乱、不软、不抢拍",
 "call": "写打斗、教学、慢动作镜头时调用，结合当前人物与场景执行，不复制面板示意。",
 "tags": ["动作", "教学"],
 "file": "符-太极拳/panel.png",
 "created": "2026-10-22"
}
```

四条命令：

```bash
python scripts/vidu.py lib                  # 库里有什么
python scripts/vidu.py lib --q 太极          # 搜名字 / 简介 / 标签
python scripts/vidu.py lib --tag 动作        # 按标签筛
python scripts/vidu.py lib --show 符-太极拳   # 看一张的详情
```

补录和移除：

```bash
# 以前手做的符，补进库（目录里要有 panel.png，最好也有 meta.json）
python scripts/vidu.py lib --add out/符/符-运镜

# 从库里移除一条
python scripts/vidu.py lib --rm 符-运镜
```

**`--rm` 只动索引，不删文件。** 图永远留在硬盘上，要清自己清。

库跟着脚本走：skill 装在哪，库就在哪。机器上有两份 skill（工作区一份、安装目录一份）想共用一个库，设 `VIDU_CARD_ROOT` 指到同一个 `out/符`。

## 用符：符怎么进提示词

用户说「用我库里的符做」「带张运镜的符」时走这里。

**这不是另开一条线。** 就待在主线（漫剧或商业）里，照常读剧本、盘资产、拆分镜组，只在**写提示词那一步**拨一下开关。前面后面都不变。

符是一张**参考图**，不是贴在画面上的东西。它告诉模型「这类事按这套规则做」——原来你要写三百字讲运镜怎么推，现在挂一张图 + 一句调用指令。

**但它不能替你写画面。** 人在哪、光从哪来、动作怎么走，该写还得写。符省的是「讲道理」的字，不是「写画面」的字。

### 四步

1. **查库，别猜。** `lib` 列出来，把命中的念给他：名字 + 管什么。两张都像就让他挑
2. **挑 0–2 张。** 多了模型会打架；一张都挑不出来，就别挂
3. **写进提示词**（三层，见下）
4. **当参考图传，永远放在 `--image` 最后一位**

### 写进提示词：三层

**第一层：登记成图片资产。** 【资产盘点】加一行，编号接在道具后面。

```
人物视觉资产：pn1,男主=@
场景资产：pn2,饭馆=@
道具资产：pn3,旧怀表=@
技能资产：pn4,符-太极拳=@
```

**第二层：加【技能调用】块，把调用指令原样抄。**

调用指令在 `_库.json` 的 `call` 字段，`lib --show 符-太极拳` 能看到，源头是 meta.json 的 `prompt`。**一字不改地抄，别改写、别概括。**

```
【技能调用】
pn4,符-太极拳=@
调用指令：写打斗、教学、慢动作镜头时调用，结合当前人物与场景执行，不复制面板示意。
禁用：本卡不在画面中出现——不出现面板、文字块、图表、分隔线，不复制其配色与版式。
```

**第三层：正文里点名调用时机。** 只在真用得上它的镜头写，全文都挂等于没挂。

```
【镜号A2】
...
运镜：按 [@符-太极拳] 的重心转移节奏，从起势推到掤
```

### 提交

```bash
python scripts/vidu.py submit --prompt-file G01.txt \
    --image 人物/男主.png --image 场景/饭馆.png \
    --image 道具/旧怀表.png --image out/符/符-太极拳/panel.png \
    --duration 10 --name G01
```

`--image` 顺序必须对上 pn 编号，符永远最后一位。

### 挂符的三条硬规矩

1. **一张符一件事。** 想同时要运镜和打斗，是两张符。最多挂 2 张，再多模型会打架。
2. **别让面板进画面。** 整张面板当参考图，模型有时候会把版式和文字块带进画面。真遇到，就把符里那块示意图裁出来当参考图（`--image 裁图.png`），比整张稳。
3. **不相关就别挂。** 硬挂一张不相关的符，比不挂更糟——它会污染构图。

---

## 做符的三条硬规矩

1. **一张符一个能力。** 想讲「太极拳 + 运镜」，是两张符。
2. **面板上每个字都要能读。** 看不懂的字等于没写，这张符就是废的。
3. **示意人物不是角色。** 除非这个能力本身讲的就是长相、服装、妆造。

## 命令速查

```bash
# 干跑，不花钱，只看提示词多少字、存哪
python scripts/vidu.py card --name 太极拳 --prompt-file out/符/符-太极拳/prompt.txt --dry-run

# 正式出图，出完自动进库
python scripts/vidu.py card --name 太极拳 --prompt-file out/符/符-太极拳/prompt.txt --meta out/符/符-太极拳/meta.json --tag 动作

# 带参考图（画风/版式照它来）
python scripts/vidu.py card --name 运镜 --prompt-file out/符/符-运镜/prompt.txt --ref 参考.png --meta out/符/符-运镜/meta.json

# 文字糊，提高分辨率
python scripts/vidu.py card --name 太极拳 --prompt-file out/符/符-太极拳/prompt.txt --resolution 2k

# 看库
python scripts/vidu.py lib
python scripts/vidu.py lib --q 太极
python scripts/vidu.py lib --show 符-太极拳
```
