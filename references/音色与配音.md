# 音色与配音：闲时锁不住音色，但**照样会出声**

写提示词之前，必须先处理这件事。**声音不对，画面再准也白搭**——观众第一耳朵听出来的就是这个。

> ★ **2026-10-26 定案（实测）**：**闲时（`nopeak`）无法参考音色**。
> 本包默认就跑闲时（0 积分、批量），所以「挂个 `音色.wav` 就锁住声线」这条路**在默认通道上不存在**。
> ⇒ 角色声音**只能在人物资产阶段用文字写死**，写成《人物音色卡》，然后每组照抄。
> 人设阶段的落点是 `.prompts/05-人设卡片提示词.md`：卡片上的九维声音与本卡同源同值。

---

## 零、先说清楚：不能"参考音色" ≠ 不能"出声"（最容易理解反的一条）

闲时**会生成配音**，由平台自带的语音模型**逐句把台词念出来**（中文，语气跟着 `<>` 走）。

| 闲时能不能 | 结论 |
|---|---|
| **台词被念出来**（平台原生 AI 配音） | ✅ **能**。这正是我们写 `角色名：台词` 的目的 |
| 指定 / 复刻某条参考音频的声线 | ❌ 不能 —— 「无法参考音色」指的是这个 |
| 用外部音频驱动口型（`lip_sync`） | ❌ 不能 |

⇒ **台词照常写、`角色名：台词` 照常给、`<>` 照常写表演。**
删 `--audio` 删掉的只是「这是谁的声音」，**不是「有没有声音」**。

⛔ **三条禁令**（写错任何一条，成片就变默片或广播剧）：

1. 不许因为「闲时不能挂音色」就**删台词**、或把整组写成纯画面；
2. 不许在【资产盘点】里写「人物音色资产：无」就以为万事大吉 —— **无的只是参考音频，不是配音**；
3. 不许把「锁不住声线」理解成「不用写声音设计了」—— 反而更要写，因为**正是这份文字卡在指挥平台的配音**。

---

## 零之二、判通道（30 秒决定用哪套办法）

| 通道 | 参考音色（`--audio`） | 用什么锁声线 | 配音谁出 | 什么时候走 |
|---|---|---|---|---|
| **闲时 `nopeak`**（默认） | ❌ **不能** | **人物音色卡**（文字九维） | ✅ **平台原生配音**，按台词念 | 批量出片、0 积分、整集整季跑 |
| **`normal`**（花积分） | ✅ 能 | `<角色名>音色.wav` ＋ `vm1,<名>音色=@` | 平台按参考音色念 | 关键集、用户明确要某个声线、要严格口型 |

**默认按闲时设计，别按 `normal` 设计。** 一集 6 组，全走 `normal` 是实打实的积分。

判完通道再往下看：走闲时看第一、三节，走 `normal` 补看第二节。

## 一、闲时通道：人物音色卡（默认路径）

### 1.1 卡从哪来

**人物资产阶段产出**，不是写到分镜组时现编。

人物资产阶段（角色设定板 ＋ `.prompts/05-人设卡片提示词.md` 的人设卡）就是干这个的：每个**有台词**的角色一份卡，和角色视觉资产同一批交付。
人设卡负责把声音形象和外形一起设计出来，`音色-<角色名>.txt` 是写给写词阶段的权威锚点；两者同源同值。
卡不在，就说明这个角色的声音资产没建 —— 后面每集都换一个嗓子。
★ **但卡不在不等于没有配音**：平台仍会按台词原生发声，缺的是声线控制，不是声音本身。

### 1.2 卡长什么样（九维，一次写死，全片不改）

| 维度 | 写什么 | 例子 |
|---|---|---|
| **1 基准音域** | 低 / 中低 / 中 / 中高 / 高，共鸣位置在哪 | 中低音，胸腔共鸣为主 |
| **2 基频区间** | ★ **给数字**，别只给形容词 | 165–205 Hz，日常落在 180 |
| **3 虚实占比** | 气声和实声的比例，尾音虚不虚 | 气 3 实 7，尾音带一点气声 |
| **4 语速** | 字/秒，平时和急的时候分开写 | 3.4–3.8 字/秒，急起来 4.4 |
| **5 停顿模式** | 句间、逗号、情绪转折各停多久 | 句间 0.4–0.6 秒，转折前停 0.8 秒 |
| **6 重音习惯** | 哪几个字加重，句尾上扬还是下沉 | 句末两字加重，问句尾音反而下沉 |
| **7 语调曲线** | 平稳 / 波浪 / 阶梯下降 / 起伏大 | 整体平稳，句尾下压，少起伏 |
| **8 微观质感** | 沙哑颗粒、鼻音、胸腔共鸣、亮不亮 | 轻微沙哑颗粒，鼻音略重，不亮不尖 |
| **9 齿音强度** | s / sh / c 刺不刺耳 | 弱，齿音不刺耳 |

**基频参考值**（写数字时照这个给，别瞎编）：

| 人 | 日常说话基频 |
|---|---|
| 成年男声 | 95–150 Hz |
| 成年女声 | 165–255 Hz |
| 老年（男/女） | 在上面的基础上整体下移 10–20 Hz |
| 少年（男/女） | 整体上移 15–30 Hz |

### 1.3 锚点串：这才是逐组要抄的那一行

九维太长，逐组全抄会吃掉提示词字数（单组上限 2000 字）。所以每张卡压出**一行锚点串**，**≤ 40 字**：

```
锚点串：中低音胸腔共鸣·3.3字/秒·句尾下压·轻微沙哑
```

规则：

- 只挑最能区分这个人的 **3—4 项**（一般是：音域 + 语速 + 尾音走向 + 质感）
- **同一角色所有分集一字不差**；⛔ 不许每次现编、不许改标点、不许换顺序
- 锚点串是机检锚点：`scripts/voice_lock_check.py` 会对卡文件查，分镜稿里对不上就是错

### 1.4 不许撞嗓（三条硬指标）

只听声音、遮住画面，观众要能分出谁在说话。两个角色都"中低音、3.5 字/秒、略沙哑" ⇒ 对白戏糊成一个人。

| 指标 | 要求 |
|---|---|
| **基频** | 任意两角色区间**不重叠**；万不得已重叠，重叠量 ≤ 10 Hz |
| **语速** | 基频重叠的那一对，语速区间必须**明显分开** |
| **质感** | 基频与语速都接近时，第 8 维（微观质感）**必须不同** |
| **同场对手戏** | 高频对戏的两人（男女主、母子、上下级）**至少 3 维不同** |

排法：先定男女主两个不重叠的基频段 ⇒ 同性别配角在同一段里**错开 15–20 Hz**并换质感 ⇒ 功能角色可以并入已有声线段，但**仍要有自己的卡**。

### 1.5 分镜组怎么写（无参考音色通道）

**① 【资产盘点】不写音色行。** 闲时没有参考音频，写了 `vm1` 也没东西挂，等于骗自己。
★ 但这**不代表这组没有声音** —— 台词照样会被平台原生配音念出来，所以**台词一行都不能少**。

```
【资产盘点】
人物视觉资产：pn1,林桂芳=@，pn2,沈砚舟=@
场景资产：pn3,老饭馆内景=@
```
（`normal` 通道才写 `人物音色资产：vm1,林桂芳=@`）

**② 用【音色文字锁定】代替【音色严格规范】**，放在【资产盘点】之后。每个发言角色一行锚点串，**原样抄卡**：

```
【音色文字锁定】
本组无参考音频，音色以下列设定为准，同一角色全片同一份，禁止改写或另立声线。
林桂芳：中低音胸腔共鸣·3.3字/秒·句尾下压·轻微沙哑
沈砚舟：中音偏亮·3.9字/秒·句末轻挑·干净无沙
```

**③ `<>` 只写这句怎么说，不重复九维。**

```
林桂芳：饭在锅里 <保持林桂芳的音色不变，声音压得很低，说完就转回身，尾音收得极短。>
```

`<>` 开头那句「保持<角色名>的音色不变，」照写 —— 没有参考音时它读作**"别换声线"的约束**，不是引用文件。
音色内容由上面的【音色文字锁定】承担，`<>` 里 ⛔ 不再抄基频、语速。

**④ 一组最多 3 个发声角色。** 人一多，模型更容易串嗓；第 4 个要么拆组，要么让他只出现不说话（背影、手、反应镜）。

### 1.6 落盘与改卡代价

```
<项目>/00_剧本与提示词/_资产提示词/音色-<角色名>.txt
```

- 文件名 = `音色-` + **资产名**（和 `01_资产库/` 图片资产名一致，别用剧本昵称）
- 后续每集**照抄锚点串**，⛔ 不重写
- **改卡 = 全片声音重来**：改完要重跑 `voice_lock_check.py`，并在交付说明里写清"哪几个角色换了声线"

```bash
python scripts/voice_lock_check.py --dir "<项目>/00_剧本与提示词/_资产提示词"
```

### 1.7 别过度承诺（也更别承诺反了）

文字卡能做到：**给平台配音一个明确方向** —— 声线类型、语速、停顿、质感都照它走，角色之间听得出来。

文字卡做不到两件事，都得说清：

1. **像某个真人** —— 复刻某条音频只有 `normal` + `--audio`，或后期自己配。
2. **逐组 100% 同一把嗓子** —— 没有参考音频时，平台每次仍会自己挑，微调无法完全避免。
   所以关键集（第 1 集、大爆点集）想稳，就走 `normal`。

⇒ 对外话术：**「我们会给每个角色定一套声音设定，平台按它出声；如果要求逐集完全一致的声线，那几集需要单独处理。」**
⛔ 别承诺"能复刻真人"，也别说"闲时没声音" —— 两句都错。

## 二、`normal` 通道：参考音色（花积分）

### 2.1 要用户补音色，这么说

别只说"给我一段音频"，他不知道要多长、念什么。照这段讲：

> 有那个角色的声音吗？有的话给我一段，**4–5 秒**最好。
> - 一句话完整台词就行，别念词表，别只"啊——"一声
> - 单人、安静房间、手机录都可以
> - 不要背景音乐、不要混响、不要变声
> - 现成的语音消息、以前录的、影视片段都行

**他手上只有长音频**，告诉他用剪辑软件裁：

```
剪映：导入 → 拖到时间线 → 掐头去尾，只留一句 4–5 秒 → 导出音频
Premiere：同样的活，导出 wav 最好
```

存成 `01_资产库/<角色名>音色.wav`，名字跟盘点表一模一样。

**为什么是 4–5 秒**：3 秒刚够认出音色，5 秒能把语速和停顿习惯也带进去；超过 8 秒平台也只取一段，白给。

### 2.2 提交时怎么写

一组最多 3 条，顺序必须和 `--audio` 一致：

```
【资产盘点】
人物视觉资产：pn1,林桂芳=@
人物音色资产：vm1,林桂芳音色=@，vm2,沈砚舟音色=@

【音色严格规范】
严格匹配各角色专属参考音色，一角色对应一份参考音；全程锁定原始音色基底，禁止修改音色参数、拼接融合或生成陌生新音色。
```

```bash
python scripts/vidu.py submit --prompt-file 提示词.txt \
  --image 林桂芳.png --audio 林桂芳音色.wav --duration 10 --mode normal
```

### 2.3 别踩的坑

- ⛔ **闲时带 `--audio` 是白跑**：本包会在提交前直接拦住并报错（省得你排完队才发现没生效）。
- ⛔ **别为了"要声音"把整组改 `normal`** —— 闲时本来就会按台词出声，只是**锁不住指定声线**。
- 音色只锁「声线基底」，语气由 `<>` 控制。

## 三、两条通道共用的铁律

1. **全片同一份设定，写一次存文件。** 每集重写一次，声音就会一集一个样。
2. **一组里说话的人别超过 3 个。** 有音色文件的最多 3 条（平台上限）；全是文字卡也一样控制。
3. **音色不随服装 / 状态 / 阶段拆版本。** 一个角色永远只有一份声音资产；变声是剧情事件，另建 `<角色名>变声版`。
4. **禁用重塑音色的词。** 磁性嗓音 / 少女音 / 御姐音 / 烟嗓 / 气泡音 / 贵族腔 / 播音腔 / 声音变老 / 低音炮 / 奶音 —— 这些会让模型**另造一个声线**，机检会直接报错。

## 四、商业片的旁白 / 口播

同样的道理，但更简单——一条片子通常只有一个声音，写五个维度就够：

```
【旁白音色设定】
男，30 岁上下，中音区，基频 120–150 Hz；
语速 4.2 字/秒偏快，句间几乎不停；
干净、不沙哑、齿音清楚；
句末下沉，不带情绪上扬，像在讲事实。
```

**卖货片的口播别用"激情叫卖"描述。** 写"语速快、句末下沉、不喊"，比写"很有感染力"管用。

## 五、常见问题

**同一角色两集声音不一样**
→ 音色卡没存文件，每集现编了。存 `音色-<角色名>.txt`，之后**照抄锚点串**。

**两个角色听着像一个人**
→ 基频区间撞了。同性别配角错开 15–20 Hz，再换一个质感（一个沙哑、一个干净），跑 `voice_lock_check.py` 看冲突清单。

**写了九维还是不像某个真人**
→ 正常。文字只能给方向。要像，只有参考音（`normal`）或后期配音。跟用户直说，别承诺"能复刻"。

**用户给的是带背景音乐的片段**
→ 让他重录，或从原素材里另找一段干净的。带 BGM 的参考音会把音乐也一起喂进去。

**音色文件太长**
→ 裁到 4–5 秒。挑情绪中性、语速正常的那一句，别挑哭喊或耳语的。

**一组里四个人都要说话**
→ 拆组，或让其中一个只出现不说话（背影、手、反应镜）。

**我这份卡和上一集卡里的"锚点串"只差一个标点，行不行**
→ 不行。机检按**一字不差**比对，差一个符号就判不过。
