# 音色与配音：有参考音就用，没有就写死一套

写提示词之前，必须先处理这件事。**声音不对，画面再准也白搭**——观众第一耳朵听出来的就是这个。

---

## 一、先查一遍：有没有音色资产

打开 `01_资产库/`，看有没有 `<角色名>音色.wav`。

| 情形 | 怎么办 |
|---|---|
| **有音色文件** | 直接挂 `--audio`，按 `SKILL.md` 的「音色参考怎么用」走 |
| **没有，用户能补** | 提醒他补，把录制要求说清楚（第二节） |
| **没有，也补不了** | 写一份「音色设定」随提示词一起提交（第三、四节），全片统一 |

**别默不作声地跳过。** 一个角色从头到尾用平台随机音色，观众听着就是"换了个演员"。

---

## 二、要用户补音色，这么说

别只说"给我一段音频"，他不知道要多长、念什么。照这段讲：

> 有那个角色的声音吗？有的话给我一段，**4–5 秒**最好。
> - 一句话完整台词就行，别念词表，别只"啊——"一声
> - 单人、安静房间、手机录都可以
> - 不要背景音乐、不要混响、不要变声
> - 现成的语音消息、以前录的、影视片段都行

**他手上只有长音频**，告诉他用剪辑软件裁：

```
剪映：导入 → 拖到时间线 → 掐头去尾，只留一句 4–5 秒 → 导出音频
Premiere：同样的活，导出 wav 最好
```

存成 `01_资产库/<角色名>音色.wav`，名字跟盘点表一模一样。

**为什么是 4–5 秒**：3 秒刚够认出音色，5 秒能把语速和停顿习惯也带进去；超过 8 秒平台也只取一段，白给。

---

## 三、用户补不了：写一份音色设定

平台锁不住音色时，只能靠文字把声音"描述"出来。**九个维度，一次写死，全片不改。**

| 维度 | 写什么 | 例子 |
|---|---|---|
| **1 基准音域** | 低 / 中低 / 中 / 中高 / 高，共鸣位置在哪 | 中低音，胸腔共鸣为主 |
| **2 基频区间** | 给数字，别只给形容词 | 165–205 Hz，日常落在 180 |
| **3 虚实占比** | 气声和实声的比例，尾音虚不虚 | 气 3 实 7，尾音带一点气声 |
| **4 语速** | 字/秒，平时和急的时候分开写 | 3.4–3.8 字/秒，急起来 4.4 |
| **5 停顿模式** | 句间、逗号、情绪转折各停多久 | 句间 0.4–0.6 秒，转折前停 0.8 秒 |
| **6 重音习惯** | 哪几个字加重，句尾上扬还是下沉 | 句末两字加重，问句尾音反而下沉 |
| **7 语调曲线** | 平稳 / 波浪 / 阶梯下降 / 起伏大 | 整体平稳，句尾下压，少起伏 |
| **8 微观质感** | 沙哑颗粒、鼻音、胸腔共鸣、亮不亮 | 轻微沙哑颗粒，鼻音略重，不亮不尖 |
| **9 齿音强度** | s / sh / c 刺不刺耳 | 弱，齿音不刺耳 |

**基频参考值**（写数字时照这个给，别瞎编）：

| 人 | 日常说话基频 |
|---|---|
| 成年男声 | 95–150 Hz |
| 成年女声 | 165–255 Hz |
| 老年（男/女） | 在上面的基础上整体下移 10–20 Hz |
| 少年（男/女） | 整体上移 15–30 Hz |

---

## 四、模板（直接抄）

```
【人物音色设定】
角色：林桂芳｜女，58 岁，江南口音，说话慢
1 基准音域：中低音，胸腔共鸣为主
2 基频区间：165–205 Hz，日常落在 180
3 虚实占比：气 3 实 7，尾音带一点气声
4 语速：3.2–3.5 字/秒（偏慢），急的时候到 3.9
5 停顿模式：句间 0.4–0.6 秒，逗号 0.2 秒；情绪转折前停 0.8 秒
6 重音习惯：句末两字加重；疑问句尾音不上扬，反而下沉
7 语调曲线：整体平稳，句尾下压，少起伏
8 微观质感：轻微沙哑颗粒，鼻音略重，不亮不尖
9 齿音强度：弱，s / sh 不刺耳
```

**一组里只有一个人说话**，可以压成一行：

```
【人物音色设定】
沈砚舟：男，40 岁，中音区，基频 115–145 Hz，气 2 实 8，3.4 字/秒，
句间停 0.3 秒，句末下沉，干净不沙哑，齿音中等
```

**多角色**就一个角色一块，写在同一段里。

## 五、这块放在提示词的哪里

放在【资产盘点】之后、【提示词正文】之前：

```
【资产盘点】
人物视觉资产：pn1,林桂芳=@，pn2,沈砚舟=@
场景资产：pn3,香坊工作间=@
人物音色资产：vm1,林桂芳音色=@        ← 有文件的写这行

【人物音色设定】
沈砚舟：男，40 岁，中音区……            ← 没文件的写这块

【提示词正文】
……
```

**两种可以共存**：一部分角色有参考音，另一部分只能文字描述，各写各的。

**文本只能贴进提示词，不能单独上传。** 平台的附件只收图片和音频，没有"文本附件"这一说——所以这份设定是**写进提示词正文、随提示词一起提交**的。

**一句都不写**的后果：模型每次自己挑一个声线，同一集里第三组换了个嗓子，观众以为换了个人。

---

## 六、三条硬规矩

1. **全片同一份设定，写一次存文件。** 存到 `00_剧本与提示词/_资产提示词/音色-<角色名>.txt`，后面每次照抄。每集重写一次，声音就会一集一个样。
2. **一组里说话的人别超过 3 个。** 有音色文件的最多 3 条（平台上限）；全是文字设定的也一样控制，人一多模型容易串嗓。
3. **有参考音一定优先用参考音。** 文字只能给方向，锁不住具体声线——九维写得再细，也复刻不了某一个真人。别反过来拿设定替代文件。

---

## 七、商业片的旁白 / 口播

同样的道理，但更简单——一条片子通常只有一个声音，写五个维度就够：

```
【旁白音色设定】
男，30 岁上下，中音区，基频 120–150 Hz；
语速 4.2 字/秒偏快，句间几乎不停；
干净、不沙哑、齿音清楚；
句末下沉，不带情绪上扬，像在讲事实。
```

**卖货片的口播别用"激情叫卖"描述。** 写"语速快、句末下沉、不喊"，比写"很有感染力"管用。

---

## 八、常见问题

**同一角色两集声音不一样**
→ 九维设定没存文件，每集重写了。存成 `音色-<角色名>.txt`，之后照抄。

**写了九维还是不像**
→ 正常。文字只能给方向。要像，只有参考音。跟用户直说，别承诺"能复刻"。

**用户给的是带背景音乐的片段**
→ 让他重录，或从原素材里另找一段干净的。带 BGM 的参考音会把音乐也一起喂进去。

**音色文件太长**
→ 裁到 4–5 秒。挑情绪中性、语速正常的那一句，别挑哭喊或耳语的。

**一组里四个人都要说话**
→ 拆组，或让其中一个只出现不说话（背影、手、反应镜）。
