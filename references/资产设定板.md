# 资产设定板：把「人、地、物」先钉死

这是全流程的第一步和第二步。**先有能复用的资产，才有稳定的片子。**

读完剧本（或聊完需求）别急着写分镜，先做这件事：**建目录 → 盘一遍资产 → 一张张生成设定板 → 交给人确认**。

---

## 一、为什么是「设定板」而不是一张随手图

一句话生成几十组视频，最容易出的问题不是画得丑，是**每一组都换一张脸、换一个房间**。

设定板的作用是把标准钉死：

- **一张板定四件事**：长相、服装、空间结构、材质
- 后面几十组全部引用同一张图，模型每次都能抓到同一个锚点
- 人看图也能一眼判断对不对，比看十张零散图快

**单张正面图不够。** 只有正面，模型不知道侧脸、后脑、肩线、衣服背面怎么长，一到转身就自由发挥。

---

## 二、资产分几类

| 类型 | 装什么 | 什么时候必须有 | 建议比例 |
|---|---|---|---|
| **人物** | 主角、对手、关键配角 | 有正脸、有台词、有连续出场 | 16:9 |
| **场景** | 主要空间（内景 / 外景） | 同一空间出现 ≥2 组，或要交代空间关系 | 16:9 |
| **道具** | 推动剧情的物件、要卖的产品 | 有特写、被拿取、承担信息 | 16:9 |
| **音色**（可选） | 每个说话人的参考音 | 用户希望声音统一、可辨识 | 3–8 秒 wav |

**四类之外不要自己加。** 光线、色调、风格写进统一风格模块，不单独占一个资产。

### 哪些不用做

- **只露一次脸、三五句台词的路人**：并进已有角色，或用背影、手、声音代替
- **只出现一次的空镜空间**：写进提示词的场景描述，不用单独生成
- **衣服、发型的变化**：在原人物板上写清变化，不重开一张（除非是全片第二套主线造型）

判断标准只有一条：**后面还会不会再引用它。** 不会再引用，就别做板。

## 三、先建目录：资产管理规范

**别手工建文件夹。** 一条命令把整棵项目树建好：

```bash
python scripts/asset_init.py 我的项目
```

它会在非系统盘上建这套结构（**默认不放 C 盘**，见下面「目录放哪」）：

```
我的项目/
├─ 00_剧本与提示词/
│  ├─ _剧本全文.txt            剧本、大纲，纯文本
│  ├─ _资产提示词/              每个资产一份 txt，文件名 = 资产名
│  ├─ _模板/                    你自己写的设定板模板，放这里就优先用你的
│  ├─ _资产映射.json            名字 → 文件 的对照表，给脚本读
│  └─ EP01/分镜组/              分镜组表、统一制作基准
├─ 01_资产库/                   ★ 图片和音色全平铺在这一层，文件名就是资产名
│  ├─ 男主.png
│  ├─ 小饭馆内景.png
│  ├─ 旧怀表.png
│  ├─ 男主音色.wav
│  ├─ _盘点.tsv                盘点表
│  └─ getname.bat              双击一下，列出本目录所有资产名（核对用）
├─ 02_分集工程/
│  └─ EP01/ … EP16/视频/        成片按集放，一组一个 mp4
├─ 03_背景音乐/
└─ 04_最终交付/创作截图/
```

### 三条规矩

1. **资产库平铺，不分子目录。** 人物、场景、道具、音色全在 `01_资产库/` 一层。分子目录看着整齐，写提示词时天天要拼路径，错一次就换脸。
2. **文件名 = 资产名。** 提示词里写 `[@男主]`，`--image` 就传 `01_资产库/男主.png`。改一个字母就断链。
3. **音色统一叫「名字 + 音色」。** `男主音色.wav`，一眼看出这是声音不是图。

### 目录放哪

**别放 C 盘。** 一条片子几十个视频、几百张图，几个 G 起步，塞系统盘迟早出事。

推荐位置（脚本会自动挑一个存在的盘）：

```
E:/AI视频项目/剧情电商/项目名
D:/AI视频项目/剧情电商/项目名
```

指定路径：

```bash
python scripts/asset_init.py 我的项目 --root "D:/AI视频项目/剧情电商"
```

**真放到 C 盘，脚本会停下来拦你**，除非你明确加 `--allow-c`。它拦的时候会告诉你能放哪，照着改就行。

### 盘点表与映射表

`01_资产库/_盘点.tsv` 是给人看的，也是给你自己核对的：

```
类型	名字	文件名	有没有	父系	用途
人物	男主	男主.png	没有		G01–G12 全程
```

`00_剧本与提示词/_资产映射.json` 是给脚本读的：

```json
{
  "schema_version": "1.0.0",
  "project": "我的项目",
  "dest": "01_资产库",
  "assets": [
    {"name": "男主", "kind": "image", "file": "男主.png", "type": "人物", "parent": ""},
    {"name": "男主音色", "kind": "audio", "file": "男主音色.wav", "type": "音色", "parent": ""}
  ]
}
```

生完一个资产就补一条。**这两张表对不上，就是丢资产的开始。**

## 四、写板的理念：宽松，但要点写死

这条最容易被做反。**设定板是你给模型出的一道题，不是一张施工图。**

### 不要指定排版

别写「四宫格 2×2」「左上正面、右上侧面」「格间留白」。原因三条：

1. **你一排格子，模型就只会照抄格子。** 它把 80% 的注意力花在「别越过分隔线」上，画脸反而敷衍
2. **同一张脸被画四遍，越画越偏。** 分格会逼模型把脸重复四次，每次都是一次新的想象，四格互相对不上
3. **写死格数等于放弃了构图。** 三视图本来可以排得更自然——正面大、侧面小、表情裁在旁边——你一写格子，这些全没了

**正确做法：交代「必须出现什么」，排版交给模型。**

板子生成后如果要给美术对齐，自己裁切，不必让模型排版。

### 哪些必须写死

宽松不等于含糊。这五类一句都不能省：

| 必须写死 | 为什么 |
|---|---|
| 可辨识特征 | 疤、痣、眼镜、旧伤、纹身，**位置**要精确 |
| 服装部件 | 颜色、纽扣、口袋、领型、袖长。只写"深灰夹克"必出四种夹克 |
| 结构方位 | 门在哪、窗在哪、主家具在哪。不写，模型每张都重新规划房间 |
| 材质与反光 | 哑光 / 釉面 / 金属拉丝 / 纸质纤维，高光位置 |
| 禁止项 | 文字、水印、第二个人、多余家具、边框装饰 |

### 人物的硬要求：三视图 + 表情细节

**人物板必须同时有这两样，缺一不可：**

- **三视图**：正面全身、正侧面全身、背面全身
- **表情细节**：至少 3 张面部近景，其中至少 2 张是**指定情绪**（写清是什么情绪、什么表情肌肉在动）

只有正面，一转身就崩；没有表情，后面几十组全是同一张呆脸。

## 五、固定骨架（六段，顺序别动）

不管人、地、物，都按这六段写。结构稳定，模型更听话，你也好复用。

```
① 板种与画法 ：什么板、什么画风、排版交给模型
② 主体       ：这是什么，把可辨识特征写死
③ 必须交代的 ：这张板必须出现哪几个角度 / 哪几处细节（不是"放哪格"）
④ 一致性     ：所有画面必须一样的那些点（比例、结构、颜色、位置）
⑤ 材质与光   ：反光属性、光从哪来、背景什么颜色
⑥ 禁止项     ：不出现什么（写死，模型最认这段）
```

**④ 和 ⑥ 是板子的命。** 少了 ④，各画各的；少了 ⑥，画面里会飘出文字、第二个人、多余家具。

**长度控制在 600 字内。** 平台单条提示词上限 2000 字，写太长模型抓不住重点，反而更乱。

## 六、三套内置模板（直接抄，方括号替换）

> 这三套是**通用骨架**，不是唯一答案。要加角度、加情绪、换画风，都可以改——只要保住「一致性」和「禁止项」两段。

### 6.1 人物设定板（三视图 + 表情）

```
人物设定板，[真人写实摄影 / 国漫 / 插画]。[性别]，[年龄段]，[体型]。
[发型长度与颜色]，[服装：上衣 / 下装 / 鞋 / 配饰，颜色与材质写死]，
[可辨识特征：疤、痣、眼镜、旧伤、纹身，写清位置]。

同一个人，完整走一遍：正面全身、正侧面全身、背面全身各一，自然站姿，双臂自然下垂，
衣服在三个角度都要交代清楚——领口、袖长、背部结构、鞋型。

再给几处面部细节：正脸近景一张，三分之四侧脸一张，
[情绪A：如压着怒气的沉默]，[情绪B：如强撑出来的笑]，[情绪C：如突然的错愕]。
每处细节都把表情画实——眉怎么走、嘴角怎么动、眼睛看向哪。

所有画面是同一个人：五官比例、发际线、脸型轮廓、左右脸特征完全一致；
服装颜色、纽扣、口袋、褶皱走向一致；身高与头身比一致。

用柔和顶光加正面补光，无强投影；背景中性浅灰，干净均匀。
[真人写实] 皮肤保留毛孔与细微起伏，不磨皮、不打美颜光。

排版你自行安排，怎么清楚怎么放，不用分隔线，不用任何标注文字。

不出现：画面内任何文字、数字、箭头、色卡；第二个人；手持道具；
夸张的表情与动作；边框与装饰纹样。
```

### 6.2 场景设定板

```
场景设定板，[画风]。[地点全称]，[建筑或房间类型]，[面积感与层高]，[年代与地域特征]。

结构写死：门在[方位]，窗在[方位]，[主要家具或设备]在[方位]，
地面是[材质]，墙面是[材质与颜色]，顶部是[结构]。

至少交代三件事：从进门位置朝[主方向]看的主视角，要同时看到[主家具]与门窗的关系；
从对面回看的反打视角，交代纵深与进门动线；[关键操作区]的局部近景，看得见材质与使用磨损。
另外给一张[光源方向]的光线状态：[白天 / 夜晚 / 灯光]，说清光从哪进来、落在哪。

所有画面是同一个空间：门窗位置、家具摆位、墙色、地面材质完全一致，不得增删大件家具。

排版你自行安排，不用分隔线。

不出现：可读文字招牌（招牌留空或纯色块）；现代穿帮物件；杂志级布景感；边框装饰。
[需要比例参考时] 可有一名远景背影，不露正脸；[否则] 不出现人物。
```

> 招牌那句别省。要中文招牌，模型十有八九写错字——**招牌留白，字后期加**。

### 6.3 道具设定板

```
道具设定板，棚拍产品感，[画风]。[道具名]，[尺寸感]，[材质]，[主色与辅色，写死色相]，
[结构：几段、几个部件、接口、磨损位置]，[状态：全新 / 有使用痕迹 / 破损]。

至少交代三件事：整体形态，45 度俯视，能看清全貌与比例；正俯视，交代轮廓与结构关系；
[关键结构]的局部特写——开关、接口、纹样、刻字位置，看得见材质颗粒与边缘倒角。
再给一张使用状态：[打开 / 合上 / 握持 / 点燃 / 倾倒]，交代与手或另一物件的关系。

所有画面是同一件物品：尺寸比例、颜色、结构件数量、磨损位置一致，高光位置一致。

材质写清反光属性（哑光 / 釉面 / 金属拉丝 / 纸质纤维），表面颗粒与瑕疵程度写死。

排版你自行安排，不用分隔线。

不出现：可读文字、品牌 Logo、价格标签、多余配件。
```

## 七、出图命令

```bash
# 人物（真人题材记得 --tail min）
python scripts/vidu.py image \
  --prompt-file "00_剧本与提示词/_资产提示词/男主.txt" \
  --name 男主 --out 01_资产库 --ratio 16:9 --tail min

# 场景
python scripts/vidu.py image \
  --prompt-file "00_剧本与提示词/_资产提示词/小饭馆内景.txt" \
  --name 小饭馆内景 --out 01_资产库 --ratio 16:9 --tail min

# 道具 / 产品
python scripts/vidu.py image \
  --prompt-file "00_剧本与提示词/_资产提示词/旧怀表.txt" \
  --name 旧怀表 --out 01_资产库 --ratio 16:9 --tail min
```

- 提示词超过两百字就用 `--prompt-file`，别塞命令行
- **`--tail` 按画风选**：真人 `min`，半写实 `mid`，动漫国漫默认 `full`。真人用 `full`，皮肤和布料纹理会被磨平
- 一家人后生的那张加 `--ref 01_资产库/男主.png`，提示词写「角色是图1的父亲，五官像图1」，**不许另写一套外貌形容词**

## 八、出完图，必须做三件事

### 第 1 件：自己先看

一张张打开看，别信 `success`。下面六条不全过，就重跑：

| 查什么 | 不合格的样子 |
|---|---|
| 是不是同一个人 | 三视图的脸型或眼距不一样，越看越像两个人 |
| 三视图齐不齐 | 只出了正面，背面和侧面糊过去，或者侧面画成了四分之三 |
| 表情有没有在做 | 几张近景是同一张脸复制粘贴，看不出情绪差别 |
| 服装是否一致 | 一边有口袋一边没有，颜色深浅不同 |
| 有没有文字 | 板面冒出中文、英文、数字、水印 |
| 结构对不对 | 门窗位置自相矛盾，六格房间变两个房间 |

**中文错字最常见的重灾区是道具上的刻字和场景招牌。** 板上一出现清晰可读的字，进视频就是变形字，直接判废。

### 第 2 件：停下来给人看

把图给人看，只问一句：

> 这个人 / 这个空间 / 这个物件，对不对？哪里不像，我改。

**不要问「你觉得怎么样」。** 太开放，用户答不上来。给具体选项：脸型、年龄感、服装、气质。

### 第 3 件：说清这是通用模板

**这句每次都要说，不能省。** 用户以为内置的就是最好的，后面不会自己调，白白浪费模型能力。

> 这套设定板用的是内置的通用模板，不是唯一写法。
> 你可以直接改，比如「侧面再多一个」「加一个哭的表情」「场景要夜景」；
> 也可以自己写一份模板放进来，我照着填、优先用你的。

模板优先级：**用户的 > 内置的**。看到 `00_剧本与提示词/_模板/` 下有 `人物.txt`、`场景.txt`、`道具.txt`，先用它，只把方括号槽位填上。

## 九、设定板和「出片参考图」不是一回事

这是最容易踩的坑：**板子好看，不等于喂给视频模型就好用。**

| 用途 | 用什么 | 原因 |
|---|---|---|
| 给人确认、定标准 | 设定板 | 信息全，一眼判断 |
| **人物出片** | **单张正视图（9:16）** | 视频模型看到多视角拼贴，容易把画中画、多重人像带进画面 |
| 场景 / 道具出片 | 优先单图；没有就用板 | 用板时必须在提示词里写死禁用句 |

人物建议这么办：**先出板（确认长相）→ 再出一张同描述的单图（去片场用）**。单图就是把模板里「一致性」段保留、把「必须交代的」压成只剩正面全身，`--ratio 9:16`。

真要用板直接出片，提示词里必须补这一句：

```
参考图仅用于人物长相与服装 / 空间结构与材质，画面中不得出现多视角拼贴、
画中画、文字标注与色卡。
```

不写这句，就等着画面里飘出一张多宫格设定稿。

## 十、常见崩坏与改法

| 现象 | 多半是这句没写 | 怎么改 |
|---|---|---|
| 三视图长得不像一个人 | 少了一致性要求 | 把「五官比例、发际线、脸型」逐项写进一致性 |
| 只出了正面，侧面背面糊弄 | 没点名三视图 | 明确写「正面全身、正侧面全身、背面全身各一」 |
| 表情都一个样 | 情绪只写了名字 | 写清眉、眼、嘴角怎么动 |
| 板面冒出中文乱字 | 少禁止项 | 加「不出现任何文字、数字、水印」，招牌留白 |
| 场景每张一个样 | 结构没写方位 | 门窗、主家具全部写「在哪个方位」 |
| 服装各图不同 | 只写了颜色没写部件 | 补纽扣、口袋、领型、袖长 |
| 真人板像磨过皮 | 尾缀用错 | `--tail min` |
| 写实板出成插画 | 画风没写死 | 开头第一句写「真人写实摄影」，禁止项加「不出现插画线条与笔触」 |
| 道具比例怪 | 尺寸感没给 | 写「约成人手掌大小」或给出参照物 |

改的时候**只改那一段，别整篇重写**。整篇重写等于换了个盲盒，上一版对的地方也会丢。
