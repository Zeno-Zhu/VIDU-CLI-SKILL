# 22 · 资产绑定（pn 的唯一来源）

> `EPxx_资产绑定.json` 由 `scripts/bind_assets.py` 生成，**零 LLM**。
> 提示词的【资产盘点】块、作业单的 `images` 顺序，都只能从它派生。
> ⛔ 人和 AI 都不许手写 pn。

---

## 一、为什么要有这张表

旧流程里 pn 有三套解释：全局定死 / 每组重排 / 上传顺序。
三者不能同时成立，所以「第 3 张图配谁」必然出现分歧。

这张表把 pn 定义成**派生量**：
**分镜组表写「谁出场」→ 脚本按固定顺序编号 → 提示词和作业单都抄它。**

---

## 三、pn 分配规则（写死）

1. **每个分镜组独立编号，永远从 1 开始**；不跨组复用，不全局定死。
2. 顺序固定：**角色（按首次出场）→ 场景 → 道具 → 技能参考（符）**。
3. **符永远最后**；没有符就整段不出现，编号不留空。
4. 随身道具 `bound_to` 到角色时，**不占 pn 槽**（`bind_assets.py` 自动跳过）。
5. 图片上限按渠道：Vidu/H3/即梦 2.0 = **9**；即梦 2.5/Wan3 = **12**。超限 ⇒ BLOCK。
6. 音色上限 **3**；发言者 >3 ⇒ 拆组（`storyboard_check` 也会拦）。
7. **pn 只出现在绑定表**；分镜组表和正文只写资产名 / id。

---

## 四、分镜组表怎么写出场资产

新增第 11 列「出场资产」，**每组必填**，只写名字或 id：

```
组号  分镜  时长  景别  角度  运镜  功能  内容  台词  站位  出场资产
G01   A1    5     中景  …     …     …     …     …     万集｜…  CH01,CH03,SC01
G02   A1    6     近景  …     …     …     …     …     …        CH01:寿宴,SC02
```

- 多状态角色写 `角色名:状态`（或 `CH01:寿宴`）；不写状态时取 `states[0]`。
- 场景写 `SC01` 或场景名；子场景写 `SC01:灶台区`。
- 道具只写**本组真的要入镜 / 被拿取**的；不要把所有道具都列上。
- **有台词的角色必须在本列**，否则 `storyboard_check.py` 判错。

---

## 五、冻结与 hash

`bind_assets.py --freeze` 会写入：
- `source.storyboard_sha256`
- `source.assets_sha256`

之后：
- `prompt_assemble.py` / `jobs_build.py` 会复核 hash；不一致 ⇒ **BLOCK**，要求重建绑定。
- 改了分镜组表或资产清单，必须重跑 `bind_assets.py --freeze`；
  提示词和作业单会因 hash 变化被强制重建——这是有意的。

---

## 六、四方对账（`bind_check.py`）

把四份东西按 `gid` 对齐，逐组比较 **pn 的 (n, name) 序列**：

| 方 | 来源 | 取什么 |
|---|---|---|
| ① 表 | `EPxx_分镜组.tsv` 的「出场资产」列 | 名字 / id 集合 |
| ② 绑定 | `EPxx_资产绑定.json` | `pn` / `vm` |
| ③ 提示词 | `EPxx_提示词_<模板>.txt` | 【资产盘点】里的 `pnN,名=@` |
| ④ 作业单 | `EPxx_jobs.json` | `images[].name` 顺序 |

**任一组任一方顺序不一致 ⇒ 退出码 2**，并打印「第几个 pn、表里是谁、提示词是谁、作业单是谁」。

---

## 七、形象一致性（旧 wardrobe_check 的替代）

旧的 `_形象规划.json` 已合并进 `资产清单.json` 的 `states`。
`bind_assets.py` 逐组检查：

1. 角色有多个状态时，`角色:状态` 必须存在；
2. 该状态的 `episodes` 必须包含当前集；
3. 同一组同一角色只能一个状态；
4. 绑定文件必须是该状态对应的图（命名 `<角色>-<状态>.png`；主状态用 `<角色>.png`）；
5. 全剧角色只有一个状态 ⇒ 自动跳过。

任一不成立 ⇒ BLOCK，并指出「第几组、哪个角色、应该用哪张图」。

---

## 八、命令

```bash
# 生成并冻结
python scripts/bind_assets.py \
  --storyboard "…/EP01/分镜组/EP01_分镜组.tsv" \
  --assets "…/资产清单.json" \
  --episode 1 --out "…/EP01/EP01_资产绑定.json" --freeze

# 只预览，不落盘
python scripts/bind_assets.py ... --dry-run

# 四方对账
python scripts/bind_check.py \
  --bind "…/EP01_资产绑定.json" \
  --prompt "…/EP01_提示词_自己人.txt" \
  --jobs "…/EP01_jobs.json" \
  --assets "…/资产清单.json" --strict
```
