# 21 · 资产清单（唯一资产表）

> 全项目只有这一张资产表：`00_剧本与提示词/资产清单.json`。
> 它合并了旧的 `资产盘点.json`、`_资产映射.json`、`_盘点.tsv`、`_形象规划.json`。
> ⛔ 不再产生第二张名字表。

---

## 二、字段

| 字段 | 必填 | 规则 |
|---|---|---|
| `id` | ✅ | `CH/SC/PR/SK` + 两位序号，全表唯一，定后不改 |
| `type` | ✅ | `character` / `scene` / `prop` / `skill` |
| `name` | ✅ | 剧内语义名，全表唯一；**= 文件名去后缀** |
| `file` | ✅ | 图片文件名，扁平放 `01_资产库/`；`skill` 可放 `assets/常用符/` |
| `status` | ✅ | `planned / candidate / final / rejected / builtin`；**只有 `final`（和 `builtin`）能进绑定** |
| `board_variant` | 角色 ✅ | `A` / `B`，必须等于 profile 的 `board_variant` |
| `speaks` | 角色 ✅ | 有台词 `true`；哑角 `false` |
| `voice` | 有台词 ✅ | A 版：`{"mode":"text","card":"音色-<名>.txt"}`；B 版：`{"mode":"audio","file":"音色/<名>.wav"}` |
| `states` | 角色 ✅ | 至少 1 个；`name` 唯一；`episodes` 不重叠（同一集只能一个状态）；非首个状态可写 `file`（默认 `<name>-<state>.png`） |
| `subscenes` | 场景 ✅ | 子场景名数组；一张场景板可含多个子场景 |
| `bound_to` | 道具选填 | 随身道具绑定到角色 id；绑定后仍保留文件，供特写，但不单独占 pn 槽 |
| `style` | 顶层 ✅ | 全剧统一画风；所有设定板共用 |

---

## 三、怎么产出（P2）

1. 读 `00_剧本与提示词/_剧本全文.txt`，按**集**分批盘（一次 6 集以内）。
2. 角色：只盘**剧本里真正出现过的状态**；`states` 写清哪几集；能一张不换装就只做一个状态。
3. 场景：一个地方一张板；同一空间的多个功能区放进 `subscenes`。
4. 道具：只有**推动剧情 / 有特写 / 被拿取**的才建；随身常用道具 `bound_to` 到角色。
5. 写完落 `资产清单.json`，跑 `assets_check.py`。

**数量硬规矩**：同一角色正式设定板 **≤3 个状态，优先 1–2 个**；超过 3 个先问用户。

## 四、校验（`assets_check.py`）

| # | 检查 | 不过 |
|---|---|---|
| 1 | `schema_version=3.0`，`style.main` 非空 | BLOCK |
| 2 | `id` / `name` 全表唯一 | BLOCK |
| 3 | `file` == `name + ".png"`（`skill` 例外） | BLOCK |
| 4 | `type` / `status` 合法 | BLOCK |
| 5 | 角色必须有 `states`，同角色 `episodes` 不重叠 | BLOCK |
| 6 | `speaks=true` 必须有 `voice`；A 版卡文件存在；B 版 wav 存在 | BLOCK |
| 7 | `board_variant` == profile 的 `board_variant` | BLOCK |
| 8 | `bound_to` 必须指向存在的 `CH` id | BLOCK |
| 9 | `--files` 时，`status=final` 的图片必须存在且 >1KB | BLOCK |
| 10 | `--require-final` 时，有引用的资产不得是 `candidate` | BLOCK |

退出码：`0 PASS`｜`2 BLOCK`（结构性错误）｜`1` 仅 `--strict` 下把告警也判失败。

---

## 五、状态流转

```
planned → candidate → final
                └──→ rejected
```

- 生图成功只到 `candidate`；用户点头才改 `final`。
- 换版不删旧图：`name-v2.png`，但**只有 `final` 那个文件能进绑定**。
- `01_资产库/` 扁平；⛔ 不再有 `图片/角色/`、`图片/场景/` 这类子目录。

## 六、旧项目迁移

| 旧文件 | 迁到 |
|---|---|
| `资产盘点.json` 的角色/场景/道具 | `assets[]`，按类型分配 id |
| `_资产映射.json` 的 name→file | 合并进 `name` / `file` |
| `_盘点.tsv` 的「候选/定稿」 | `status` |
| `_形象规划.json` 的 images | 角色的 `states`（`name`=状态名，`episodes`=场号所在集） |

迁移方式：按上表**人工映射**一次；本包不提供自动迁移脚本（旧文件只读，不删）。
迁移后跑 `assets_check.py --files --require-final`，0 才算完成。
