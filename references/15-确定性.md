# 15 · 确定性工作流（本包取值）

> 方法论全文见 `manju-creation/references/确定性工作流.md`；本文件只写**本包怎么落地**。
> 一句话：**能机械判定的，一律脚本；必须逐字出现的，一律注入 + 命中率 100%。**

---

## 一、五级定级

| 级 | 谁做 | 本包用在哪 |
|---|---|---|
| **L0** | 模型判断 | 分镜怎么切、景别怎么选、峰值、表演、哪版更好 —— **必须标「需人工」** |
| **L1** | 模型出结构稿 → 脚本注入固定串 → grep 100% | 角色设定板固定段；提示词【资产盘点】/强制声明/禁用句 |
| **L2** | 脚本做物理切割，不做创作 | 绑定表 pn 分配、作业单 images 顺序、交付清单 |
| **L3** | 硬门断言 + 退出码 | 时长上限、单镜下限、资产存在、pn 连续、台词多重集 |
| **L4** | 台账 + 幂等 | 生图 / 出片 / 下载，已有产物跳过 |

**口诀**：3 行代码能判对错 ⇒ 至少 L3；判不了对错只能判好坏 ⇒ L0，标「需人工」。

---

## 二、三条铁律

1. **可判定必程序化**：同一约束只允许两种形态 —— 能跑的脚本，或明确标注「需人工」。⛔ 没有第三种「写在文档里指望模型遵守」。
2. **逐字内容不交给模型抄**：台词、风格主干、pn 块、强制声明、禁用句、音色锚点串，一律注入 + 校验命中率 100%。只注入不校验 = 没做。
3. **硬门必须有退出码，且三态**：

```
0 = PASS    告警只呈现，允许继续
2 = BLOCK   仅结构性错误：字段缺失 / 编号冲突 / 文件不存在 / pn 不连续
1 = 仅 --strict 下出现（交付前想把告警也清干净时）
```

⛔ 只打日志不返回码的检查器 = 摆设。

## 三、本包四道硬门（P7.5 之后、P9 之前，全绿才许提交）

| # | 门 | 脚本 | 判据 |
|---|---|---|---|
| 1 | 分镜组结构 | `storyboard_check.py` | 组时长 ≤ profile 上限 · 单镜 ≥1.2s · 出场资产列在 · 名字在清单里 |
| 2 | 绑定四方对账 | `bind_check.py` | 表 / 绑定 / 提示词 / 作业单 的 pn 顺序完全一致 |
| 3 | 提示词结构 | `vidu_check_prompts.py` | 结构 / 时长 / pn 连续 / vm ≤3 / 台词逐字 / `<>` 绑定 / 音色通道 |
| 4 | 形象与参考预检 | `bind_assets.py` | 多形象状态合法 · 文件存在 · 图 ≤ 渠道上限 · 音 ≤3 |

> ⛔ 四道门全绿才允许提交。任一为红 ⇒ 修完重跑，不得「先提交再说」。
> ⚠ 四道门只查形式。峰值、景别、表演 —— **L0，人工判**。

## 四、四个可复用模式

### A · dry-run 前置（花钱调用必须有）

```
探活 → dry-run（本地校验，不连服务端）→ 报价/记账 → 执行 → 等终态 → 取件
```
生图与出片都走 `--dry-run`；缺一道 = 白烧钱。

### B · 多重集断言（台词）

改任何提示词前后：全篇台词多重集相同；索引不缺不重不换序；说话人归属不变。
任一条不成立 ⇒ **不落盘**（`vidu_check_prompts.py --script`）。

### C · 预切 → 硬门 → 定向返工

分镜组超长：先按 Shot 边界**物理预切**，再跑硬门；只重做违规组，其余逐字不动。
⛔ soft 偏好（优先档位）不当硬门，否则预切会被判更差。

### D · 台账 + 幂等

出图/出片：每个任务落台账（id / 状态 / 产物 / 时间）；重跑先读台账，已完成跳过。
⛔ 无台账裸跑批量；⛔ 用 `| tail` 接管道跑批量。

## 五、各阶段定级（与 `00-流程总表.md` 一致）

| 阶段 | 手段 | 级 |
|---|---|---|
| P0 初始化 | 四问落 profile，缺则退出码 2 | L3 |
| P1 剧本 | 只加结构与时长标注，不改字 | L2 |
| P2 盘点 | LLM 出清单 → schema 校验 | L0→L1 |
| P3 设定板 | LLM 填 JSON → 脚本渲染固定骨架 → 校验 | **L1** |
| P4 生图 | 预检 → 一张一交 → 台账 | L4 |
| P5 分镜组 | 按 profile 预切 → 硬门 → 定向返工 | **L2+L3** |
| P6 绑定 | 脚本分配 pn，冻结 hash | **L2+L3** |
| P7 写词 | 只写戏，不写 pn、不抄固定串 | L0（人工） |
| P7.5 注入 | pn 块 / 强制声明 / 禁用句 注入 | **L1** |
| P8 作业单 | images 顺序逐字抄绑定 | L2 |
| P9 出片 | dry-run → 提交 → 轮询 → 取件 | L3+L4 |

## 六、反模式（本包明令禁止）

1. 把「单组 ≤16s」写进提示词，指望模型遵守
2. 门不过就重跑 LLM（不收敛，还覆盖已好的组）
3. 只注入不校验
4. 先落盘再校验
5. 把优先档位当硬门
6. 无台账裸跑批量
7. 只打日志不返回退出码
8. 让模型手写 pn 顺序
