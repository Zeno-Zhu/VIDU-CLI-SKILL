> 用法：阶段 C 写每一集之前读一遍。

---

## 一、你拿到什么，要交什么

**拿到：** seed 骨架（目标秒数、钩子、悬念、待认领爽点、候选场景与人物）+ 大纲里这一集的梗概 + 场景卡与角色信息 + 前一集的结尾悬念。

**要交：** 把这一集的 `scenes` 从空写满。

**一次写一集。一批 ≤ 3 集。** 剧本是全管线改得最凶的一层，小批量出、快拍板、再往下写。

---

## 二、八条硬规则

### 1. 时长预算先于一切

目标秒数就是墙。75 秒一集约 **22 个节拍**（13 句台词 + 9 拍动作）。

```
台词秒数 = 非空白字符数 ÷ 4.5
动作秒数 = 动作节拍数 × 2.5
每集合计须落在 目标 × (1 ± 15%)
```

**写超先砍动作，写欠补冲突不补寒暄。**

### 2. 单句台词 ≤ 35 字，一口气说得完

长句拆成两句，中间可以插一拍动作或对方的反应。

> 不是所有台词都要短。是**单句**要能一口气说完。人物要讲清一件事，可以说三句。

### 3. 谁的话像谁

看大纲角色表里的性情、身份、说话方式（有 `cast.json` 更全）。**盖住名字也认得出是谁在说话**，这条做不到，人物就是纸片。

### 4. 动作一拍一件事，叙述体，动作要「常见」 ⛔

「胡二爷的手停在半空，笑僵在脸上」是一拍；「气氛很尴尬」不是画面，写不得。

**动作里不许出现引号台词**（`「」『』""`）——台词混进动作就没法计秒、没法喂 TTS。

#### 常见动作是 AI 生成的生命线

这条戏最终是视频模型演的，**它只会演它见过千万次的动作**：

| 写法 | 例子 | 生成结果 |
| --- | --- | --- |
| ✗ 精确物理交互 | 货担撞上船帮，铜铃碎响。老周伸篙一挡，担子稳稳落进舱里 | 篙、担、船帮三物交互，必崩 |
| ✓ 常见动作 | 胡二爷挑着担子上船，老周搭手帮他把担子卸进舱里 | 挑担、搭手、放下，全是常见动作 |

**判据：这个动作在生活视频里常见吗？**

| 放心写 | 改写或删 |
| --- | --- |
| 上船、坐下、递东西、点头、回头、抱紧、站起来、推门、拿起、放下、转身、走开、抓住手腕、把东西推过去 | 用工具挡住某物、微表情（睫毛颤）、以寸计的位移（收了半寸）、比喻性画面（像被雾攥住的茧）、三件以上物品同时交互 |

**戏剧信息靠常见动作的组合与时机给，不靠动作本身的精巧。**

### 5. 每场至少一个动作节拍

三句台词之间没有一个画面动作，就该问自己：这场戏观众在看什么？

> 纯对白的场 = 广播剧。AI 生成时没有画面可写。

### 6. 钩子不是标签，是第一拍，而且要在运动中给

每集第 1 拍冷开场。钩子的具象必须**带主体运动**：

| ✗ 静物特写一闪 | ✓ 运动中给 |
| --- | --- |
| 旧皮箱抱在怀里，指节掐白 | 抱着旧皮箱在雾里跑 |

奔跑、追赶、挣脱、猛地按住，都行。静态细节特写（掐白的指节、口袋的轮廓）留给第二落点兑现（登船、开箱）。

`hookBeat` 认领它——**门查位置，必须落在全集前 4 拍内**；有没有运动是写作纪律，门查不了。

**上一集的结尾悬念要在开场接住。接住不等于立刻解开。**

### 7. 结尾最后一拍必须是悬念

一句没说完的话、一个没解释的动作、一声来历不明的响。

`cliff` 字段写效果说明，戏里落成具体的一拍。

### 8. 认领的爽点要有戏扛

`beatsClaimed` 里的每个爆点，这一集里必须有一段**连续节拍**在兑现它。

**爆点是演出来的，不是梗概里说说。**

## 三、修改纪律

错误最常从单点修改混进来。

### 改一拍，连读三拍

任何节拍改动后，把前后各一拍连起来重读，专查三样：

1. **人物位置**——上一拍还在岸路，下一拍不能已经在栈桥上
2. **道具在手状态**——上一拍还在他手里，下一拍不能没了
3. **谁在场**——上一拍走了的人，下一拍不能开口说话

> 写作时空间状态在你脑子里，改的时候它不在。**连读是把状态找回来的唯一办法。**

### 改画面，带声景

剧本动作一改，下游分镜的描述、声景、分镜图三处要一起动。**源头在剧本这层就要有意识。**

## 四、手感规则（不设门，但决定戏好不好看）

- **台词短，动作密。** 短剧的对话节奏比电视剧快一倍——两三句就要有一次动作或反应插进来，**超过四句连续对白就闷了**。
- **潜台词写进 `delivery`。**「嘴上让座，身子没动」这种表演层的信息放括号里，别把潜台词直接写成台词说破。
- **VO 省着用。** 心声是强调不是拐杖，**一集三到五条封顶**。用在「表面平静、心里翻江倒海」的错位时刻最值。75 秒的容量比三分钟紧，VO 一多就变成有声小说。
- **人群按大纲的 `crowdPlan` 拆。** 谁在前景说话、谁在背景反应，写清楚。
- **场次切换是免费的，注意力不是。** AI 换景不要钱，但观众每换一次景要重新建立空间感。**75 秒里换四个景，还不如在一个景里把戏拧紧。**

## 五、常见病

| 病 | 症状 | 治法 |
| --- | --- | --- |
| 广播剧 | 整场只有台词 | 每两三句台词之间插一拍画面动作 |
| 文学病 | 动作写成美文：伸篙一挡、睫毛颤、退了半寸 | 换成常见动作，见硬规则 4 |
| 开场死画面 | 第一拍是静物特写 | 同一具象换成运动中给，静帧挪到第二次出现 |
| 空间跳变 | 上一拍在岸路跑，下一拍写栈桥才露出来 | 改一拍连读三拍 |
| 注水 | 寒暄、让茶、问路占了半集 | 删。每一拍要么推进剧情要么翻转关系 |
| 演讲癖 | 一个人连说四句 | 拆给对手，或用动作打断 |
| 全知病 | 台词把信息说尽 | 信息藏进动作和 `delivery`，台词只说三分 |
| 断头戏 | 结尾平收 | 最后一拍换成悬念，哪怕只是一声汽笛 |
| **超时** | 跑 validate 发现 90 秒 | 先砍动作拍，再压台词长句，最后才动结构 |
| **欠时** | 跑 validate 发现 60 秒 | 补一场冲突，不补寒暄。加一个对手的反击，别加闲聊 |

## 六、写之前先问三句

1. 这一集卖的是大纲里承诺的那个东西吗？（`beatsClaimed`）
2. 第 1 拍能不能让人不划走？（钩子具象 + 运动）
3. 最后一拍之后，观众会不会想点下一集？（`cliff`）
