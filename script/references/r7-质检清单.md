# r7｜质检清单

> 源：《无限轮回宇宙·短剧共创 设定》第十章 10.1–10.7、第十一章 11.1–11.7
> 用法：阶段 A 结束查一次（一、二）、阶段 B 骨架拍板前查一次（三、四）、阶段 C 每集定稿查一次（五、六）。

---

## 一、世界观一致性（阶段 A）

1. 是否违反母宇宙根本规则？
2. 是否无理由改变主角核心人格？
3. 前世知识与能力的使用是否合理？
4. 当前世界力量是否符合当地规则？
5. 是否误把局部神明或系统设为母宇宙最高意志？
6. 是否错误处理固定女主锚点？
7. 是否提前揭露未经确认的终极秘密？

> 七问答不出「是」，不进阶段 B。脚本管不了语义，这七条只能靠人。

---

## 二、核心观看价值（阶段 A / B）

1. 当前世界篇真正卖什么？
2. 这个卖点是否已经在实际剧情中得到体现？
3. 人物是否具有记忆点？
4. 主要冲突、关系和事件是否有实际体验价值？
5. 是否存在「逻辑完整但整体普通」的问题？
6. 是否因为过度解释而削弱了爽感、喜剧、情绪或奇观？

---

## 三、开局有效性（阶段 B / C 第 1 集）

1. 第一集是否尽快进入核心看点？
2. 是否存在大量低价值前史？
3. 主角是否拥有清楚的当前行动或欲望？
4. 观众是否能理解当下阻力？
5. 开局已经建立的期待，是否能在后续兑现？
6. 前三集是否持续提供新的观看价值？

---

## 四、剧情运行（阶段 B）

1. 场景是否具有推进、蓄力或即时体验价值？
2. 人物是否长期停留在同一状态？
3. 核心梗是否仍然有效？
4. 重要结果是否得到后续继承？
5. 是否过度依赖新反派、新事故和机械反转？
6. 已经形成的重大期待是否得到足够兑现？
7. 是否存在需要提高的关键情绪峰值？

---

## 五、人物与关系（阶段 C）

1. 人物行为是否符合已有性格、欲望和认知？
2. 主角是否具有必要的主动性？
3. 人物是否因为剧情需要突然降智？
4. 不同人物的语言和行为是否有区别？
5. 关系变化是否真正通过选择和行动发生？
6. 是否为了「成熟、礼貌或所谓高级感」削弱人物冲突？

---

## 六、正式剧本质量（阶段 C）

1. 标题与场景格式是否统一？
2. 场景人物是否清楚？
3. 对白是否自然、可表演？
4. △ 动作是否可见、可执行？
5. 是否存在大量无效微动作？
6. 重要物件和人物状态是否连续？
7. 电话、画外声音和设备信息来源是否明确？
8. 是否混入小说化心理描写和作者总结？
9. 重要高值过程是否被过度省略？

---

## 七、修改优先级 ⛔

发现问题时，**按这个顺序处理**，不要平均用力：

```
1. 剧情成立
2. 核心观看体验
3. 人物魅力
4. 关系价值
5. 重要期待与结果
6. 剧本自然度
7. 后续制作可行性
```

**不为了追求形式完美而无限修改。已经成立的有效内容应当优先保护。**

---

## 八、AI 执行纪律（对应设定第十一章）

### 8.1 自动识别任务，不要求用户用固定命令

用户可能说：「我想让主角这次变成一头猪」「帮我设计一部玄幻短剧」「我要 80 集都市赘婿剧」「给我三种不同的故事方向」「帮我写全剧架构」「把这个脑洞扩展成 50 集细纲」「直接开始写第 1 集」「修改第 3 集的对白」「检查这个剧本有没有 AI 味」。

按实际任务执行，不要求用户记命令。

### 8.2 世界篇初始化优先

全新世界篇，无论信息是否充分，都先完成阶段 A。

- 已提供完整设定 → 直接整理校准，不重复发明
- 已初始化且确认 → 后续任务直接执行，不重复初始化
- 用户补充修改 → 按变更范围局部更新，不重新开始
- 用户要求同时做初始化和后续任务 → 可以连续执行，但**必须先完成独立的世界篇初始化设定，不能省略或混入后续正文**

### 8.3 优先保护用户当前创作方向

用户明确提出的题材、核心脑洞、人物关系、卖点和剧情方向，应当优先保留。

如果与母宇宙不可变规则冲突，**指出具体冲突，并提出不破坏核心创意的最小调整方案**。

如果用户明确要求修改母宇宙规则，作为母设修订任务处理，说明必要影响，不静默更新其他窗口无法获知的共享事实。

### 8.4 不擅自扩展创作任务

| 用户要求 | 不要做 |
| --- | --- |
| 共创 | 直接输出完整剧本 |
| 细纲 | 直接写全部正式对白 |
| 剧本 | 额外生成长篇世界观报告 |
| 定向修改 | 重写整个故事 |

### 8.5 创作自由优先 ⛔

**不得机械套用：**

固定三幕结构 / 固定反转次数 / 固定情绪曲线 / 固定数量的副梗 / 固定数量的高值峰值 / 每集必须打脸 / 每部必须升级 / 每篇必须谈恋爱 / 每篇必须发现线索 / 每部必须用死亡结尾。

这些都应根据当前世界篇真实需要决定。

### 8.6 正式创作与讨论状态分离

- 讨论或分析时：可以解释创作判断并提出方案。
- 要求正式世界设定时：输出可直接使用的设定内容。
- 要求正式剧本时：只保留作品本身需要的内容。

**正式设定和正式剧本中，不混入大量创作过程、优化解释、自我评价和被放弃的方案。**

### 8.7 不预设商业表现

应主动提高观众进入、观看、情绪消费和续看意愿。

**但不能仅凭剧本设计就断言必然爆款、必然获得某种播放量或付费成绩。**

允许参考爆款题材与机制。应萃取**观看体验、人物关系、核心梗与高值节点的有效方法**，而不是直接复制其他作品的独特人物、设定和连续事件。

---

## 九、一句话总检

一集定稿前，只问一个问题：

> **如果观众只看这一集，他会不会想看下一集？**

会 → 交。不会 → 回 `r6` 找病，别回 `r1` 加设定。
