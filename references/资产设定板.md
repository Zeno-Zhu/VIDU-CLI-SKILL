# 资产设定板：把「人、地、物」先钉死

这是全流程的第一步和第二步。**先有能复用的资产，才有稳定的片子。**

读完剧本（或聊完需求）别急着写分镜，先做这件事：**盘一遍资产 → 一张张生成设定板 → 交给人确认**。

---

## 一、为什么是「设定板」而不是一张随手图

一句话生成几十组视频，最容易出的问题不是画得丑，是**每一组都换一张脸、换一个房间**。

设定板的作用是把标准钉死：

- **一张板定四件事**：长相、服装、空间结构、材质
- 后面几十组全部引用同一张图，模型每次都能抓到同一个锚点
- 人看图也能一眼判断对不对，比看十张零散图快

**单张正面图不够。** 只有正面，模型不知道侧脸、后脑、肩线、衣服背面怎么长，一到转圈就自由发挥。设定板把侧后也交代了，跑起来才不漂。

---

## 二、资产分几类

| 类型 | 装什么 | 什么时候必须有 | 生成比例 |
|---|---|---|---|
| **人物** | 主角、对手、关键配角 | 有正脸、有台词、有连续出场 | 16:9 四宫格 |
| **场景** | 主要空间（内景 / 外景） | 同一空间出现 ≥2 组，或要交代空间关系 | 16:9 四宫格 |
| **道具** | 推动剧情的物件、要卖的产品 | 有特写、被拿取、承担信息 | 16:9 四宫格 |
| **音色**（可选） | 每个说话人的参考音 | 用户希望声音统一、可辨识 | 3–8 秒 wav |

**四类之外不要自己加。** 光线、色调、风格写进统一风格模块，不单独占一个资产。

### 哪些不用做

- **只露一次脸、三五句台词的路人**：并进已有角色，或用背影、手、声音代替
- **只出现一次的空镜空间**：写进提示词的场景描述，不用单独生成
- **衣服、发型的变化**：在原人物板上写清变化，不重开一个资产（除非是全片第二套主线造型）

判断标准只有一条：**后面还会不会再引用它。** 不会再引用，就别做板。

## 三、盘点表：先出表，再出图

盘完写成一张表，落盘 `out/资产/_盘点.tsv`（制表符分隔）：

```
类型	名字	文件名	有没有	父系	用途
人物	男主	男主.png	没有	—	G01–G12 全程
人物	男主父亲	男主父亲.png	没有	男主	G07 回忆、G09 对峙
场景	小饭馆内景	小饭馆内景.png	没有	—	G01–G05、G11
道具	旧怀表	旧怀表.png	没有	—	G06 特写、G12 结尾
音色	男主音色	男主音色.wav	有	—	全片对白
```

- **父系** = 这张图照着谁生。同一人换状态、同一空间换视角、一家人，必须填。不填，第三组就换脸
- **有没有** = 有就直接复制进 `out/资产/`，没有才生
- **文件名与名字保持一致**，后面 `--image` 引用靠它，改一个字母就断链

盘点完**停下来给用户看这张表**，问一句：够不够，有没有可以合并的路人。

## 四、设定板的固定骨架（六段，顺序别动）

不管人、地、物，都按这六段写。模型对稳定结构更听话，你也好复用。

```
① 版式     ：什么板、几宫格、画面里不许有字
② 主体     ：这是什么，把可辨识特征写死
③ 必一致项 ：四格必须一样的那些点（比例、结构、颜色、位置）
④ 细节模块 ：每一格具体放什么
⑤ 材质与光 ：反光属性、光从哪来、背景什么颜色
⑥ 禁止项   ：不出现什么（写死，模型最认这段）
```

**③ 和 ⑥ 是板子的命。** 少了 ③，四格各长各的；少了 ⑥，画面里会飘出文字、第二个人、多余家具。

**长度控制在 600 字内。** 平台单条提示词上限 2000 字，写太长模型抓不住重点，反而更乱。

## 五、三套内置模板（直接抄，方括号替换）

> 这三套是**通用骨架**，不是唯一答案。要加格、减格、换画风、改成三视图，都可以改——只要保住「必一致项」和「禁止项」两段。

### 5.1 人物设定板

```
人物设定板，[画风：真人写实 / 国漫 / 插画]，四宫格 2×2 排版，格间留白，
画面内不出现任何文字、数字、箭头、色卡标注。

主体：[性别]，[年龄段]，[体型]，[发型与长度]，[服装：上衣/下装/鞋/配饰，
颜色与材质写死]，[可辨识特征：疤、痣、眼镜、旧伤、纹身，写清位置]。

左上一（主视角）：正面全身，站立，双臂自然下垂，中性表情，平视，头顶留白。
右上一：四分之三侧身，同一姿态，交代侧脸轮廓与肩线。
左下一：正侧身，交代服装侧面结构、发型长度、鞋型。
右下一：腰部以上正脸近景，交代五官比例、皮肤质感、眉眼间距。

一致性要求：四格是同一个人，五官比例、发际线、脸型轮廓、左右脸特征完全一致；
服装颜色、纽扣、口袋、褶皱走向一致；身高与头身比一致。

材质与光：柔和顶部柔光加正面补光，无强投影，背景统一浅灰、均匀无渐变。
[真人写实] 皮肤保留毛孔与细微起伏，不磨皮、不打美颜光。

禁止：不出现第二个人，不出现手持道具，不出现文字与品牌标识，
不出现夸张表情与动作，不出现分格线以外的装饰。
```

### 5.2 场景设定板

```
场景设定板，[画风]，四宫格 2×2 排版，格间留白，画面内不出现任何文字与标注。

空间：[地点全称]，[建筑或房间类型]，[面积感与层高]，[年代与地域特征]。

结构（四格必须一致）：门在[方位]，窗在[方位]，[主要家具或设备]在[方位]，
地面是[材质]，墙面是[材质与颜色]，顶部是[结构]。

左上一（主视角）：从[进门位置]朝[主方向]拍，同时看到[主家具]与门窗关系，广角。
右上一：反打，从[对面墙角]回看门口，交代进门动线与纵深。
左下一：[关键操作区]特写：[台面/货架/工具/工位]，材质与使用磨损。
右下一：[光源方向]的光线状态：白天/夜晚/灯光，写清色温与光从哪进、落在哪。

一致性要求：四格是同一个空间，门窗位置、家具摆位、墙色、地面材质完全一致，
不得增删大件家具。

人物：不出现人物；[需要比例参考时] 可有一名远景背影，不露正脸。

禁止：不出现可读文字招牌（招牌留空或纯色块）、不出现现代穿帮物件、
不出现杂志级布景感、不出现分格线以外的装饰。
```

> 招牌那句别省。要中文招牌，模型十有八九写错字——**招牌留白，字后期加**。

### 5.3 道具设定板

```
道具设定板，棚拍产品感，[画风]，四宫格 2×2 排版，格间留白，无文字无标注。

主体：[道具名]，[尺寸感]，[材质]，[主色与辅色，写死色相]，
[结构：几段、几个部件、接口、磨损位置]，[状态：全新 / 有使用痕迹 / 破损]。

左上一：45 度俯视整体，居中，浅灰背景，柔光箱打光。
右上一：正俯视顶视图，交代完整轮廓与比例关系。
左下一：[关键结构]特写：[开关/接口/纹样/刻字位置]，可见材质颗粒与边缘倒角。
右下一：[使用状态]：[打开/合上/握持/点燃/倾倒]，交代与手或另一物件的关系。

一致性要求：四格是同一件物品，尺寸比例、颜色、结构件数量、磨损位置一致，
高光位置一致。

材质：写清反光属性（哑光 / 釉面 / 金属拉丝 / 纸质纤维），
表面颗粒与瑕疵程度写死。

禁止：不出现可读文字、不出现品牌 Logo、不出现价格标签、不出现多余配件。
```

## 六、出图命令

```bash
# 人物（真人题材记得 --tail min）
python scripts/vidu.py image \
  --prompt-file out/资产/_提示词/男主.txt \
  --name 人物/男主 --ratio 16:9 --tail min

# 场景
python scripts/vidu.py image \
  --prompt-file out/资产/_提示词/小饭馆内景.txt \
  --name 场景/小饭馆内景 --ratio 16:9 --tail min

# 道具 / 产品
python scripts/vidu.py image \
  --prompt-file out/资产/_提示词/旧怀表.txt \
  --name 道具/旧怀表 --ratio 16:9 --tail min
```

- 提示词超过两百字就用 `--prompt-file`，别塞命令行
- **`--tail` 按画风选**：真人 `min`，半写实 `mid`，动漫国漫默认 `full`。真人用 `full`，皮肤和布料纹理会被磨平
- 一家人后生的那张加 `--ref 人物/男主.png`，提示词写「角色是图1的父亲，五官像图1」，**不许另写一套外貌形容词**

## 七、出完图，必须做三件事

### 第 1 件：自己先看

一张张打开看，别信 `success`。下面六条不全过，就重跑：

| 查什么 | 不合格的样子 |
|---|---|
| 是不是同一个人 | 四格脸型或眼距不一样 |
| 服装是否一致 | 一边有口袋一边没有，颜色深浅不同 |
| 有没有文字 | 板面冒出中文、英文、数字、水印 |
| 有没有多余的人或物 | 背景里站着路人，道具旁边多出配件 |
| 结构对不对 | 门窗位置自相矛盾，六格房间变两个房间 |
| 画风对不对 | 该写实的出成插画，或反了 |

**中文错字最常见的重灾区是道具上的刻字和场景招牌。** 板上一出现清晰可读的字，进视频就是变形字，直接判废。

### 第 2 件：停下来给人看

把图给人看，只问一句：

> 这个人 / 这个空间 / 这个物件，对不对？哪里不像，我改。

**不要问「你觉得怎么样」。** 太开放，用户答不上来。给具体选项：脸型、年龄感、服装、气质。

### 第 3 件：说清这是通用模板

**这句每次都要说，不能省。** 用户以为内置的就是最好的，后面不会自己调，白白浪费模型能力。

> 这三套设定板模板是内置的通用骨架，不是唯一写法。
> 你可以直接改，比如「人物板换成三视图」「加一格表情」「场景要夜景」；
> 也可以自己写一份模板给我，我照着填——放在 `out/资产/_模板/人物.txt` 就会优先用你的。

模板优先级：**用户的 > 内置的**。看到 `out/资产/_模板/` 下有对应文件，先用它，只把方括号槽位填上。

## 八、设定板和「出片参考图」不是一回事

这是最容易踩的坑：**板子好看，不等于喂给视频模型就好用。**

| 用途 | 用什么 | 原因 |
|---|---|---|
| 给人确认、定标准 | 设定板 | 四格信息全，一眼判断 |
| **人物出片** | **单张正视图（9:16）** | 视频模型看到多格拼贴，容易把分格、多视角带进画面 |
| 场景 / 道具出片 | 优先单图；没有就用板 | 用板时必须在提示词里写死禁用句 |

人物建议这么办：**先出板（确认长相）→ 再出一张同描述的单图（去片场用）**。单图就是把上面模板里「版式」「细节模块」「一致性要求」三段删掉，只留主体、材质与光、禁止项，`--ratio 9:16`。

真要用板直接出片，提示词里必须补这一句：

```
参考图仅用于人物长相与服装 / 空间结构与材质，画面中不得出现分格、多视角拼贴、
文字标注与色卡。
```

不写这句，就等着画面里飘出一张四宫格。

## 九、常见崩坏与改法

| 现象 | 多半是这句没写 | 怎么改 |
|---|---|---|
| 四格长得不像一个人 | 少了一致性要求 | 把「五官比例、发际线、脸型」逐项写进必一致项 |
| 板面冒出中文乱字 | 少禁止项 | 加「画面内不出现任何文字、数字、水印」，招牌留白 |
| 场景一格一个样 | 结构没写方位 | 门窗、主家具全部写「在哪个方位」 |
| 服装每格不同 | 只写了颜色没写部件 | 补纽扣、口袋、领型、袖长 |
| 真人板像磨过皮 | 尾缀用错 | `--tail min` |
| 写实板出成插画 | 画风没写死 | 开头第一句写「真人写实摄影」，禁止项加「不出现插画线条与笔触」 |
| 道具比例怪 | 尺寸感没给 | 写「约成人手掌大小」或给出参照物 |

改的时候**只改那一段，别整篇重写**。整篇重写等于换了个盲盒，上一版对的地方也会丢。
