# 40 · 质检门

> 四道门，全绿才允许提交。**只查形式与结构**；戏好不好是 L0，人工判。
> 退出码统一：`0 PASS（告警只呈现）｜2 BLOCK｜1 仅 --strict 下告警也判失败`。

---

## 门 1 · 分镜组结构

```bash
python scripts/storyboard_check.py "…/EP01_分镜组.tsv" \
  --assets "…/资产清单.json" --require-assets
```

查：组时长 ≤ profile 上限 · 单镜 ≥1.2s · 组 ≥2 镜 · 出场资产列在且非空 · 资产名在清单里 ·
空镜占比 / 景别机位重复 / 台词密度（警告）。

**BLOCK**：超上限、单镜过短、单镜组、缺出场资产、资产名不存在。

---

## 门 2 · 资产清单

```bash
python scripts/assets_check.py --file "…/资产清单.json" --files --require-final
```

查：id/name 唯一 · 文件名 = 资产名 · 状态合法 · 角色有 states 且集数不重叠 ·
有台词有音色卡 / wav · 板式 = profile · `bound_to` 有效 · final 文件存在。

**BLOCK**：任一结构错。

---

## 门 3 · 绑定四方对账

```bash
python scripts/bind_check.py \
  --bind "…/EP01_资产绑定.json" \
  --prompt "…/EP01_提示词_自己人.txt" \
  --jobs "…/EP01_jobs.json" \
  --assets "…/资产清单.json" --strict
```

查：源文件 hash 未变 · 资产都是 final · 文件存在 · 表/绑定/提示词/作业单的 pn 序列完全一致 ·
vm 序列一致。

**BLOCK**：任一不一致。这是「换脸 / 换嗓」的唯一拦截点。

---

## 门 4 · 提示词结构

```bash
python scripts/vidu_check_prompts.py \
  --new "…/EP01_提示词_自己人.txt" \
  --asset-dir "…/01_资产库" --panel-dir "assets/常用符" \
  --voice-dir "…/_资产提示词" \
  --script "…/_剧本全文.txt"
```

查 A—J：结构 / 标题 / 时长 / 资产（pn 连续、≤上限、名字存在）/ 音色（发言者 ≤3、vm 与角色一致）/
台词逐字多重集 / `<>` 绑定 / 格式 / 正文（无 `《》`）/ 音色通道。

**BLOCK**：台词改字、pn 不连续、音色通道判错、`<>` 缺失。

---

## 提交前顺序（一条命令链）

```bash
python scripts/assets_check.py --file "…/资产清单.json" --files --require-final && \
python scripts/storyboard_check.py "…/EP01_分镜组.tsv" --assets "…/资产清单.json" --require-assets && \
python scripts/bind_check.py --bind "…/EP01_资产绑定.json" --prompt "…/EP01_提示词_自己人.txt" \
  --jobs "…/EP01_jobs.json" --assets "…/资产清单.json" && \
python scripts/vidu_check_prompts.py --new "…/EP01_提示词_自己人.txt" \
  --asset-dir "…/01_资产库" --voice-dir "…/_资产提示词" --script "…/_剧本全文.txt"
```

全过（退出码 0）才 `vidu.py run`。

## 什么不进硬门（L0，需人工）

- 峰值选得对不对
- 景别合不合理
- 表演是否到位
- 两个版本哪个更好
- 运镜是否服务剧情

这些写进交付说明，让用户判；⛔ 不要伪装成脚本门。
