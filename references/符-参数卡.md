# 符的参数卡：锁 / 变 / 禁 / 让

`prompts/符的生成.txt` 管**怎么把经验萃取成一张面板**（机制、变量、颗粒度）。
这份文件只补它不管的**运行期**问题：**这张符被挂上去之后，怎么和剧本、平台、别的符相处。**

一句话：**做符是把知识压成图；挂符是把图的控制力翻译成四个参数位。**

---

## 一、四个参数位

每张符都要能回答四个问题。答不出，这张符只有观赏价值，挂上去只会污染画面。

| 位 | 字段 | 问句 | 条数 | 缺了会怎样 |
|---|---|---|---|---|
| **锁** | `locks` | 这张符**靠什么成立**？哪几条一改，能力就废了 | 1—4 | 挂了等于没挂，模型按自己理解画 |
| **变** | `variables` | 下游**必须提供什么**，符才能落地 | 1—4 | 模型自己编，出来的东西和你脑子里的不一样 |
| **禁** | `negatives` | 这张符**最容易被带歪成什么** | 3—5 | 每次都要靠运气 |
| **让** | `defer` | 哪些**故意不管**，交给下游自己发挥 | 0—3 | 你会忍不住把一切都写死，符变成模板 |

### 判断问句（用这一个就够）

> **这个东西改了，是「能力不成立」，还是「只是换个样子」？**

- 不成立 → 写进 `locks`
- 只是换个样子，但**必须由剧本给** → 写进 `variables`
- 只是换个样子，**模型自己定就行** → 写进 `defer`

**别把四件事混成一件事。** 最常见错法：把「必须由剧本给的输入」写进锁里 —— 那张符就只能在一种戏里用。

### 例：符-运镜

```
locks     ：每个运动必有起点 → 路径 → 落点；一个镜头只承担一个运动任务
variables ：本镜的戏剧任务、主体位置、可用的运动幅度（由剧本/镜头给）
negatives ：无目的匀速晃镜；起落幅都在动的复合运动；运动与主体动作方向相反
defer     ：具体焦段、运动速度曲线、用不用辅助机位
```

**「一个镜头只承担一个运动任务」放锁里**，因为两个运动叠在一起，观众看不出是推还是摇——能力不成立。
**「焦段」放让里**，因为 35mm 还是 50mm 不改变运镜这件事成不成立。

## 二、主符与辅符：符链怎么搭

### 主符按「主要成功条件」选，不按关键词选

一条片子好不好看，取决于哪个条件最先崩——那个条件对应的符，就是主符。

| 场景 | 主要成功条件 | 主符 |
|---|---|---|
| 打斗 | 攻防因果、受力反馈 | 空间关系与动作可读性 |
| 两人对峙 | 轴线、关系镜、反应镜分配 | 对话戏镜头组织 |
| 摊牌 / 打脸 | 信息什么时候砸出来 | 情绪推进与信息释放 |
| 哭戏 / 崩溃 | 反应是否像真人 | 真人感表演 |
| 一组拍下来没重点 | 镜头任务和落点 | 镜头调度（总纲） |

**关键词只是线索，不能替代判断。**
一条对话戏里出现摔杯子，不等于要挂打斗符——如果观看价值还在两人的话上，主符仍是对话戏。

### 辅符只在「有独立缺口」时加

三问，全过才加：

1. 主符管不到这件事吗？
2. 这件事会独立地把片子搞砸吗？
3. 加进去不会和主符抢同一块控制权吗？

有一个否，就别加。**没有独立贡献的辅符，等于给模型加了一条互相矛盾的指令。**

### 槽位上限：主符 1 + 辅符 1

不是审美问题，是资源问题：Vidu 一次最多 9 张参考图，人物/场景/道具/音色占完，符最多还剩 2 格。
想挂三张符，先问自己是不是想用一张符解决两件事——那就该拆符，不是叠符。

### 总纲符与单点符不并列

总纲符（`type: 总纲`，一张管一类事的符）说的是「这一类事共同怎么定」；
单点符说的是「这一种运动怎么做」。
**两张一起挂，模型会收到两套调度指令，构图必然打架。**

正确用法：总纲符定方向 → 单点符做细化，但**一次只挂一张**。需要两张时，说明这一组该拆成两组。

### 常见组合（各挂一张，别贪多）

| 主符 | 辅符 | 适用 |
|---|---|---|
| 镜头调度 | 对话戏镜头组织 | 多人对话、盘问、谈判 |
| 空间关系与动作可读性 | —— | 追逐、打斗、走位复杂 |
| 情绪推进与信息释放 | 真人感表演 | 摊牌、反转、打脸 |
| 镜头调度 | 常用运镜 | 一组镜头调度没主意，且运镜平 |

**「——」也是答案。** 很多组一张都不用，那才是常态。

## 三、冲突裁决：符和剧本打架时谁赢

六级，从上往下，**高级别永远压低级别**：

| 级 | 谁 | 说明 |
|---|---|---|
| 1 | **平台硬限** | Vidu 单组 1—16 秒整数、9 图 3 音、提示词 2000 字、单镜 ≥1.2 秒。符说了不算 |
| 2 | **用户明确锁定** | 「这条必须 8 秒」「这张脸不能变」 |
| 3 | **剧本事实与已确认资产** | 角色长相、服装、场景、时代、上下组连续性 |
| 4 | **符的锁** | 这张符成立的前提 |
| 5 | **符的建议** | 符里写的默认做法、节奏、强度 |
| 6 | **AI 自由发挥** | 焦段、配色、细节 |

### 冲突时必须说出来

> ⛔ **不许删掉一方，然后假装两边都做到了。**

例：剧本写「8 秒两人对坐说完三句话」，同时挂了对话戏符（建议 4 个机位）。
8 秒放不下 4 个机位——这是**平台+剧本压符**。处理：

1. 按剧本走，压到 2—3 个机位；
2. 在交付里说明一句：「本组 8 秒，对话戏符的 4 机位压到 3 个，砍掉了插入镜」；
3. 不重写符，也不偷偷改剧本。

**符是咨询，不是法律。** 但符的锁（第 4 级）一旦被压，要记下来——连续三次被压，说明这张符的适用范围该改。

## 四、负面约束：按符定制，不抄通用清单

### 每张符写 3—5 条自己的

抄「不要变形、不要糊、不要多手指」这种清单没有意义——那是全片的底线，不是这张符的。
符的负面约束要写在**这张符最容易被带歪的方向**：

| 符 | 它最容易被带歪成什么 |
|---|---|
| 对话戏镜头组织 | 机械正反打、越轴、反应镜全是同一侧脸 |
| 表情绪推进 | 靠皱眉瞪眼演情绪、信息一次全倒出来 |
| 真人感表演 | 摆拍感、情绪先行因果后补、动作幅度过大 |
| 常用运镜 | 无目的晃镜、运镜与主体动作方向相反 |
| 空间关系 | 接触没有受力、人物穿模、方向连不上 |
| 镜头调度 | 一组里多个注意力落点、景别全是一个档 |

### 三类东西**不要**当通用禁止项

1. **颗粒、噪点**——年代戏、纪实感可能是故意的
2. **运动模糊**——打斗、追车要的就是它
3. **强烈光晕、非写实曝光**——风格化选择，不是缺陷

用户明确要的风格化，写进 `defer`，不要写进 `negatives`。

### 永远都有的一条（系统级，不占符的配额）

> **符本身不进画面。** 不出现面板、文字块、图表、分隔线，不复制其配色与版式。

这条不写在每张符里，写在调用模板里（见 `prompts/符-生成.md` 用符那节）。

## 五、五维分：这张符够不够格当定稿

三道闸（机器 / 自查 / 用户）管的是「能不能用」。这一节管的是**「值不值得留」**。

**五项，各 20 分，满分 100。只给定稿打分，候选不打。**

| 维 | 问句 |
|---|---|
| **D1 可复用性** | 换一个剧本、换一组人，这张符还成立吗？还是只对那一个案例有效 |
| **D2 控制力** | 它有没有真的控制住生成结果？还是写了一堆形容词 |
| **D3 清晰度** | 下游模型能不能一眼看出「做什么、按什么顺序、做到什么算完」 |
| **D4 参数完整度** | 锁/变/禁/让四个位齐不齐？有没有互相冲突 |
| **D5 稳定性设计** | 身份一致性、动作连续、物理关系、风格污染，考虑了吗 |

### 等级与门槛

| 级 | 分 | 怎么处置 |
|---|---|---|
| **S** | 92—100 | 母符级，可以往下拆子符 |
| **A+** | 86—91 | 重要生产任务直接用 |
| **A** | 78—85 | **定稿门槛**，常规生产可用 |
| **B** | 65—77 | 仍算候选，补参数再评 |
| **C** | 0—64 | 当灵感，别进生产 |

- **A（78）以下不许标 `定稿`。** 标了就是拿没验证的图指导几十个镜头。
- **设计评级 ≠ 实测评级。** 没跑过片子，就只能说「设计 82 分」，不能说「实测 82 分」。
- **不要每张都打分。** 简单的一次性符（比如「怎么拍开水倒进杯子」）不值得走五维，用户点头就定稿。

### 打分表（照这个填，别自由发挥）

```json
"score": {"D1": 18, "D2": 17, "D3": 19, "D4": 16, "D5": 17},
"grade": "A+"
```

## 六、符类缺口：按这 14 类对一遍

这是从参考体系搬来的**能力域分类**（不是我们的知识形态分类，两者正交）。
拿它当清单：**你库里有几张，覆盖了哪几格，该补哪几格。**

> 本包**不含内置符库** —— 下表「现有」一列是空的，正常。看「该不该补」那一列，按顺序自己建。

| # | 符类 | 管什么 | 现有 | 该不该补 |
|---|---|---|---|---|
| 1 | 导演风格 | 视觉美学迁移 | — | 有立谱就够，暂不补 |
| 2 | 导演镜头 | 景别机位运镜切镜 | — | 已经有同类的就别重复做 |
| 3 | 美学光影 | 光源方向、色温、材质响应 | — | **★ 优先补**（每组都要） |
| 4 | 动作打斗 | 攻防因果、受力反馈 | — | **★ 补** |
| 5 | 动作编排 | 舞蹈、连续肢体 | — | 有这类戏再补 |
| 6 | 事件叙事 | 触发—行动—信息—结果 | — | 补一张就够 |
| 7 | 女性向情绪 | 关系、距离、视线 | — | 有就够 |
| 8 | 商业广告 | 产品完整性、卖点证据 | — | **★ 补**（商业线在用） |
| 9 | 音乐表演 | 节拍、舞台、灯光 | — | 低优先 |
| 10 | 音色表演 | 音色、语气、停顿 | — | **★ 补**（Vidu 有音色参考） |
| 11 | 多参数综合 | 多目标协调 | —— | **不要做**，符必须一件事 |
| 12 | 喜剧动作 | 预期差、意外、道具 | — | 有喜剧本子再补 |
| 13 | 视觉资产一致性 | 跨组身份/服装/道具继承 | — | **★★ 最该补**（跨组一致性最痛） |
| 14 | 参考解析 | 从参考图/视频抽机制 | — | 这是做符时的方法，不是挂片用的符 |

**补的顺序（按投入产出）：** 视觉资产一致性 → 美学光影 → 动作打斗 → 音色表演 → 商业广告。
一次补一张，补完先在自己片子里用三集，再谈下一张。

## 七、写进 meta.json 长什么样

```json
{
  "name": "常用运镜",
  "type": "镜头语言",
  "intro": "按戏剧任务选运镜、每个运动交代落点……",
  "prompt": "写推／拉／摇／移／跟／升降／环绕，或出现运镜重复、镜头死板时调用……",
  "status": "定稿",
  "parent": "",
  "tags": ["运镜", "镜头语言"],

  "chain": "aux",
  "locks": ["每个运动必有起点→路径→落点", "一个镜头只承担一个运动任务"],
  "variables": ["本镜的戏剧任务", "主体位置", "可用的运动幅度"],
  "negatives": ["无目的匀速晃镜", "起落幅都在动的复合运动", "运动与主体动作方向相反"],
  "defer": ["焦段", "速度曲线"],
  "score": {"D1": 18, "D2": 17, "D3": 19, "D4": 17, "D5": 17},
  "grade": "A+"
}
```

**八个字段里，`locks` / `variables` / `negatives` 是硬要求**（缺了就说明这张符没想清楚）。
`chain` / `defer` / `score` / `grade` 可选：单点符可以没有 `chain`；没评过的不要编分。

`lib --show` 会把它们全打出来；`lib --grade A` 只看够定稿的。

## 八、这份文件从哪来的

- **四个参数位（锁/变/禁/让）**：改写自《万能视频提示词符链 Skill v2.0》的参数状态
  （核心 / 默认 / 条件 / 可扩展 / 锁定）与「必要变量 / 开放变量」判断标准，压到卡片尺度。
- **主符 / 辅符 / 符链、关键词只是线索、冲突裁决六级、五维评分、负面约束按任务定制**：
  同源，按 Vidu Q4 的硬限（16 秒 / 9 图 3 音 / 2000 字）与本包的分镜组流程重写。
- **符有四态（候选/定稿/弃用）、6—7 区块容量闸、三道闸**：来自本包 `符的方法论.md`（方法出处：多参BUDDY）。

⚠ 参考体系原文 1400 行、30+ 参数、14 符类，是**视频提示词架构**；本文件只取能落到一张 16:9 卡片上的部分。
**不搬它的参数层级和输出协议**——那会把符写成一份文档，而符必须是一张能看懂的图。
